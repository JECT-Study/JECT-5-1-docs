# 요구사항 정의서 v0.2

|---|---|
| 기준일 | 2026-10-17 · 10/18 후속 결정 반영 |
| 작성 기준 | [MVP v0.6](../01_mvp/mvp-v0.6.md) · 와이어프레임_PM · 기능 명세서 v0.2 · 정책서 v0.2 |
| 문서 역할 | 요구사항 정의서 = **무엇을** 만들지 · 기능 명세서 = **어떻게** 동작하는지 (정책 · 조건 · 예외) |
| 연결 | 요구사항마다 "기능"으로 기능 명세서 ID를 가리킴 |

## 규칙

- **ID:** `REQ-영역-번호`
  - A 진입 · 가입 / B 교환글 작성 / C 탐색 · 교환 요청 / D 요청 수락 / E 채팅 · 약속 / F 현장 교환 · 완료 / G 마이 · 설정 / X 공통 / N 비기능
- **요구사항 문장:** "사용자는 \~할 수 있다" / "시스템은 \~해야 한다"
- **우선순위:** P0 (MVP 필수) / P1 (MVP 이후 바로) / 후순위
- **MVP:** 포함 / 제외 / 논의
- **상태:** 확정 / 논의 / 개발 확인 / 제안 (기능 명세서와 같은 기준)
- **예외:** 그 요구사항에서 안 되는 것 · 막히는 경우
- **화면:** 와이어프레임 화면 번호

## A 진입 · 가입

### REQ-A-01
사용자는 첫 실행 시 앱 소개(최대 5장)를 보고 건너뛸 수 있다
- `P0` · MVP 포함 · 확정 · 기능 A-01-1 · 화면 0-02
- 예외: 두 번째 실행부터는 안 보임

### REQ-A-02
사용자는 소셜 계정으로 로그인 · 가입할 수 있다
- `P0` · MVP 포함 · **논의** · 기능 A-02-1 · 화면 0-03
- 예외: 이메일 · 전화번호 가입 없음
- 비고: 로그인 종류 (카카오 · 구글 · 애플) [논의]

### REQ-A-03
시스템은 소셜 계정 기준으로 기존 · 신규 회원을 구분하고 중복 가입을 막아야 한다
- `P0` · MVP 포함 · 확정 · 기능 A-03-1 · 화면 0-03
- 예외: 같은 소셜 계정 중복 가입 불가 · 다른 소셜 계정으로 가입하면 별개 계정 (이메일 · 전화번호 미수집)

### REQ-A-04
사용자는 필수 약관(개인정보 수집 항목 · 목적 · 보관 기간)에 동의해야 가입할 수 있다. 마케팅 정보 수신 동의는 선택이다
- `P0` · MVP 포함 · 확정 · 기능 A-04-1 · 화면 0-04
- 예외: 필수 약관 미동의 시 다음 단계 불가

### REQ-A-05
사용자는 소셜 계정에서 받을 수 있는 정보는 자동으로 채워진 상태로, 나머지는 직접 입력해 닉네임 · 생년월일 · 성별 프로필을 만들 수 있다
- `P0` · MVP 포함 · 확정 · 기능 A-05-1, A-05-2, A-05-3 · 화면 0-05
- 예외: 자동으로 채워진 값도 수정 가능 · 만 14세 미만 가입 불가 · 닉네임 중복 불가 · 생년월일을 직접 입력하면 허위 입력은 막을 수 없음
- 비고: 수집 가능 범위는 소셜별로 다름 (BE 10/15 문서, 애플은 전부 직접 입력). [제안] 소셜이 실명을 주는 경우 닉네임에 자동 입력하지 않고 직접 설정. 성별 수집 목적: 연령 · 성별별 이용 통계. 닉네임 규칙은 명세서

### REQ-A-06
사용자는 온보딩에서 위시리스트 키워드를 등록하거나 나중에 할 수 있다
- `P0` · MVP **논의** · **논의** · 기능 A-06-1 · 화면 0-06
- 예외: 건너뛰어도 가입 가능 · 키워드는 금지어 검사
- 비고: 10/16: 개발 일정 산정 후 PM 결정 [논의]

### REQ-A-07
사용자는 알림을 켤지 선택하고, 켜면 OS 알림 권한을 요청받는다
- `P0` · MVP 포함 · 확정 · 기능 A-07-1 · 화면 0-06, 9-01
- 예외: 알림 거부해도 가입 · 이용 가능

### REQ-A-08
사용자는 가입 완료 화면에서 교환글 보기 또는 첫 글 작성으로 이어갈 수 있다
- `P0` · MVP 포함 · 확정 · 기능 A-08-1 · 화면 0-07

### REQ-A-09
로그인 상태가 유지된 사용자는 앱 실행 시 바로 첫 번째 탭으로 들어간다
- `P0` · MVP 포함 · 확정 · 기능 A-09-1 · 화면 0-01
- 예외: 로그인 만료 시 로그인 화면으로
- 비고: 첫 번째 탭 = 교환 지도 (10/13)

## B 교환글 작성

### REQ-B-01
사용자는 사진(1\~5장, 앱 안 촬영 포함)과 템플릿(10개 항목)으로 교환글을 작성할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 B-01-1, B-01-2 · 화면 1-06, 1-07
- 예외: 사진 0장이면 게시 불가 · 6장 이상 첨부 불가
- 비고: 명세서 "9개 항목" → 10개 (태그 추가)

### REQ-B-02
사용자는 교환글에 # 태그를 최대 5개 달 수 있고, 입력한 글자가 들어간 기존 태그를 사용 횟수순 자동완성으로 고를 수 있다
- `P0` · MVP 포함 · 확정 · 기능 B-02-1 · 화면 1-06, 1-03
- 예외: 6개째 태그 입력 불가 · 같은 태그 중복 불가 · 금지어 태그 불가
- 비고: 태그별 사용 횟수 수집 필요 (BE 요청)

### REQ-B-03
사용자는 희망 장소(필수)를 거점 · 현재 위치 · 장소 검색 · 지도 핀으로 정할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 B-03-1, B-03-2, B-03-3 · 화면 1-08
- 예외: 희망 장소 없이 게시 불가 (지도 · 가까운순의 기준) · 거점만 고르면 거점 대표 좌표 사용
- 비고: 핀의 거점 반경 판정은 개발 확인

### REQ-B-04
사용자는 현장 모드를 켜고 유지 시간을 정할 수 있으며, 시간이 끝나면 일반 글로 바뀐다
- `P0` · MVP 포함 · 확정 · 기능 B-04-1 · 화면 1-06
- 예외: 최대 3시간 초과 설정 불가 · 끝나면 자동 해제
- 비고: 3시간 = 쇼핑몰 체류 시간 기준 (10/15) · 개발 확인 완료: 서버 자동 해제 (10/18)

### REQ-B-05
시스템은 교환글 입력 단계에서 금지어를 검사해 표시하고, 게시할 때 서버에서 한 번 더 검사해야 한다
- `P0` · MVP 포함 · 확정 · 기능 B-05-1, B-06-2 · 화면 1-06
- 예외: 금지어 포함 시 게시 불가
- 비고: 태그도 검사 대상

### REQ-B-06
사용자는 필수 항목을 채우면 작성 완료 즉시 교환글을 게시할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 B-06-1, B-06-2 · 화면 1-06, 1-01
- 예외: 필수 항목 빠지면 게시 버튼 비활성

### REQ-B-07
사용자는 내 교환글을 수정 · 삭제하고 현장 모드를 끌 수 있다
- `P0` · MVP 포함 · 확정 · 기능 B-07-1, B-07-2, B-07-3 · 화면 1-03c, 5-04
- 예외: 대기 중 · 수락된 요청이 남아 있으면 수정 불가 (전부 거절 · 만료되면 수정 가능) · 예약중 글은 약속 취소 후 삭제 가능 · 교환 완료 글 삭제 불가
- 비고: 요청 받은 뒤 글 내용이 바뀌면 안 됨 (10/15)

### REQ-B-08
시스템은 교환글 상태를 약속 확정 시 예약중, 교환 완료 처리 시 교환 완료, 약속 취소 시 교환 가능으로 자동 변경해야 한다
- `P0` · MVP 포함 · 확정 · 기능 B-08-1 · 화면 1-03, 5-04
- 예외: 사용자가 직접 바꿀 수 없음 · 요청 · 수락 단계에서는 교환 가능 유지 (여러 명과 동시 채팅 가능)
- 비고: 명세서 C.1 교환글 상태 정책과 연결

### REQ-B-09
시스템은 금지어를 반복 위반한 사용자를 제재해야 한다
- `P0` · MVP **논의** · **논의** · 기능 정책서 P-05-04 · 화면 -
- 예외: 1회 글 삭제 + 경고 · 2회 7일 제한 · 3회 영구 정지 (외부 거래 · 판매 확인 포함)
- 비고: 정책서 P-05-04 (기준값 확정) · MVP 적용 여부는 [논의] (P-05-01)

## C 탐색 · 교환 요청

### REQ-C-01
사용자는 교환 지도에서 [지도 \| 리스트]를 전환해 현장 글을 보고 카테고리로 거를 수 있다. 지도는 축소하면 거점별로 묶이고 확대하면 개별 핀으로 보인다
- `P0` · MVP 포함 · 확정 · 기능 C-01-1, C-01-2, C-01-3 · 화면 3-01, 3-02
- 예외: 위치 권한 없어도 지도는 보임 (내 위치만 표시 안 됨) · 예약중 글 제외 · 거점만 고른 글은 거점 대표 좌표에 표시
- 비고: 교환 지도 = 첫 번째 탭 (10/13) · 10/16 이전안 확정 (FE 구현 가능) · 거점별 대표 출구, 글이 많을 때 성능 [개발 확인] · 구성은 PD 하이파이

### REQ-C-02
사용자는 교환 지도의 내 위치 버튼을 누르면 내 위치 주변 1km가 보이게 이동하고, 이후 줌은 자유롭게 조절할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-02-1 · 화면 3-01
- 예외: 위치 권한 거부 시 권한 안내 화면
- 비고: 1km = 서베이 이동 30분 이내 최다 (도보 15분) · 10/16: 탭 → 버튼, 줌 상한 없음 (FE)

### REQ-C-03
사용자는 교환글 리스트를 최신순 · 가까운순 · 인기순으로 보고 카테고리 · 거점으로 거를 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-03-1, C-03-2, C-03-3 · 화면 1-01, 1-02a
- 예외: 가까운순은 위치 권한 필요
- 비고: 인기순 = 최근 7일 받은 교환 요청 수 순, 같으면 조회수 순 (운영하며 변경 가능). 리스트 = 두 번째 탭 (10/13)

### REQ-C-04
사용자는 제목과 태그로 교환글을 검색할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-04-1 · 화면 1-02
- 예외: 차단한 사용자 글 제외 · 결과 없으면 빈 화면 안내
- 비고: 정확도순: ① 태그 정확히 일치 ② 제목 포함 ③ 태그 일부 포함, 같은 순위는 최신순. 정렬 선택: 정확도순 · 최신순 · 가까운순 · 인기순 (10/16)

### REQ-C-05
사용자는 최근 검색어를 보고 다시 검색하거나 지울 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-05-1 · 화면 1-02

### REQ-C-06
사용자는 교환글 상세에서 사진 · 템플릿 정보 · 태그 · 게시자 신뢰 정보를 확인할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-06-1, C-06-2 · 화면 1-03, 1-05
- 예외: 삭제된 글은 "삭제된 글" 안내

### REQ-C-07
사용자는 내 아이템(내 교환글 또는 새 사진)을 첨부해 교환을 요청할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-07-1, C-07-2 · 화면 1-03a, 1-04
- 예외: 아이템 첨부 없이 요청 불가 · 내 글 · 예약중 · 교환 완료 글에는 요청 불가 · 새 사진 아이템 이름은 금지어 검사
- 비고: 원하는 아이템이 아니어도 제안 가능

### REQ-C-08
시스템은 같은 글에 대기 중인 요청이 있으면 중복 요청을 막아야 한다
- `P0` · MVP 포함 · 확정 · 기능 C-08-1 · 화면 1-03a
- 예외: 대기 중 요청 있으면 같은 글에 새 요청 불가

### REQ-C-09
요청자는 거절된 요청을 1회 다시 보낼 수 있다 ("이미 교환했어요"는 제외)
- `P0` · MVP 포함 · 확정 · 기능 C-09-1 · 화면 1-03, 1-03a
- 예외: 재요청은 1회까지 · "이미 교환했어요" 거절은 재요청 불가

### REQ-C-10
시스템은 교환 요청 · 채팅에서 외부 거래 표현을 키워드로 감지하면 전송은 하되 경고와 신고하기를 보여줘야 한다
- `P0` · MVP 포함 · 확정 · 기능 C-10-1 · 화면 1-03a, 5-05a, 2-02
- 예외: 전송은 막지 않음 (경고만)
- 비고: 전송을 막지 않는 이유: "어디서 샀어요"처럼 구한 경로를 말하는 경우가 있어 맥락을 봐야 판단 가능. 키워드 목록은 정책서 P-02-06 [제안]

### REQ-C-11
사용자는 교환글을 신고하고, 사용자를 차단할 수 있다
- `P0` · MVP 포함 · 확정 · 기능 C-11-1, C-11-2 · 화면 9-04, 1-03b
- 예외: 차단한 사용자의 글 · 채팅 · 요청 안 보임
- 비고: 글 숨기기는 MVP 제외 (10/15) → REQ-C-12

### REQ-C-12
사용자는 보고 싶지 않은 교환글을 숨기고, 숨긴 글을 다시 볼 수 있다
- 후순위 · MVP 제외 · 확정 · 기능 C-12-1 · 화면 9-04
- 비고: MVP 제외 (10/15): 초기 글 수가 적고 신고 · 차단으로 대응 가능, 관리 화면 공수 절감
