### E-01-1 채팅 목록

> 내가 참여한 1:1 채팅방을 최근 메시지순으로 보여준다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-01 | P-07-03 | 2-01 |

- **예외 · 제약:**
  - 채팅방은 교환 요청을 보내면 바로 생긴다.
  - 목록 위 칩으로 전체 · 상태 · 받은 요청 · 보낸 요청을 골라 본다.
  - 차단한 상대의 방은 숨긴다.
- **비고:** v0.5.1 (10/28): 보낸 · 받은 요청 한 목록 · 새 요청 방 문구 · 글별 채팅 목록([채팅 n개 보기]) 같은 행 재사용 · 밀어서 나가기 없음 · 빈 화면 옛 수락 문구 교체 (PM 결정, PD 채팅 탭 초안 검토). v0.5.2 (10/31): 글별 채팅 목록 진입에 내 교환글 [채팅 n] 2개 이상 추가. 11/23: 하이파이에 맞춰 칩 추가

**진입** 하단 탭 채팅(2-01)에서 들어온다. 내 교환글 상세 [채팅 n개 보기](C-05-1)를 누르거나, 내 교환글 관리 [채팅 n]이 2개 이상일 때(G-02-2) 누르면 글별 채팅 목록으로 들어온다

**동작**
1. 목록 위에 칩 [전체] [상태 ▾] [받은 요청] [보낸 요청]을 둔다.
   - 처음에는 [전체]가 선택되어 있고, 보낸 요청 · 받은 요청을 한 목록에 보여준다.
   - [받은 요청]을 누르면 내 글로 받은 요청 방만, [보낸 요청]을 누르면 내가 요청한 방만 보여준다.
   - [상태 ▾]를 누르면 상태를 골라 본다 (선택지는 아래 미결정).
2. 최근 메시지 시각 내림차순으로 정렬한다.
3. 항목에는 상대 닉네임 · 교환글 대표 사진 · 마지막 메시지 1줄 · 시각 · 안 읽은 수 · 상태 배지(예약중 · 교환 완료)가 보인다.
4. 항목을 누르면 채팅방(2-02)으로 가고, 안 읽은 수를 초기화한다.

**조건**
- 마지막 메시지가 사진이면 "사진"으로, 시스템 메시지면 요약 문구로 보여준다.
- 안 읽은 수가 99를 넘으면 "99+"로 보여준다.
- 교환이 끝난 방도 그대로 남긴다 (배지 "교환 완료")
- 내가 나간 방은 목록에서 지운다
- 상대가 나간 방은 남기고 "상대가 나갔어요"를 표시한다.
- 새 요청 방(첫 메시지가 아이템 카드)의 마지막 메시지 줄은 받은 쪽에 "교환 요청이 왔어요", 보낸 쪽에 "교환 요청을 보냈어요"로 보인다 (10/28, 함께 보낸 메시지는 11/20 삭제)
- 목록에서 밀어서 나가기 · 알림 끄기는 없다. 채팅방 ⋮에서만 할 수 있다 (E-09-1) (10/28)
- 알림을 끈 방은 목록 행에 표시한다 (모양은 PD, 10/29)
- 글별 채팅 목록(내 교환글 상세 [채팅 n개 보기] · 내 교환글 관리 [채팅 n] 2개 이상)은 아래처럼 보인다 (10/28)
  - 같은 행 디자인을 쓴다.
  - 상단만 다르다. 뒤로가기 + 교환글 제품명 + "채팅 n"이 보인다.
  - 이 글로 열린 방 중 상대가 나가지 않은 방만 보인다.
  - n은 상세의 "요청 n"과 같다.
  - 하단 탭은 없다.
- 남의 글 상세 [채팅으로 가기]는 목록을 거치지 않고 그 채팅방(2-02)으로 바로 간다 (같은 글 · 같은 사람 채팅방 1개)

| 예외 상황 | 처리 |
|---|---|
| 0개 | "채팅중인 상대가 없습니다" / "새로운 교환을 요청해보세요!"와 [교환글 보러가기]를 보여준다. 칩 줄은 그대로 보인다 |
| 불러오기 실패 | 공통 오류를 보여준다 (P-07-03) |

**결과** 채팅방으로 들어간다

**미결정**
- [논의] [상태 ▾] 칩의 선택지 (PD 확인)

### E-01-2 메시지 전송 (텍스트 · 사진 · + 메뉴)

> 텍스트와 사진을 주고받고, + 메뉴에서 사진 선택 · 약속 잡기를 연다 (장소 보내기는 P2)

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-01, REQ-N-09 | P-02-03, P-07-04 | 2-02, 2-02h |

- **예외 · 제약:**
  - 예약중 · 교환 완료 뒤에도 대화는 유지된다.
  - 같은 글이 다른 방에서 예약중 · 교환 완료면 + 메뉴의 약속 잡기를 쓸 수 없다 (E-11-1).
  - 대화가 막히는 경우는 나가기 · 차단 · 탈퇴 · 이용 제한뿐이다.
- **비고:** 외부 거래 표현 경고(C-08-1)는 2차 (10/20). v0.5 (10/27): 약속 잡기 · 약속 취소는 + 메뉴에서 (입력창 위 버튼 삭제). v0.5.2 (10/29~10/31): 교환 완료 뒤 같은 글 다른 방도 대화 유지 · 차단당한 쪽 · 탈퇴 · 이용 제한 입력창 문구 · 교환 완료 방 + 메뉴는 사진만 · 외부 거래 경고 보낸 사람에게도

**진입** 채팅방(2-02) 입력창에서 시작한다

**동작**
1. 텍스트 · 사진을 보내면 상대에게 새 메시지 알림이 간다 (X-01-1).
2. 입력칸 왼쪽 + 버튼을 누르면 바텀시트가 열린다 (하이파이대로, 11/23).
   - 시트에는 사진 선택(B-01-2 재사용) / 약속 잡기(E-03-1) / [닫기]가 있다.
   - 장소 보내기(E-02-1)는 P2다.
   - 확정 약속이 있으면 약속 잡기 자리가 약속 취소(E-07-1)로 바뀐다.
   - 입력창 위 약속 버튼은 없다 (10/27 PM · PD 합의).
3. 텍스트는 외부 거래 표현 검사를 한다 (C-08-1, P1).
   - 보낸 사람 · 받은 사람 화면 모두 메시지 아래에 경고가 보인다.
   - 받은 사람에게는 [신고하기]도 보인다.
   - 상단 고정 경고는 없다.

**조건**
- 텍스트는 1\~1,000자다. 공백만 있으면 보낼 수 없다.
- 사진은 1회에 최대 5장까지 보낸다.
- 입력칸은 4줄까지 늘어나고 그 뒤로는 스크롤된다.
- 메시지는 실시간으로 전달한다 (REQ-N-09)
- 예약중이어도, 교환이 완료돼도 대화는 유지된다. 같은 글의 다른 방도 대화는 유지되고 약속 잡기만 막힌다 (F-02-1)
- 교환 완료된 당사자 방의 + 메뉴에는 사진 선택만 있다 (약속 잡기 · 장소 보내기 없음)
- 읽음 표시는 MVP에서 빠진다 (이후)

| 예외 상황 | 처리 |
|---|---|
| 전송 실패 | 말풍선 옆에 !가 보인다. 누르면 [다시 보내기] / [삭제]가 나온다 |
| 다른 분과 교환이 완료된 글의 방 | 대화는 유지된다. + 메뉴의 약속 잡기는 쓸 수 없고, 누르면 토스트 "교환이 완료된 글이에요"가 뜬다 |
| 상대가 나간 방 | 입력창 대신 "상대가 대화방을 나갔어요"가 보인다 |
| 차단 | 차단한 쪽은 방이 숨겨진다. 차단당한 쪽은 방이 남고 입력창 대신 "대화할 수 없는 상대예요"가 보인다 (차단 사실은 알리지 않음, C-09-2) |
| 상대 탈퇴 · 영구 정지 | 닉네임 자리에 "탈퇴한 사용자"가 보이고, 입력창 대신 "탈퇴한 사용자와는 대화할 수 없어요"가 보인다. 탈퇴 처리 전체는 G-09-2 "탈퇴하면 바뀌는 것" 표에 있다 |
| 상대가 이용 제한 중 | 입력창 대신 "지금은 대화할 수 없는 상대예요"가 보인다 (제재 사실은 알리지 않음). 제한이 풀리면 다시 대화할 수 있다 (P-05-01) |
| 내가 이용 제한 중 | 대화는 볼 수 있다. 입력창 · + 메뉴 대신 "이용 제한 중이라 메시지를 보낼 수 없어요 · {해제일}까지"가 보인다. 누르면 사유 · 해제일 · 문의하기가 나온다 (P-05-05) |

**결과** 말풍선이 바로 보이고, 맨 아래로 스크롤된다

### E-01-3 상단 교환 카드 · 시스템 메시지

> 채팅방 위에 교환 대상과 글 상태를 고정하고, 교환 요청 · 약속 · 취소 · 완료 같은 진행 상황을 채팅 흐름에 카드로 남긴다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-01 | - | 2-02 |

- **예외 · 제약:** 시스템 메시지와 수정 · 삭제 자동 메시지는 삭제할 수 없다.
- **비고:** v0.4 (10/26): 첫 메시지 아이템 카드 · 입력창 위 [약속잡기]/[약속취소] · 약속 변경 제안 · 첨부 글 수정 카드 · 상단 바 매너 지표 2차. 상단 카드 상태 배지 PD 시안 반영 (10/29). v0.5 (10/27): 약속 버튼 → + 메뉴 · 수정 · 삭제 안내 = 수정 · 삭제한 사람 쪽 자동 메시지 · 상단 카드 다시 계산

**진입** 채팅방(2-02)

**동작**
1. 상단 카드에는 교환글 대표 사진 · 제품명 ↔ 첨부 아이템 요약 + 상태 배지가 보인다.
   - 첨부 아이템 요약은 첫 아이템 카드를 기준으로 "OO 외 n개"로 보인다.
   - 아이템이 삭제되면 남은 아이템으로 다시 계산한다 (남은 게 없으면 "⇆ 삭제된 아이템").
   - 상태 배지는 교환 가능 · 예약중 · 교환 완료 중 하나다.
   - 확정 약속이 있으면 "10.10 (토) 오후 3:00 · 홍대입구역" 한 줄이 보인다.
2. 상단 바에는 상대 닉네임 · "교환 n회" · 매너 지표(F-06-1)가 보인다.
   - 프로필 사진은 없다.
   - 닉네임을 누르면 상대 프로필(C-05-2)로 간다.
3. 약속은 입력칸 + 메뉴에서 잡거나 취소한다.
   - 확정 약속이 없으면 약속 잡기(E-03-1)가 보인다.
   - 확정 약속이 있으면 약속 취소(E-07-1)가 보인다.
   - 입력창 위 버튼은 없다 (10/27).
4. 진행 상황이 바뀌면 시스템 메시지 카드를 넣는다

| 이벤트 | 카드 · 버튼 |
|---|---|
| 교환 요청 (첫 메시지) | 첨부 아이템마다 사진 카드가 하나씩 올라간다 (사진 · 제품명 · 상품 상태 배지, 최대 5개). 카드를 누르면 아이템 상세로 간다 (C-07-1 · C-07-2) |
| 약속 제안 (카드 제목 "약속 제안") | 상대에게는 [거절] [수락하기]가 보인다. 제안한 사람에게는 [제안 취소]가 보인다 (11/23 PM, 화면은 PD 확인 [논의]) |
| 약속 확정 (카드 제목 "약속 확정") | 교환할 굿즈 · 날짜 · 시간 · 장소와 "약속 30분 전에 알림을 보내드려요"가 보인다. 카드를 누르면 약속 상세(2-06)가 열린다 (E-03-2). [수정하기]는 P1이다 |
| 약속 변경 제안 (P1) | 상대에게만 [수락] [거절]이 보인다 |
| 첨부 글 · 아이템 · 요청받은 글 수정 | 수정한 사람 쪽 자동 메시지 카드 "'아이템명'을 수정했어요 [보러가기]"가 올라간다 (내 화면 오른쪽 · 상대 화면 왼쪽). [보러가기]를 누르면 아이템 상세(C-07-2)로 가고, 요청받은 글이면 교환글 상세(C-05-1)로 간다 |
| 약속 취소 | 내 화면에는 "약속이 취소됐어요", 상대 화면에는 "상대가 약속을 취소했어요"가 보인다 (E-07-1) |
| 상대 탈퇴 | "상대가 탈퇴했어요"가 보인다 (푸시 없음). 확정 약속이 있었으면 "상대가 탈퇴해서 약속이 취소됐어요"가 보인다 (푸시 "약속이 취소됐어요"). G-09-2 |
| 제안 만료 (P1) | "응답이 없어 약속 제안이 만료됐어요"가 보인다 (E-10-1) |
| 약속 제안 자동 취소 (다른 방에서 먼저 확정) | "다른 분과 약속이 먼저 확정돼서 이 약속 제안은 취소됐어요"가 보이고, 카드 버튼은 "취소됨"으로 바뀐다 (E-04-1 · E-05-1) |
| 교환 확인 질문 (카드 제목 "교환을 완료했나요?") | [교환하지 못했어요] [무사히 교환했어요]가 보인다 (F-01-1) |
| 교환 완료 | "교환에 성공했어요!" 카드가 올라간다. [후기 남기기]는 P2다 (F-05-1) |
| 다른 분과 교환 완료 ("다른 분과 교환이 완료됐어요") | - (대화는 유지되고 약속 잡기는 쓸 수 없다, F-02-1) |
| 자동 완료 | "응답이 없어 자동으로 완료됐어요. 교환하지 않았다면 마이 > 문의하기로 알려주세요"가 보인다 (F-03-1) |
| 운영자가 자동 완료를 되돌림 | "교환 전으로 되돌렸어요"가 보인다 (H-03-4) |
| 같은 글이 다른 방에서 예약중 ("다른 분과 약속이 잡혀 있어요") | - (약속잡기를 쓸 수 없다, E-11-1) |
| 앞 약속 취소 ("다시 약속을 잡을 수 있어요") | + 메뉴의 약속 잡기를 다시 쓸 수 있다 |
| 교환글 삭제 | "교환글이 삭제됐어요"가 보이고, 상단 카드는 "삭제된 글이에요"로 바뀐다 (B-07-2) |
| 첨부 글 삭제 | 지운 사람 쪽 자동 메시지 "'아이템명'을 삭제했어요"(버튼 없음)가 올라간다. 그 아이템 카드는 "삭제된 아이템"으로 바뀐다. 상단 카드를 다시 계산한다 (B-07-2) |

**조건**
- 카드 버튼은 처리 뒤 결과로 바뀐다 (예: [수락하기] → "수락했어요")
- 첫 메시지 카드에 [약속 잡기] 버튼은 없다 (10/26). 약속 잡기 · 취소는 + 메뉴에서 한다 (10/27)
- 수정 · 삭제 안내는 시스템 메시지가 아니라 수정 · 삭제한 사람이 보낸 자동 메시지로 보인다. 사용자가 지울 수 없다 (10/27, PD 시안)

| 예외 상황 | 처리 |
|---|---|
| 이미 처리된 카드 버튼 | "이미 처리된 요청이에요"라고 안내한 뒤 카드를 갱신한다 |
| 교환글이 삭제됨 | 상단 카드가 "삭제된 글이에요"로 바뀐다 |

**결과** 상단 카드를 누르면 교환글 상세로 간다. 확정 약속 카드를 누르면 약속 상세(시간 · 장소 · 교환할 굿즈, 보기 전용)로 간다. [수정하기]는 P1이다

### E-03-1 약속 제안

> 시간 · 장소 · 교환할 굿즈를 정해 약속을 제안한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-03 | - | 2-02b |

- **출시 후로 미루는 부분:** 임박 취소 안내 문구 (E-08-1, P1)
- **예외 · 제약:**
  - 지난 시간으로는 제안할 수 없다.
  - 한 채팅방에 진행 중인 제안은 1개만 둘 수 있다.
- **비고:** v0.4 (10/26): '교환할 물건' 고르기 추가 (PD 시안 '원하는 물품 직접 입력' → 첨부 아이템 중 고르기) · 진입 = 입력창 위 [약속잡기]. v0.5 (10/27): 진입 = + 메뉴 약속 잡기. v0.5.2 (10/29): 버튼 "약속 제안하기" · 장소는 지도에서 검색 또는 핀 · 주의사항에 취소 규칙

**진입** 채팅 입력칸 + 메뉴에서 약속 잡기를 누른다 (확정 약속이 없을 때)

**동작**
1. 전체 화면 "교환 약속 잡기"가 열린다. 날짜와 시간은 따로 고른다.

| 항목 | 필수 | 입력 방식 |
|---|---|---|
| 날짜 선택 | 필수 | 오늘 / 직접 선택(달력) 중에서 고른다 |
| 시간 | 필수 | 지금 바로 / 직접 선택(10분 단위) 중에서 고른다. 지금 교환 글은 "지금 바로"가 기본이다 |
| 장소 | 필수 | 빈 칸에는 "장소 선택"이 보인다. 기본값은 교환글 희망 장소다. 누르면 지도에서 장소를 검색하거나 핀으로 지정한다. 검색으로 고르면 장소 이름이, 핀으로 고르면 지번이 표시된다 (교환글 희망 장소와 같은 규칙) |
| 교환할 굿즈 | 필수 | 요청에 첨부된 아이템 중에서 고른다 (체크, 1개 이상). 줄마다 상품 상태 · 제품명 · 체크박스가 보인다. 첨부가 1개면 자동으로 선택되고 칸은 숨긴다 |

- 약속 전 알림을 고르는 줄은 없다. 약속 30분 전에 각자에게 알린다 (E-06-1).

2. 화면 아래에 주의사항 "약속 30분 뒤 교환했는지 물어봐요"가 보인다. 임박 취소 안내 "약속 1시간 전부터 취소하면 매너 지표에 반영돼요. 그 전에는 자유롭게 취소할 수 있어요"는 P1이다 (E-08-1).
3. [약속 제안하기]를 누르면 채팅에 "약속 제안" 카드(교환할 굿즈 · 날짜 · 시간 · 장소)가 올라가고, 상대에게 알림이 간다.

**조건**
- 날짜는 오늘\~7일 후 범위에서 고른다.
- 진행 중 제안은 한 채팅방에 1개다. 새로 제안하려면 이전 제안을 취소해야 한다.
- 제안은 수락 · 거절 · 철회 전까지 남는다. 철회는 제안한 사람이 카드의 [제안 취소]를 눌러서 한다 (11/23 PM). 자동 만료(24시간 · 약속 시각)는 P1이다 (E-10-1)
- 교환할 굿즈(교환할 물건): 요청에 여러 개를 첨부했으면 이 중 실제로 교환할 것을 고른다. 고른 물건이 확정 카드에 표시되고, 교환 완료 때 고른 아이템의 글만 교환 완료된다 (F-01-2)
- 고를 수 있는 건 아직 교환 가능한 첨부 아이템뿐이다 (다른 곳에서 예약중 · 교환 완료 · 삭제된 아이템은 빠진다).

| 예외 상황 | 처리 |
|---|---|
| 지난 시각 | 선택할 수 없다고 안내한다 |
| 진행 중 제안 있음 | "이전 제안을 취소하고 새로 제안할까요?"라고 묻는다 |
| 같은 글이 다른 방에서 예약중 · 교환 완료 · 교환글 삭제됨 | 약속 잡기를 쓸 수 없다 (E-11-1) |
| 고를 수 있는 첨부 아이템 0개 | "교환할 수 있는 아이템이 없어요"를 보여주고, 약속을 제안할 수 없다 |

**결과** 약속 제안 카드가 보인다

### E-03-2 약속 수락 · 확정 약속 수정

> 상대가 제안을 수락하면 확정되고, 확정 뒤에는 약속 상세에서 변경을 제안해 상대가 수락하면 바뀐다 (확정 약속 수정은 P1)

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-03 | - | 2-02b, 2-06 |

- **출시 후로 미루는 부분:** 확정 약속 수정 · 변경 제안 (P1). 바꾸려면 약속을 취소하고 다시 제안한다
- **이번 출시의 약속 상세(2-06):** 보기 전용으로 넣는다. 시간 · 장소 · 교환할 굿즈만 본다. 바꿀 수 있는 것은 없다 (11/23 PM)
- **예외 · 제약:**
  - 제안자 본인은 수락할 수 없다.
  - 변경은 상대가 수락할 때만 반영된다 (P1).
  - 약속 시간이 지나면 수정할 수 없다 (P1).
- **비고:** v0.4 (10/26): 제안 단계 '수정 요청' 삭제 → 확정 약속 카드 탭 → 약속 상세 [수정하기] → 변경 제안 → 상대 수락 (PM)

**진입** "약속 제안" 카드에서 [수락하기] · [거절]을 누른다. 확정 약속 수정은 확정 약속 카드를 눌러 약속 상세로 간 뒤 [수정하기]를 누른다 (P1)

**동작 — 제안 수락**
1. [수락하기]를 누르면 수락 시트가 열리고, 시트에서 [수락하기]를 누르면 확정한다 (E-04-1). 시트에 약속 전 알림을 고르는 줄은 없다.
2. [거절] (PD 시안 [취소])을 누르면 제안이 무효가 되고, 제안자에게 알림이 간다. 다시 제안하려면 + 메뉴의 약속 잡기를 쓴다.

**동작 — 확정 약속 수정 (P1)**
1. 확정 카드를 누르면 약속 상세(2-06)가 열린다. 시간 · 장소 · 교환할 굿즈와 [수정하기]가 보인다.
2. [수정하기]를 누르면 기존 값이 채워진 약속 잡기 화면이 열린다. 값을 고쳐서 보낸다.
3. 채팅에 "약속 변경을 제안해요" 카드가 올라가고, 상대에게 [수락] [거절]이 보인다.
4. 수락하면 새 약속으로 바뀌고, 약속 전 알림(E-06-1)과 교환 확인 시점(F-01-1)을 새 시간 기준으로 다시 예약한다.
5. 거절하거나 응답이 없으면 기존 약속을 그대로 둔다.

**조건**
- 제안자 본인은 자기 제안을 수락할 수 없다
- 수정은 양쪽 다 할 수 있다. 대기 중인 변경 제안은 1개 (P1)
- 약속 시간이 지나면 수정할 수 없다 (교환 확인 단계로 넘어간다) (P1)
- 약속 취소는 약속 상세가 아니라 + 메뉴에서 한다 (E-07-1, 10/27)
- 제안 단계의 "수정 요청"은 없다 (10/26). 바꾸려면 거절한 뒤 다시 제안하고, 확정 뒤에 바꾸려면 약속을 취소하고 다시 제안한다 ([수정하기]는 P1).
- 변경 제안은 24시간 뒤 만료된다 (10/29) (P1)
  - 약속 시각이 더 빠르면 그 시각에 만료된다.
  - 만료되거나 거절되면 기존 약속을 유지한다.
- 약속 수정은 임박이어도 매너 지표에 반영하지 않는다 (상대가 수락해야 바뀌는 변경, 10/29) (P1)

| 예외 상황 | 처리 |
|---|---|
| 제안이 만료(P1) · 취소 · 새 제안으로 바뀜 | "더 이상 유효하지 않은 약속이에요"라고 안내한 뒤 카드를 갱신한다 |
| 제안에 담긴 물건(첨부 글)이 삭제됨 | 그 제안을 자동으로 취소하고 채팅방에 안내한다. 그 뒤 수락은 실패한다 (B-07-2) |
| 약속 시각이 이미 지남 | "약속 시간이 지났어요. 새로 약속을 잡아주세요"를 보여준다 |
| 수락 순간 다른 방에서 먼저 확정 | E-05-1 |
| 변경 제안 대기 중 [수정하기] (P1) | 누를 수 없고 "변경 제안에 대한 답을 기다리고 있어요"가 보인다 |

**결과** 약속이 확정되거나, 약속이 바뀌거나(P1), 기존 약속이 그대로 유지된다

### E-04-1 약속 확정 · 예약중 전환

> 약속 요청을 수락하면 약속을 확정하고 글을 예약중으로 바꾸며, 같은 글의 다른 약속 요청 · 제안은 자동 거절하되 다른 채팅방 대화는 유지한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-04 | P-07-03 | 2-02, 2-02 약속 수락 시트 |

- **예외 · 제약:**
  - 글 하나에 확정 약속은 1개만 둘 수 있다.
  - 다른 채팅방의 약속 요청 · 제안은 자동으로 거절된다 (매너 지표 영향 없음, P-01-01).
  - 그 채팅방에서는 약속 잡기를 쓸 수 없다 (E-11-1).
- **비고:** 10/18: 약속 요청은 여러 채팅방에서 받을 수 있고, 하나를 수락하면 나머지 자동 거절 (PM). v0.4 (10/26): 약속에서 고른 첨부 글도 예약중 · 확정 카드 탭 → 약속 상세. v0.5.2 (10/29): 확인 창을 없애고 수락 시트 안 한 줄 안내로 합침

**진입** 약속 카드 [수락하기]를 누른 뒤 수락 시트에서 [수락하기]를 누른다 (E-03-2). 같은 글에 진행 중인 다른 약속 제안이 있으면 시트 안에 한 줄 "다른 채팅방의 약속 제안은 모두 취소돼요"가 보인다 (확인 창 없음)

**동작**
1. 글이 교환 가능인지 확인한다.
2. 아래를 한 번에 처리한다.
   - 약속을 확정한다.
   - 글을 예약중으로 바꾼다.
   - 약속에서 고른 첨부 글도 예약중으로 바꾼다 (10/26: 고른 첨부 글의 수정 · 삭제 · 다른 약속을 막기 위해).
   - 알림을 예약한다.
3. 채팅방에 "약속 확정" 카드(교환할 굿즈 · 날짜 · 시간 · 장소 · "약속 30분 전에 알림을 보내드려요")가 올라가고, 상단 배지가 "예약중"으로 바뀐다.
   - 카드를 누르면 약속 상세로 간다 (E-03-2).
   - + 메뉴의 약속 잡기가 약속 취소로 바뀐다.
4. 새 교환 요청을 막는다
5. 같은 글의 다른 채팅방은 대화를 유지한다.
   - 그 방에 진행 중인 약속 제안은 자동으로 취소한다.
   - "다른 분과 약속이 먼저 확정돼서 이 약속 제안은 취소됐어요" 안내와 알림을 보낸다 (P-07-04).
   - 카드 버튼은 "취소됨"으로 바뀐다.
6. 약속 30분 전 알림(E-06-1)과 약속 30분 뒤 교환 확인(F-01-1)을 예약한다. "지금 바로" 약속은 약속 전 알림이 없다.
7. 지금 교환 글이면 지금 교환 배지를 숨긴다 (시간은 계속 흐름). 약속이 취소돼 교환 가능으로 돌아왔을 때 시간이 남아 있으면 다시 보인다 (B-04-1)

| 예외 상황 | 처리 |
|---|---|
| 확정 순간 다른 방에서 먼저 확정 | E-05-1 |
| 처리 실패 | 약속 카드는 제안 상태로 둔다. 공통 오류를 보여준다 (P-07-03) |

**결과** 글이 예약중이 되고, 약속이 확정된다

**진입** 약속 확정 (E-04-1)

**동작**

2. 약속 30분 전에 두 사람 각자에게 "30분 뒤 {장소}에서 {닉네임}님과 교환 약속이 있어요" 알림을 보낸다.

| 푸시 실패 | 앱 안 알림 목록에는 저장한다 |

**결과** 알림을 누르면 채팅방으로 간다

### E-07-1 약속 취소

> 확정된 약속을 + 메뉴에서 확인 팝업 한 번으로 바로 취소한다 (상대 동의 없음)

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-07 | P-07-01, P-01-01, P-07-03 | 2-02h, 2-02d |

- **예외 · 제약:**
  - 상대 동의 단계는 없다.
  - 약속 1시간 전부터("지금 바로" 약속은 확정 순간부터)의 임박 취소(E-08-1)는 P1이다. 이번 출시는 임박 여부와 상관없이 같은 방식으로 취소한다.
  - 교환 확인 질문이 뜨기 전(약속 시각 30분 뒤)까지는 약속 취소를 쓸 수 있다. 질문이 뜬 뒤에는 취소 대신 [교환하지 못했어요]로 정리한다 (11/23 PM) (F-01-1). "지금 바로" 약속도 같다.
- **비고:** v0.5.2 (10/29): 취소 요청 · 합의 취소 · 동의 / 거절 단계와 일방 취소(옛 E-08-2)를 없애고 한 번에 취소로 합침. 취소하려는 사람은 급한 일이 생긴 경우라 요청 · 동의를 거치면 불편하고, 규칙을 약속 제안 때 미리 알린 뒤 임박만 매너 지표에 반영 (PM 결정, PD 시안과 같음)

**진입** 채팅 입력칸 + 메뉴에서 약속 취소를 누른다 (확정 약속이 있을 때). 확정 약속이 있는 방에서 나가기를 눌러도 들어온다 (E-09-1)

**동작**
1. 언제 취소하든 같은 확인 팝업 "약속을 취소할까요? 상대에게 바로 알려요" [닫기] [취소하기]를 띄운다.
   - 약속 1시간 안쪽에 취소할 때 뜨는 임박 취소 경고 팝업(E-08-1)은 P1이다.
2. [취소하기]를 누르면 바로 취소된다. 취소한 사람 · 임박 여부를 저장한다 (기록만 한다. 감점은 P1)
3. 글을 교환 가능으로 바꾼다 (B-08-1).
   - 약속에서 고른 첨부 글도 교환 가능으로 바꾼다.
   - 새 요청 · 약속을 다시 받는다.
4. 양쪽에 시스템 메시지가 올라간다 (내 화면 "약속이 취소됐어요", 상대 화면 "상대가 약속을 취소했어요").
   - 상대에게 알림을 보낸다.
   - 내 화면에는 토스트 "약속을 취소했어요"가 뜬다.
   - 상단 카드는 교환 가능으로 바뀐다.
5. 예약된 약속 전 알림 · 교환 확인 질문을 취소한다
6. 같은 글의 다른 채팅방에 "다시 약속을 잡을 수 있어요"를 남기고, 약속 잡기를 다시 쓸 수 있게 한다 (E-11-1).

**조건**
- 약속 취소는 이번 출시에 매너 지표에 영향이 없다 (임박 취소 감점은 P1).
- 상대 화면에는 임박 취소였는지 보여주지 않는다 (P1)
- 채팅방은 유지된다 (나가기로 취소한 경우 제외)
- 지금 교환 배지는 남은 시간이 있으면 다시 보인다 (B-04-1)

| 예외 상황 | 처리 |
|---|---|
| 이미 취소 · 완료된 약속 | "이미 처리된 약속이에요"라고 안내한 뒤 카드를 갱신한다 |
| 처리 실패 | 공통 오류를 보여준다 (P-07-03) |

**결과** 약속이 취소되고, 글은 교환 가능으로 돌아간다

### E-08-1 임박 취소 · 구제 신청

> 약속이 임박했을 때 취소하면 매너 지표 반영을 먼저 알리고, 합의한 취소였다면 사후에 구제를 신청할 수 있게 한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P1 | REQ-E-08 | P-07-01, P-01-01 | 2-02e |

- **예외 · 제약:**
  - 임박은 시간을 지정한 약속이면 1시간 전부터, "지금 바로" 약속이면 확정 순간부터다 (P-07-01).
  - 매너 지표 감점은 매너 지표 기능에서 정한다 (F-06-1).
- **비고:** v0.5.2 (10/29): 취소 요청 거절 · 무응답 뒤 경고하던 흐름을 없애고, 임박 시점에 약속 취소를 누르면 바로 이 팝업. 둘 다 취소를 원해도 누른 사람만 기록하고 사후 구제 (신고 화면은 상대 고발용이라 섞지 않음)

**진입** 임박 시점에 + 메뉴에서 약속 취소(E-07-1)를 누르거나, 확정 약속이 있는 방에서 나가기(E-09-1)를 누른다

**동작**
1. 팝업 "약속 1시간 전이에요. 지금 취소하면 매너 지표에 반영돼요" + "상대와 합의한 취소라면 취소 후 문의하기로 알려 주세요. 확인되면 반영하지 않아요" [약속 유지] [취소하기]를 띄운다.
2. [취소하기]를 누르면 E-07-1과 같이 취소하고 임박 취소로 기록한다.
3. 합의한 취소였다면 마이 > 문의하기(G-08-1)의 "임박 취소 구제 신청"에 사유를 적는다. 운영자가 관리자 페이지에서 확인한 뒤 기록을 삭제한다 (H-03-3).

**조건**
- 임박 시간에 둘 다 취소를 원해도 누른 사람만 기록한다. 억울하면 구제 신청을 한다.
- 상대 화면에는 임박 여부가 보이지 않는다
- 차단 · 탈퇴 · 이용 제한으로 인한 자동 취소, 약속 수정(E-03-2)은 반영하지 않는다

| 예외 상황 | 처리 |
|---|---|
| 이미 취소 · 완료된 약속 | "이미 처리된 약속이에요"라고 안내한 뒤 카드를 갱신한다 |

**결과** 약속이 취소되고, 임박 취소로 기록된다

### E-10-1 약속 제안 자동 만료

> 상대가 24시간 동안 수락하지 않은 약속 제안을 자동 만료한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P1 | REQ-E-10 | - | 2-02b, 2-02 예외 · 약속 제안 만료 |


- **예외 · 제약:**
  - 약속 시각이 24시간보다 먼저 오면 약속 시각에 만료된다.
  - 만료된 제안은 수락할 수 없다.

**진입** 시스템 처리 (스케줄)

**동작**
1. 제안 후 24시간 동안 수락이 없으면 만료된다.
2. 약속 시각이 그보다 먼저 오면 약속 시각에 만료된다.
3. 카드에 "만료됨"이 표시되고, 양쪽에 "응답이 없어 약속 제안이 만료됐어요"가 보인다.

**조건**
- 만료는 매너 지표에 반영하지 않는다.

| 예외 상황 | 처리 |
|---|---|
| 만료된 제안의 [수락] | "시간이 지나 만료된 약속이에요"라고 안내한다 |

**결과** 제안이 만료되고, 다시 제안할 수 있다

### E-11-1 예약중 약속 잡기 제한 · 취소 시 안내

> 글이 예약중이면 같은 글의 다른 채팅방에서 약속 잡기를 막고, 약속이 취소되면 열린 채팅방 모두에 안내하고 다시 연다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-E-11 | P-07-04 | 2-02, 2-02h |

- **예외 · 제약:**
  - 순번은 없다.
  - 먼저 약속을 확정한 사람이 우선이다 (선착순).
- **비고:** 10/16: 대기 걸기 삭제 (차례가 와도 교환을 보장하지 못함) · BE: 열린 방 전체 알림 가능 · 10/18: 확정 시 다른 방 약속 제안 자동 취소 (E-04-1) · v0.5.2 (10/31): 교환 완료 뒤에도 다른 방 대화 유지

**진입** 시스템 처리 (같은 글에 채팅방이 2개 이상일 때)

**동작**
1. 한 채팅방에서 약속이 확정되면(E-04-1) 같은 글의 다른 채팅방에서 + 메뉴의 약속 잡기를 막고 "다른 분과 약속이 잡혀 있어요" 시스템 메시지를 남긴다. 교환이 완료되거나(F-02-1) 교환글이 삭제돼도(B-07-2) 약속 잡기는 막힌다.
2. 대화는 계속할 수 있다
3. 확정된 약속이 취소되면(약속 취소 E-07-1 · 나가기 E-09-1 · 차단 C-09-2 · 탈퇴 G-09-2 · 이용 제한 P-05-01) 열린 채팅방 모두에 "다시 약속을 잡을 수 있어요" 시스템 메시지 + 알림을 보내고 약속 잡기를 다시 연다
4. 먼저 약속을 확정한 사람이 우선이다 (선착순).

**조건**
- 순번 · 대기는 없다.
- 3번의 알림은 게시자에게는 방이 여러 개여도 1개만, 요청자에게는 각 1개를 보낸다 (11/16)
- 다시 열 때 "열린 채팅방"은 같은 글에서 아직 나가지 않은 채팅방을 말한다.

| 예외 상황 | 처리 |
|---|---|
| 교환이 완료됨 | 다시 열지 않는다. 다른 채팅방은 대화가 유지되고 "다른 분과 교환이 완료됐어요"가 보인다 (F-02-1) |
| 비활성 중 약속 잡기를 누름 | 예약중이면 토스트 "다른 분과 약속이 잡혀 있어요"가 뜨고, 교환 완료면 "교환이 완료된 글이에요"가 뜬다 |

**결과** 예약중에는 약속이 1개만 유지된다. 취소되면 열린 채팅방 모두에서 다시 약속을 잡을 수 있다
