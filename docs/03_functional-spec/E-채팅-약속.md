### E-01-1 채팅 목록

> 내가 참여한 1:1 채팅방을 최근 메시지순으로 보여준다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-01 | P-07-03 | 2-01 |

- **예외 · 제약:** 채팅방은 수락으로만 생김 · 차단한 상대 방은 숨김

**진입** 하단 탭 채팅

**동작**
1. 최근 메시지 시각 내림차순
2. 항목: 상대 닉네임 · 교환글 대표 사진 · 마지막 메시지 1줄 · 시각 · 안 읽은 수 · 상태 배지(예약중 · 교환 완료)
3. 항목 → 채팅방(2-02), 안 읽은 수 초기화

**조건**
- 마지막 메시지가 사진이면 "사진", 시스템 메시지면 요약 문구
- 안 읽은 수 99 초과면 "99+"
- 교환이 끝난 방도 그대로 남긴다 (배지 "교환 완료")
- 내가 나간 방은 목록에서 지운다
- 상대가 나간 방은 남기고 "상대가 나갔어요" 표시

| 예외 상황 | 처리 |
|---|---|
| 0개 | "아직 대화가 없어요. 교환 요청이 수락되면 채팅이 열려요" + [교환글 둘러보기] |
| 불러오기 실패 | 공통 오류 (P-07-03) |

**결과** 채팅방 진입

### E-01-2 메시지 전송 (텍스트 · 사진 · + 메뉴)

> 텍스트와 사진을 주고받고, + 메뉴에서 사진 · 약속 잡기 · 장소 보내기를 연다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-01, REQ-N-09 | P-02-03, P-07-04 | 2-02, 2-02h |

- **예외 · 제약:** 예약중에도 대화 유지 · 같은 글이 다른 방에서 예약중이면 + 메뉴 약속 잡기 비활성 (E-11-1) · 교환 완료 후에도 당사자 방은 유지, 같은 글의 다른 방만 입력 종료
- **비고:** 외부 거래 표현 경고(C-08-1)는 2차 (10/20)

**진입** 채팅방(2-02) 입력창

**동작**
1. 텍스트 입력 후 전송, 상대에게 채팅 알림
2. +를 누르면 키보드 자리에 패널: 사진(B-01-2 재사용) / 약속 잡기(E-03-1) / 장소 보내기(E-02-1)
3. 텍스트는 외부 거래 표현 검사 (C-08-1)

**조건**
- 텍스트 1\~1,000자, 공백만은 전송 불가. 사진 1회 최대 5장
- 입력칸은 4줄까지 늘어나고 이후 스크롤
- 메시지는 실시간 전달 (REQ-N-09)
- 예약중이어도, 교환이 완료돼도 당사자 방은 대화 유지. 같은 글의 다른 방만 입력 종료 (F-02-1)
- 읽음 표시는 MVP 제외 (후순위)

| 예외 상황 | 처리 |
|---|---|
| 전송 실패 | 말풍선 옆 !, 누르면 [다시 보내기] / [삭제] |
| 다른 분과 교환이 완료된 글의 방 | 입력창 대신 "교환이 완료된 글이라 메시지를 보낼 수 없어요" |
| 상대가 나간 방 | 입력창 대신 "상대가 대화방을 나갔어요" |
| 차단한 상대 | 입력창 대신 "차단한 사용자와는 대화할 수 없어요" |

**결과** 말풍선 즉시 표시, 맨 아래로 스크롤

### E-01-3 상단 교환 카드 · 시스템 메시지

> 채팅방 위에 교환 대상과 글 상태를 고정하고, 교환 요청 · 약속 · 취소 · 완료 같은 진행 상황을 채팅 흐름에 카드로 남긴다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-01 | - | 2-02 |

- **예외 · 제약:** 시스템 메시지는 삭제할 수 없음
- **비고:** v0.4 (10/26): 첫 메시지 아이템 카드 · 입력창 위 [약속잡기]/[약속취소] · 약속 변경 제안 · 첨부 글 수정 카드 · 상단 바 매너 지표 2차. 상단 카드 상태 배지는 PD에 [제안] 중

**진입** 채팅방(2-02)

**동작**
1. 상단 카드: 교환글 대표 사진 · 제목 ↔ 첨부 아이템 요약 + 상태 배지. 확정 약속이 있으면 "10.10 (토) 오후 3:00 · 홍대입구역" 한 줄 (v0.3 그대로, 상태 배지 · 세부 표시는 PD 확인 중)
2. 상단 바: 상대 닉네임 · "교환 n회" (매너 지표는 2차, 프로필 사진 없음)
3. 입력창 위 버튼: 약속이 없으면 [약속잡기](E-03-1), 확정 약속이 있으면 [약속취소](E-07-1)
4. 진행 상황이 바뀌면 시스템 메시지 카드를 넣는다

| 이벤트 | 카드 · 버튼 |
|---|---|
| 교환 요청 (첫 메시지) | 아이템 카드: 첨부 아이템 한 줄씩(최대 5줄), 줄 탭 → 아이템 상세 (C-07-1 · C-07-2) |
| 약속 제안 ("교환을 제안해요") | 상대에게만 [수락하기] [거절] |
| 약속 확정 ("약속이 확정됐어요") | 시간 · 장소 · 교환해요 / 원해요. 카드 탭 → 약속 상세 [수정하기] (E-03-2) |
| 약속 변경 제안 | 상대에게만 [수락] [거절] |
| 첨부 글 · 아이템 수정 | "상대가 첨부한 글을 수정했어요 [보기]" / 요청받은 글이면 "글 내용이 수정됐어요 [보기]" |
| 취소 요청 | 상대에게만 [동의] [거절] (v0.3 그대로, PD 시안은 한 번에 취소 — 논의) |
| 약속 취소 · 제안 만료 | - |
| 교환 확인 질문 | [못 만났어요] [교환했어요] (F-01-1, 문구는 PD 시안과 맞출 예정) |
| 교환 완료 | "교환 성공!" 카드. [후기 남기기]는 2차 |
| 다른 분과 교환 완료 | - |
| 같은 글이 다른 방에서 예약중 ("다른 분과 약속이 잡혀 있어요") | - (약속잡기 비활성, E-11-1) |
| 앞 약속 취소 ("다시 약속을 잡을 수 있어요") | 입력창 위 [약속잡기] 다시 보임 |
| 교환글 · 첨부 글 삭제 | "교환글이 삭제됐어요" / 아이템 줄에 "삭제된 아이템" (B-07-2) |

**조건**
- 카드 버튼은 처리 뒤 결과로 바뀐다 (예: [수락하기] → "수락했어요")
- 첫 메시지 카드에 [약속 잡기] 버튼은 없다 (10/26, 입력창 위 버튼으로)

| 예외 상황 | 처리 |
|---|---|
| 이미 처리된 카드 버튼 | "이미 처리된 요청이에요" 안내 후 카드 갱신 |
| 교환글이 삭제됨 | 상단 카드 "삭제된 글이에요" |

**결과** 상단 카드 → 교환글 상세, 확정 약속 카드 → 약속 상세(시간 · 장소 · 교환할 물건 · [수정하기] · 내 알림 변경)

### E-02-1 장소 보내기 · 장소 카드

> 지도에서 장소를 골라 채팅에 장소 카드로 보낸다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P0 | REQ-E-02 | P-07-03 | 2-02i, 2-02j |

- **예외 · 제약:** 실시간 위치 공유 아님
- **비고:** 10/18: [지도에서 보기] 버튼 → 앱 안 지도 (PM)

**진입** 채팅방 + 메뉴 → 장소 보내기(2-02i)

**동작**
1. 기본 위치는 교환글 희망 장소
2. 지도 가운데 핀 · 검색 · ◎ 내 위치로 장소를 고른다. 거점 근처면 "홍대 거점" 표시
3. [이 장소 보내기] → 채팅에 장소 카드 (지도 썸네일 · 장소 이름 · [지도에서 보기])
4. [지도에서 보기] 버튼을 누르면 앱 안 지도(2-02j)로 장소 · 만날 곳 이름을 보여준다. 카드의 다른 곳을 눌러서는 열리지 않는다

**조건**
- ◎ 내 위치는 위치 권한 필요 (N-03-2)
- [제안] 가장 최근 장소 카드를 약속 잡기 장소 기본값으로

| 예외 상황 | 처리 |
|---|---|
| 검색 결과 없음 | "검색 결과가 없어요 · 지도를 움직여 골라 주세요" |
| 전송 실패 | 화면 유지, 공통 오류 (P-07-03) |

**결과** 채팅방에 장소 카드

### E-03-1 약속 제안

> 시간 · 장소 · 교환할 물건을 정해 약속을 제안한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-03 | - | 2-02b |

- **예외 · 제약:** 지난 시간으로 제안 불가 · 한 채팅방에 진행 중 제안 1개
- **비고:** v0.4 (10/26): '교환할 물건' 고르기 추가 (PD 시안 '원하는 물품 직접 입력' → 첨부 아이템 중 고르기) · 진입 = 입력창 위 [약속잡기]

**진입** 채팅 입력창 위 [약속잡기] 버튼 (약속이 없을 때 보임)

**동작**
1. 약속잡기 바텀시트

| 항목 | 필수 | 입력 방식 |
|---|---|---|
| 약속 시간 | 필수 | 지금 바로 / 날짜 · 시간(10분 단위). 지금 교환 글은 "지금 바로"가 기본 |
| 장소 | 필수 | 기본값 교환글 희망 장소, 목록 선택 또는 직접 입력 |
| 교환할 물건 | 필수 | 요청에 첨부된 아이템 중 고르기 (체크, 1개 이상). 첨부가 1개면 자동 선택 · 칸 숨김 |
| 약속 전 알림 | 선택 | E-06-1. "지금 바로"면 숨김 |

2. 시트 아래 주의사항 (알림 · 노쇼 안내, 문구 PD)
3. [교환 요청하기] → 채팅에 "교환을 제안해요" 카드(시간 · 장소 · 교환해요 / 원해요), 상대에게 알림

**조건**
- 날짜 범위 오늘\~7일 후
- 진행 중 제안은 한 채팅방에 1개. 새로 제안하려면 이전 제안을 취소
- 제안은 24시간 뒤 만료 (E-10-1)
- 교환할 물건: 요청에 여러 개를 첨부했으면 이 중 실제로 교환할 것을 고른다. 고른 물건이 확정 카드에 표시되고, 교환 완료 때 고른 아이템의 글만 교환 완료된다 (F-01-2)
- 고를 수 있는 건 아직 교환 가능한 첨부 아이템만 (다른 곳에서 예약중 · 교환 완료 · 삭제된 아이템 제외)

| 예외 상황 | 처리 |
|---|---|
| 지난 시각 | 선택 불가 안내 |
| 진행 중 제안 있음 | "이전 제안을 취소하고 새로 제안할까요?" |
| 글이 이미 예약중 | 약속 잡기 비활성 (E-11-1) |
| 고를 수 있는 첨부 아이템 0개 | "교환할 수 있는 아이템이 없어요" + 약속 제안 불가 |

**결과** 약속 제안 카드 표시

### E-03-2 약속 수락 · 확정 약속 수정

> 상대가 제안을 수락하면 확정되고, 확정 뒤에는 약속 상세에서 변경을 제안해 상대가 수락하면 바뀐다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-03 | - | 2-02b, 2-06 (추가 예정) |

- **예외 · 제약:** 제안자 본인은 수락 불가 · 변경은 상대 수락 시에만 반영 · 약속 시간이 지나면 수정 불가
- **비고:** v0.4 (10/26): 제안 단계 '수정 요청' 삭제 → 확정 약속 카드 탭 → 약속 상세 [수정하기] → 변경 제안 → 상대 수락 (PM)

**진입** "교환을 제안해요" 카드 [수락하기] · [거절] / 확정 약속 카드 탭 → 약속 상세 [수정하기]

**동작 — 제안 수락**
1. [수락하기] → 본인 약속 전 알림을 같이 정하고 확정 (E-04-1)
2. [거절] (PD 시안 [취소]) → 제안 무효, 제안자에게 알림. 다시 제안하려면 [약속잡기]

**동작 — 확정 약속 수정**
1. 확정 카드를 누르면 약속 상세(2-06): 시간 · 장소 · 교환할 물건 + [수정하기]
2. [수정하기] → 기존 값이 채워진 약속잡기 시트 → 고쳐서 보냄
3. 채팅에 "약속 변경을 제안해요" 카드 → 상대에게 [수락] [거절]
4. 수락하면 새 약속으로 바뀌고, 약속 전 알림(E-06-1)과 교환 확인 시점(F-01-1)을 새 시간 기준으로 다시 예약
5. 거절하거나 응답이 없으면 기존 약속 그대로

**조건**
- 제안자 본인은 자기 제안을 수락할 수 없다
- 수정은 양쪽 다 할 수 있다. 대기 중인 변경 제안은 1개
- 약속 시간이 지나면 수정할 수 없다 (교환 확인 단계로)
- [약속취소]는 약속 상세가 아니라 입력창 위 버튼 (E-07-1)
- 제안 단계의 "수정 요청"은 없다 (10/26). 바꾸려면 거절 후 다시 제안, 확정 뒤에는 [수정하기]

| 예외 상황 | 처리 |
|---|---|
| 제안이 만료 · 취소 · 새 제안으로 바뀜 | "더 이상 유효하지 않은 약속이에요" 안내 후 카드 갱신 |
| 약속 시각이 이미 지남 | "약속 시간이 지났어요. 새로 약속을 잡아주세요" |
| 수락 순간 다른 방에서 먼저 확정 | E-05-1 |

### E-04-1 약속 확정 · 예약중 전환

> 약속 요청을 수락하면 약속을 확정하고 글을 예약중으로 바꾸며, 같은 글의 다른 약속 요청 · 제안은 자동 거절하되 다른 채팅방 대화는 유지한다

- **비고:** 10/18: 약속 요청은 여러 채팅방에서 받을 수 있고, 하나를 수락하면 나머지 자동 거절 (PM). v0.4 (10/26): 약속에서 고른 첨부 글도 예약중 · 확정 카드 탭 → 약속 상세

**동작**
1. 글이 교환 가능인지 확인
2. 약속 확정 + 글 예약중 + 약속에서 고른 첨부 글도 예약중 + 알림 예약을 한 번에 처리 (10/26: 고른 첨부 글의 수정 · 삭제 · 다른 약속을 막기 위해)
3. 채팅방에 "약속이 확정됐어요" 카드(시간 · 장소 · 교환해요 / 원해요 · "약속 N분 전에 알려드릴게요"), 상단 배지 "예약중". 카드를 누르면 약속 상세(E-03-2), 입력창 위 버튼은 [약속취소]로 바뀜
4. 새 교환 요청을 막는다
5. 같은 글의 다른 채팅방은 대화 유지. 그 방에 진행 중인 약속 요청 · 제안은 자동 거절 · 취소하고 "다른 분과 약속이 확정돼서 보낸 약속 요청이 취소됐어요" 안내 + 알림 (P-07-04)

7. 현장 모드 글이면 현장 모드를 끈다. 약속이 취소돼도 다시 켜지지 않는다 (B-07-3)

| 예외 상황 | 처리 |
|---|---|
| 확정 순간 다른 방에서 먼저 확정 | E-05-1 |
| 처리 실패 | 약속 카드는 제안 상태 유지, 공통 오류 (P-07-03) |

**결과** 글 예약중, 약속 확정

**결과** 제안 만료, 다시 제안 가능

### E-11-1 예약중 약속 잡기 제한 · 취소 시 안내

> 글이 예약중이면 같은 글의 다른 채팅방에서 약속 잡기를 막고, 약속이 취소되면 열린 채팅방 모두에 안내하고 다시 연다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-E-11 | P-07-04 | 2-02, 2-02h |

- **예외 · 제약:** 순번 없음, 먼저 약속을 확정한 사람이 우선 (선착순)
- **비고:** 10/16: 대기 걸기 삭제 (차례가 와도 교환을 보장하지 못함) · BE: 열린 방 전체 알림 가능 · 10/18: 확정 시 다른 방 약속 요청 자동 거절 (E-04-1)

**진입** 시스템 처리 (같은 글에 채팅방이 2개 이상일 때)

**동작**
1. 한 채팅방에서 약속이 확정되면(E-04-1) 같은 글의 다른 채팅방에서 + 메뉴 · 카드의 약속 잡기를 비활성하고 "다른 분과 약속이 잡혀 있어요" 시스템 메시지를 남긴다
2. 대화는 계속할 수 있다
3. 확정된 약속이 취소되면(합의 취소 E-07-1 · 일방 취소 E-08-2 · 차단 자동 취소 C-09-2) 열린 채팅방 모두에 "다시 약속을 잡을 수 있어요" 시스템 메시지 + 알림을 보내고 약속 잡기를 다시 연다
4. 먼저 약속을 확정한 사람이 우선 (선착순)

**조건**
- 순번 · 대기 없음
- 다시 열 때 "열린 채팅방" = 같은 글에서 아직 나가지 않은 채팅방

| 예외 상황 | 처리 |
|---|---|
| 교환이 완료됨 | 다시 열지 않고 다른 채팅방 입력 종료 (F-02-1) |
| 비활성 중 약속 잡기를 누름 | "다른 분과 약속이 잡혀 있어요" 토스트 |

**결과** 예약중에는 약속 1개만 유지, 취소되면 열린 채팅방 모두 다시 약속 가능
