### F-01-1 교환 확인 질문

> 약속 30분 뒤 양쪽에 교환했는지 묻고, 한 명만 "교환했어요"라고 답해도 완료로 넘긴다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-F-01 | P-07-04, P-07-03 | 2-02, 2-02g |

- **예외 · 제약:** 응답이 엇갈리면 완료 우선 · 이의는 신고 · 문의로 따로 제기
- **비고:** 10/19: 버튼 "교환 못 했어요" → "못 만났어요" (PD 시안). v0.5.2 (10/29): [못 만났어요]는 각자 답 · 약속 시각이 지나면 약속 취소 대신 [못 만났어요] · 상단 카드 [교환했어요] 미리 보이기는 넣지 않음 (화면이 복잡해짐, PD 의견)

**진입** 약속 시각 30분 뒤 (시스템)

**동작**
1. 양쪽에 푸시 + 채팅방 카드 "교환 잘 하셨나요? 약속 시간이 30분 지났어요. 한 명만 답해도 처리돼요"
2. [교환했어요] → 교환 완료 처리(F-01-2)
3. [못 만났어요] → 이유 선택(F-04-1). 상대도 따로 자기 이유를 남긴다
4. 응답 없음 → 리마인드 · 자동 완료(F-03-1)

**조건**
- "교환했어요"는 한 명만 답해도 완료되고 상대 카드도 결과로 바뀐다
- "못 만났어요"는 먼저 답한 사람 기준으로 약속을 취소하고, 상대는 [이유 남기기]로 자기 이유를 따로 남긴다 (F-04-1)
- 응답은 1인 1회, 바꿀 수 없다
- 약속 시각이 지나면 + 메뉴 약속 취소는 안 되고 [못 만났어요]로만 정리한다
- 약속 전 알림을 꺼도 이 질문은 간다 (E-06-1)

| 예외 상황 | 처리 |
|---|---|
| 응답이 엇갈림 (교환했어요 vs 못 만났어요) | 완료로 처리하고 토스트로 알림. 내 [못 만났어요]는 처리되지 않음. 이의는 채팅방 신고 · 문의(G-08-1)로 |
| 상대가 먼저 "교환했어요" | 내 카드가 "교환이 완료됐어요"로 바뀜, [후기 남기기] (2차) |
| 상대가 먼저 "못 만났어요" | 내 카드가 "약속이 취소됐어요 [이유 남기기]"로 바뀜 (F-04-1) |
| 처리 실패 | 공통 오류 (P-07-03) |

**결과** 완료 또는 못 만남(이유 기록) 중 하나로 정리

### F-01-2 교환 완료 처리

> 교환글과 약속에서 고른 첨부 글을 교환 완료로 바꾸고, 완료 횟수를 올린다 (후기는 2차)

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-F-01, REQ-F-02 | P-01-01, P-07-02 | 2-02g |

- **예외 · 제약:** 사용자는 되돌릴 수 없음 (자동 완료만 운영자가 되돌림, H-03-4) · 약속 없이 만나 교환했으면 게시자가 [교환 완료로 바꾸기]로 완료 (G-02-1)
- **비고:** 매너 지표 반영 · 후기 요청은 2차 (10/20). v0.4 (10/26): 약속에서 고른 첨부 글만 완료 · 후기 화면은 PD가 '2차' 표시로 그려 둠. v0.5.2 (10/29~10/31): 약속 없이 교환한 경우 교환 완료로 바꾸기 · 완료 뒤 + 메뉴 사진만 · 다른 방 대화 유지

**진입** [교환했어요] → 완료 처리 시트 [완료하기] · 자동 완료(F-03-1) · 교환 완료로 바꾸기에서 상대 선택(G-02-1)

**동작**
1. 시트 안내 "한쪽만 확정해도 교환 완료 처리돼요 · 확정은 취소할 수 없어요" (문구 PD 시안)
2. 약속 · 교환글 · 약속에서 고른 첨부 글을 교환 완료로 한 번에 처리. 약속에서 고르지 않은 첨부 글은 교환 가능으로 남는다 (10/26). 새로 작성한 아이템은 글이 아니라 처리할 것 없음
3. 양쪽 교환 완료 횟수 +1, 매너 지표 반영
4. 같은 글의 다른 채팅방에 안내, 대화는 유지하고 약속 잡기만 막음 (F-02-1)
5. 교환 내역(5-07)에 기록, 상대에게 후기 요청 알림
6. 교환한 방의 + 메뉴는 사진만 남는다 (약속 잡기 · 장소 보내기 없음)

| 예외 상황 | 처리 |
|---|---|
| (고른 첨부 글은 약속 확정 때 예약중이 되므로 다른 곳 예약 충돌은 생기지 않음, E-04-1) 고르지 않은 첨부 글 | 영향 없음, 교환 가능 유지 |
| 처리 실패 | 응답은 저장하고 서버에서 다시 시도 [개발 확인] |

**결과** 응답한 사람 → 후기(2-03). 상대 채팅방 카드 "교환이 완료됐어요 [후기 남기기]"

### F-02-1 같은 글 다른 채팅방 안내

> 교환이 완료되면 같은 글의 다른 채팅방에 안내하고, 대화는 유지한 채 그 글로는 약속을 잡을 수 없게 한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-F-02 | - | 2-02 |

- **예외 · 제약:** 대화는 계속 가능 · 약속 잡기만 막힘
- **비고:** v0.5.2 (10/31): "다른 채팅방 입력 종료" → 대화 유지로 바꿈. 예약중일 때 다른 방 규칙(E-11-1, 대화 유지 · 약속 잡기만 비활성)과 같게, 다른 물건으로 교환 대화를 이어갈 수 있게, 잘못 자동 완료돼도 피해가 작게 (PM 결정)

**진입** 시스템 처리 (F-01-2 · 교환 완료로 바꾸기 G-02-1)

**동작**
1. 같은 글의 채팅방 중 교환한 방을 뺀 나머지에 시스템 메시지 "다른 분과 교환이 완료됐어요"
2. 상단 카드 배지를 교환 완료로 바꾼다
3. + 메뉴의 약속 잡기를 비활성. 누르면 토스트 "교환이 완료된 글이에요". 사진 보내기는 된다

**조건**
- 교환한 두 사람의 방도 완료 뒤 대화 유지 (하자 등 사후 연락). 교환 내역(5-07)에서도 들어갈 수 있다
- 다른 방은 채팅 목록에 그대로 남는다. 대화가 필요 없으면 각자 나간다

| 예외 상황 | 처리 |
|---|---|
| 화면이 바뀌기 전에 약속을 제안함 | 서버에서 거부, 토스트 "교환이 완료된 글이에요" |

**결과** 다른 채팅방은 대화 유지, 그 글로 약속 불가

### F-03-1 리마인드 · 자동 완료

> 양쪽 모두 답하지 않으면 24시간 뒤 리마인드하고, 3일 뒤 자동으로 교환 완료 처리한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-F-03 | P-01-01, P-07-04 | 2-02g |

- **예외 · 제약:** 한 명이라도 응답하면 대상 아님 · 노쇼 신고가 있으면 자동 완료 안 함 · 사용자 되돌리기 없음, 잘못 완료되면 문의하기 → 운영자가 되돌림
- **비고:** v0.5.2 (10/30~10/31): 자동 완료 하루 전 마지막 알림 추가. 사용자 되돌리기 버튼(7일)은 넣었다가 뺌 — 질문 · 리마인드 · 마지막 알림을 둘 다 무시해야 생기는 드문 경우라 운영자 처리로 충분 (PM 결정)

**진입** 시스템 처리 (스케줄)

**동작**
1. 교환 확인 질문 뒤 24시간 동안 양쪽 모두 답이 없으면 리마인드 "{닉네임}님과 교환 잘 하셨나요? 결과를 알려주세요" (푸시 + 알림 목록)
2. 질문 뒤 2일에 마지막 알림 "내일 자동으로 교환 완료돼요. 교환하지 않았다면 지금 알려주세요"
3. 3일 뒤에도 답이 없으면 자동 완료 (F-01-2와 같은 처리 + 자동 완료 표시), 양쪽에 알림
4. 채팅방에 자동 완료 카드 "응답이 없어 자동으로 완료됐어요. 교환하지 않았다면 마이 > 문의하기로 알려주세요"
5. 알림을 누르면 그 채팅방의 교환 확인 카드로

**조건**
- 자동 완료도 완료 횟수 · 글 상태에 똑같이 반영. 매너 지표에는 반영하지 않는다

| 예외 상황 | 처리 |
|---|---|
| 알림 전에 한쪽이 답함 | 리마인드 · 마지막 알림 보내지 않음 |
| 교환하지 않았는데 자동 완료됨 | 문의하기 → 운영자가 관리자 페이지에서 되돌림 (H-03-4) |
| 노쇼 신고가 접수돼 있음 | 자동 완료하지 않음 |

**결과** 자동 완료, 양쪽에 후기 요청

### F-04-1 못 만난 이유 (각자 답)

> [못 만났어요]를 누르면 이유를 고르고, 상대도 따로 자기 이유를 남긴다. 두 사람의 답을 맞춰 누가 안 나왔는지 판단한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-F-04 | P-01-01 | 2-02g |

- **예외 · 제약:** 서로 취소는 매너 지표 영향 없음 · 고른 이유는 상대에게 비공개 · 1차는 기록만, 매너 지표 반영은 2차
- **비고:** 10/19 PM·PD 회의 · PD 시안: 실패 사유 5개 (10/20 PM 확정). v0.5.2 (10/29): "제가 못 갔어요" 추가(6개) · 각자 답 · 이유 남기기 기한 3일. 노쇼한 본인이 먼저 "서로 취소"를 눌러 노쇼를 덮는 것을 막기 위해 (PM 결정)

**진입** 교환 확인 카드 [못 만났어요] · 상대가 먼저 [못 만났어요]로 답한 뒤 내 카드 [이유 남기기]

**동작**
1. 이유 선택 시트 (하나 선택)

| 이유 | 처리 |
|---|---|
| 상대가 연락 없이 안 나왔어요 | 기록 저장. 2차: 노쇼 신고로 이어짐 (F-04-2) |
| 제가 못 갔어요 | 기록 저장 (본인 기록) |
| 물품이 달라요 | 기록 저장. 운영자 확인 후 매너 지표 반영 |
| 금품을 요구했어요 | 기록 저장. 운영자 확인 후 매너 지표 반영 |
| 서로 약속을 취소했어요 | 확인 팝업 먼저 → 기록 저장, 매너 지표 영향 없음 |
| 직접 입력 (0\~100자) | 기록 저장. 운영자가 관리자 페이지에서 확인 |

2. 먼저 답한 사람 기준으로 약속 취소 · 글 교환 가능, 상대에게 "약속이 취소됐어요" 알림 (이유는 보이지 않음)
3. 상대 카드는 닫히지 않고 "약속이 취소됐어요 [이유 남기기]"로 바뀐다 → 상대도 같은 시트에서 자기 이유를 남긴다
4. 같은 글의 다른 채팅방에 "다시 약속을 잡을 수 있어요" (E-11-1)

**조건**
- 하나를 골라야 [다음] 활성
- 이유 남기기 기한 3일 (자동 완료와 같은 기준). 지나면 카드가 "이유를 남길 수 있는 기간이 지났어요"로 닫힌다. 리마인드 없음
- 상대가 끝까지 남기지 않으면 먼저 답한 사람의 답으로만 처리. 답이 없다는 것만으로 노쇼로 정하지 않는다
- 두 사람 답을 맞춰 누가 안 나왔는지 판단 (예: A "상대가 연락 없이 안 나왔어요" + B "제가 못 갔어요" → B 노쇼). 엇갈리면 운영자가 채팅 기록으로 확인 (P-01-01)
- 1차는 매너 지표가 없어서 기록만 남긴다. 기록은 2차 매너 지표 · 노쇼 처리에 쓴다

| 예외 상황 | 처리 |
|---|---|
| 상대가 이미 "교환했어요"로 답함 | 완료가 우선 (F-01-1) |

**결과** 약속 취소, 글 교환 가능, 두 사람의 이유 기록

### F-04-2 노쇼 신고

> 약속 장소에 오지 않은 상대를 신고하고, 노쇼 기록은 공개하지 않는다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P0 | REQ-F-04, REQ-N-02 | P-01-03, P-05-02, P-05-03 | 2-04 |

- **예외 · 제약:** 약속 시간 전 신고 불가 · 한 약속에 1회 · 노쇼 기록 비공개
- **비고:** v0.5.2 (10/29): 진입은 교환 확인에서만 (채팅방 신고 메뉴에는 노쇼 사유 없음). 처리는 관리자 페이지 (10/31)

**진입** 못 만난 이유 "상대가 연락 없이 안 나왔어요" → [다음] (F-04-1)

**동작**
1. 확인 "{닉네임}님을 노쇼로 신고할까요? 추가 설명은 상대에게 공개되지 않아요" + 추가 설명(선택, 0\~300자)
2. 신고를 접수하고 글을 교환 가능으로 되돌린다
3. 운영자가 관리자 페이지에서 하루 1회 확인 (H-02-2). 인정하면 노쇼한 사람 매너 지표 −10 + 본인에게만 알림 "노쇼로 기록됐어요. 이의가 있으면 문의하기로 알려주세요". 신고자에게는 결과를 알리지 않는다. 확인 전에는 반영 보류

**조건**
- 노쇼 횟수는 다른 사용자에게 공개하지 않음. 본인은 내 프로필에서 확인 (G-03-1)
- 상대 화면에는 "약속이 취소됐어요"만 보인다 (신고 · 이유 비공개)
- 노쇼 누적 제한: 90일 안 인정 2회 7일 · 3회 30일 (P-05-02). 운영자가 기준을 보고 관리자 페이지에서 적용, 자동 적용 없음
- 이의 제기(문의하기)가 받아들여지면 운영자가 인정 취소 → 매너 지표 복구 + 본인에게 "노쇼 기록이 취소됐어요" (H-03-1)
- 허위 신고로 판단되면 신고자 매너 지표 −10 (P-05-03)

| 예외 상황 | 처리 |
|---|---|
| 상대가 이미 "교환했어요"로 답함 | 완료가 우선 (F-01-1). 노쇼 주장은 문의(G-08-1)로 |
| 같은 약속 중복 신고 | "이미 신고했어요" 안내 |

**결과** 채팅방에 "노쇼 신고를 접수했어요 · 글이 다시 교환 가능으로 바뀌었어요"

> 교환 후 별로예요 / 좋아요 / 최고예요 중 하나로 후기를 남기거나 건너뛴다

|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P0 | REQ-F-05 | P-01-01, P-04-03 | 2-03 |

- **예외 · 제약:** 비공개 · 교환 1건당 1개 · 수정 · 삭제 불가
- **비고:** v0.5.2 (10/29): 3단계 확정 (별로예요 / 좋아요 / 최고예요)

**진입** "교환했어요" 직후 · 후기 요청 알림 · 채팅방 [후기 남기기] · 교환 내역 [후기 보내기]

**동작**
1. 3단계 중 하나를 고르면 [보내기] 활성, [건너뛰기]는 항상 가능
2. 저장하고 매너 지표에 반영

**조건**
- 후기는 상대에게 공개하지 않음. 받은 후기는 본인만 내 프로필에서 단계별 개수로 확인

- 작성 가능 기간 교환 완료 후 7일
- "별로예요" 이유 수집은 MVP 제외 (후순위)

| 기간 지남 | "후기 작성 기간이 지났어요" |

**결과** 토스트 "후기를 보냈어요"
