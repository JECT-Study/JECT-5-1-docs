### C-01-1 탐색 위치 설정 (지도에서 위치 고르기 · 내 위치 버튼)

> 홈 헤더에서 지도를 열어 위치를 고르면, 그 지점 주변 1km 교환글만 홈에 보여준다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-C-01 | P-03-01, P-03-02, P-03-04 | 1-01a, 1-15, 1-15a |

- **예외 · 제약:** 반경 1km 고정 · 설정 위치는 기기에만 저장(서버 저장 안 함) · 주소는 헤더 구 + 동, 리스트 위 · 지도 하단은 번지까지 (P-03-04)
- **비고:** v0.4 (10/26): 교환 지도 탭 삭제로 '내 위치 버튼'을 탐색 위치 설정으로 다시 씀 (PD 검색 위치 설정 시안 · 주석 답변 기준). v0.5 (10/27): 숫자 핀 탭 = 그 위치로 지도 이동(글 목록 없음) · 지도 하단 1줄 지번 + 2줄 도로명 · 리스트 위 번지까지 · 지도 칩을 홈에도 적용 (PD 시안 주석 답변)

**진입** 홈 헤더 "모든 지역 ▾"(위치를 정했으면 "마포구 동교동 ▾") → 드롭다운 [탐색 위치 설정하기]

**동작**
1. 헤더 드롭다운: 모든 지역에서 찾기 / 탐색 위치 설정하기 (체크 표시 없음)
2. [탐색 위치 설정하기] → 지도 화면(1-15). 가운데 고정 핀이 고를 위치를 가리키고, 지도를 움직여 위치를 고른다. 처음엔 가이드 문구 "지도를 움직여서 선택해보세요", 지도를 움직이면 사라지고 다시 나오지 않음
3. 지도 위
   - 장소 검색창: 누르면 장소 검색(B-03-1, 역 · 가게 · 주소) 결과 목록(1-15a) → 고르면 지도가 그 위치로 이동
   - 칩: [모든 교환글 ▾] (모든 교환글 / 지금 교환 / 일반 교환) — 지도를 열면 홈에서 고른 칩이 그대로 적용, 바꾸면 지도 숫자와 하단 글 수에 반영. [이 위치에서 찾기]를 누르면 지도에서 고른 칩이 홈에도 적용, [✕]로 닫으면 홈 칩은 그대로
   - 거점 칩: 홍대 · 용산 · 건대·성수 · 신도림 · 국전 → 누르면 그 거점 중심으로 지도 이동
   - 숫자 핀: 그 주변 교환글 수(대략). 확대해도 핀 모양은 그대로, 숫자로만 표시. 누르면 지도가 그 핀 위치로 이동해 가운데 핀이 그 자리에 놓이고, 하단 주소 · 글 수가 바뀐다. 글 목록은 띄우지 않는다 (목록은 [이 위치에서 찾기] 뒤 홈에서, 10/27)
   - 내 위치 버튼: 내 위치로 지도 이동, 내 위치는 동그라미로 표시
4. 하단: 가운데 핀 위치 주소 두 줄 (1줄 = 구 + 동 + 번지, 장소 검색으로 들어와 아직 지도를 안 움직였으면 검색한 장소 이름 / 2줄 = 도로명 주소) + "1km 주변 {칩} 교환글 n개" + [이 위치에서 찾기]
5. [이 위치에서 찾기] → 홈으로 돌아가 헤더가 "마포구 동교동 ▾", 리스트 위 "마포구 동교동 170-10 주변 1km · n개", 목록은 그 지점 1km 안 글만 (C-02-1)
6. [모든 지역에서 찾기] → 위치 해제, 헤더 "모든 지역 ▾", 전체 글

**조건**
- 반경은 1km 고정 (도보 15분, 서베이 근거). 거리는 가운데 핀 지점 ↔ 글의 희망 장소 좌표
- 주소 표시 (P-03-04): 홈 헤더 = 구 + 동 (마포구 동교동 ▾) / 리스트 위 = 구 + 동 + 번지 (마포구 동교동 170-10 주변 1km) / 지도 하단 = 1줄 지번(또는 검색한 장소 이름) · 2줄 도로명. 탐색 위치는 내 화면에만 보이고 서버에 저장하지 않는다. 동은 법정동 기준 [개발 확인]
- 지도에서 핀으로 건물명을 거꾸로 찾지 않는다 (근처 다른 건물 이름이 잡힐 수 있음). 이름은 장소 검색으로 고른 경우에만
- 설정한 위치는 기기에만 저장해 앱을 다시 켜도 유지. 서버에 저장하지 않음 (REQ-N-04). 재설치 · 기기 변경 시 "모든 지역"으로
- 지도 축소: 구 단위까지는 가까운 핀을 합쳐 숫자로 표시, 구보다 넓게 축소하면 숫자 핀을 숨기고 "지도를 확대하면 교환글 수를 볼 수 있어요" (정확한 줌 단계는 FE 확인)
- 숫자 · 글 수는 홈 목록과 같은 기준으로 센다 (교환 가능 · 예약중 글, 교환 완료 · 삭제 · 차단한 사용자 글 제외)
- 거점 칩 이동에는 거점별 중심 좌표가 필요 (P-03-01, 다각형과 함께 11/2 전달)

| 예외 상황 | 처리 |
|---|---|
| 위치 권한 없음 · OS 위치 꺼짐에서 내 위치 버튼 | 사전 안내 → OS 팝업 (N-03-2). 거부하면 "지도는 그대로 움직여서 고를 수 있어요" |
| 현재 위치를 못 가져옴 | "현재 위치를 찾을 수 없어요" |
| 1km 안 글 0개 | 하단 "1km 주변 교환글 0개", [이 위치에서 찾기]는 그대로 가능 |
| 번지 · 도로명을 못 가져옴 | 가져온 단위까지만 표시 (구 + 동 또는 구) |
| 장소 검색 결과 0건 | B-03-1과 같음 |

**결과** 홈 목록이 설정 위치 1km 안 글로 바뀌고 헤더에 위치 표시

**참고**
- v0.3까지는 교환 지도 탭의 "내 위치 버튼"이었다 (10/23 교환 지도 탭 삭제)
- "내 주변에서 찾기"(현재 위치 1km 바로 적용)는 넣지 않음 — 지도에서 내 위치 버튼으로 같은 일을 할 수 있어서 (10/26)

### C-02-1 홈 교환글 목록 · 카드

> 홈(첫 번째 탭)에서 교환글을 카드 목록으로 보여주고, 위치를 정했으면 그 주변 1km 글만 보여준다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-02 | P-07-03, P-03-04 | 1-01 |

- **1차에서 빠지는 부분:** 탐색 위치 줄 · 카드 ⋮ 지금 교환 끄기 · 교환 완료로 바꾸기
- **예외 · 제약:** 교환 완료 · 삭제 · 차단한 사용자 글은 보이지 않음 · 빈 화면은 이유별 안내
- **비고:** v0.4 (10/26): 교환 지도 탭 삭제로 홈이 첫 번째 탭 · 위치 필터 · 빈 화면 이유별 · 카드 ⋮. v0.5 (10/27): 리스트 위 줄은 번지까지 · 칩과 상관없이 표시 · 목록과 함께 스크롤, 카드 위치는 구 + 동, 지금 교환 배지는 교환 가능일 때만

**진입** 하단 첫 번째 탭 홈(1-01). 하단 탭은 홈 · 채팅 · 마이

**동작**
1. 헤더: 위치("모든 지역 ▾" 또는 "마포구 동교동 ▾", C-01-1) · 검색(C-03-1) · 알림(X-01-1)
2. 칩 줄: 맨 앞 [모든 교환글 ▾] 칩(고정, C-02-3) + 카테고리 칩. 리스트 위 오른쪽 [최신순 ▾] (C-02-2)
3. 위치를 정했으면 리스트 위에 "마포구 동교동 170-10 주변 1km · n개" (칩과 상관없이 표시, 개수는 고른 칩 기준). 리스트 위 줄([최신순 ▾] 포함)은 목록과 함께 스크롤되어 위로 사라진다
4. 교환 가능 · 예약중 글을 최신순으로 20개씩 불러온다. 위치를 정했으면 그 지점 1km 안 글만
5. 카드: 대표 사진 · 제목 · 위치(구 + 동, 예: 마포구 동교동) · 작성 시각 · 상태 배지 · 지금 교환 배지("지금 교환 · n분", 교환 가능일 때만) · 원하는 아이템 · ⋮
6. 카드 ⋮ (바텀시트)
   - 남의 글: 신고하기 (C-09-1)
   - 내 글: 수정하기(B-07-1) · 지금 교환 끄기(B-07-3, 지금 교환 글일 때만) · 교환 완료로 바꾸기(G-02-3, 교환 가능 글만) · 삭제하기(B-07-2). 예약중 글은 수정 비활성 "약속이 잡힌 글은 수정할 수 없어요" · 삭제 시 "약속을 먼저 취소해 주세요"
7. 아래로 당기면 새로고침, 끝까지 내리면 다음 20개. 위로 스크롤하면 헤더 · 칩 줄이 숨고, 아래로 스크롤하면 다시 보임. [+ 글쓰기]와 하단 탭은 항상 보임
8. 카드 → 교환글 상세(1-03), 오른쪽 아래 [+ 글쓰기] → 1-06

**조건**
- 교환 완료 · 삭제 글, 차단한 사용자의 글은 제외
- 첫 진입 기본값: 모든 지역 · 모든 교환글 · 최신순
- 카드 ⋮에 사용자 차단은 넣지 않음. 차단은 채팅방 ⋮ · 게시자 프로필 ⋮에서 (C-09-2, 10/26)

| 예외 상황 (빈 화면) | 문구 · 버튼 |
|---|---|
| 전체 0개 (모든 지역 · 모든 교환글) | "아직 등록된 교환글이 없어요" + [첫 교환글 올리기] |
| 지금 교환만 보는데 0개 | "지금 교환 중인 글이 없어요. 먼저 올려볼까요?" + [글쓰기] |
| 카테고리로 걸러 0개 | "조건에 맞는 교환글이 없어요" + [전체 보기] (카테고리 초기화) |
| 설정 위치 1km 안 0개 | "주변 1km에 교환글이 없어요" + [다른 위치 보기] (C-01-1) |
| 불러오기 실패 | 공통 오류 (P-07-03) + [다시 시도] |

- 여러 경우가 겹치면 위치 → 칩 순서로 안내. [+ 글쓰기]는 빈 화면에서도 유지

**결과** 카드 목록 표시

**참고**
- 예약중 글도 목록에 그대로 두고 "예약중" 배지를 붙인다
- v0.3까지 홈은 두 번째 탭이었다 (첫 번째 탭 교환 지도 삭제, 10/23)

### C-02-2 목록 정렬

> 리스트 위 [최신순 ▾]로 최신순 · 가까운순 · 인기순을 고른다 (1차는 최신순만)

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P2 | REQ-C-02 | P-03-02 | 1-01c |

- **예외 · 제약:** 가까운순 · 인기순은 2차 · 가까운순 기준점 = 설정 위치(모든 지역이면 내 위치)
- **비고:** 1차는 최신순만, 가까운순 · 인기순은 2차 (10/20 · 10/26 재확인). v0.4: 정렬을 칩 줄에서 빼 리스트 위 드롭다운으로, PD 시안 '인기' 칩 제외

**진입** 홈 리스트 위 오른쪽 [최신순 ▾]

**동작**
1. 누르면 드롭다운: 최신순 (기본) / 가까운순 (2차) / 인기순 (2차)
2. 고르면 목록을 다시 불러온다

| 정렬 | 기준 |
|---|---|
| 최신순 (기본) | 작성 시각. 모든 교환글은 지금 교환 · 일반 교환 글을 섞어 최신순 |
| 가까운순 (2차) | 위치를 정했으면 설정 위치, "모든 지역"이면 내 위치 ↔ 글의 희망 장소 거리 |
| 인기순 (2차) | 1순위 최근 7일 새로 생긴 채팅방(교환 요청) 수, 2순위 조회수 |

**조건**
- 1차 화면에서 가까운순 · 인기순은 "2차" 표시 (PD는 그려 두되 1차 개발 제외)
- 고른 정렬은 앱을 다시 켜도 유지
- 정렬은 칩 줄에 두지 않는다 (칩 = 거르기, 정렬 = 순서)

| 예외 상황 | 처리 |
|---|---|
| (2차) 모든 지역에서 가까운순인데 위치 권한 없음 | 가까운순 비활성 + "위치 권한이 필요해요" → 사전 안내 · OS 팝업 (N-03-2) |
| (2차) 희망 장소에 좌표 없는 글 | 가까운순에서 맨 뒤 |

**결과** 정렬된 목록

### C-02-3 교환 방식 · 카테고리 칩

> 홈 칩 줄의 [모든 교환글 ▾]과 카테고리 칩으로 목록을 거른다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-02 | P-03-01 | 1-01b, 1-02a |

- **1차에서 빠지는 부분:** 검색 결과 카테고리 필터 시트 1-02a (검색과 함께 P1)
- **예외 · 제약:** 교환 방식 · 카테고리 각각 하나만 · 거점 필터 없음
- **비고:** v0.4 (10/26): 거점 ▾ 필터 삭제(10/24 PD), 교환 방식 칩 추가, '애니메이션' → '캐릭터'(B-01-1과 통일)

**진입** 홈 칩 줄 / 검색 결과의 카테고리 ▾ → 필터 바텀시트(1-02a)

**동작**
1. 맨 앞 교환 방식 칩 [모든 교환글 ▾]: 누르면 드롭다운 모든 교환글 / 지금 교환 / 일반 교환. 고른 항목에 체크, 칩 이름이 고른 것으로 바뀐다. 옆으로 넘겨도 이 칩은 고정
2. 카테고리 칩: 캐릭터 / 아이돌(케이팝) / 스포츠 / 기타 중 하나를 누르면 바로 적용, 다시 누르면 해제
3. 검색 결과에서는 카테고리 ▾를 누르면 바텀시트, 고른 뒤 [적용] / [초기화]
4. 목록을 다시 불러온다

**조건**
- 첫 진입 기본: 모든 교환글 · 카테고리 전체

### C-05-1 교환글 상세 · 하단 버튼 상태

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-05 | - | 1-03, 1-03d |

- **1차에서 빠지는 부분:** 매너 지표 · 게시자 프로필 이동 · 전체 화면 지도 · 태그 · ⋮ 지금 교환 끄기 · 교환 완료로 바꾸기
- **예외 · 제약:** 삭제되었거나 차단한 사용자의 글은 볼 수 없음
- **비고:** v0.4 (10/26): 교환 개수 삭제 · 장소 메모 없음 · 지도 미리보기 + 탭 → 전체 화면 지도 · 요청 수 표시 · 버튼 이름 '교환 요청하기' · 매너 지표는 2차 표시. v0.5 (10/27): 교환장소 = 장소 이름(검색) 또는 번지(핀) · 장소 메모 다시 표시 · [지도 보기] 버튼 · 요청 0개 비활성 버튼 · 지금 교환 배지는 교환 가능일 때만 · 삭제된 글 안내 화면 (PD 시안 코멘트) v0.5.1 (10/28): [채팅으로 가기]는 채팅방으로 바로, [채팅 n개 보기]는 글별 채팅 목록(E-01-1)

**진입** 홈 목록 · 검색 · 알림 · 게시자 프로필의 교환글

2. 교환 장소: 장소 이름 한 줄 + 희망 장소 지도 미리보기 + 지도 아래 장소 메모
   - 장소 이름: 글 쓸 때 장소 검색으로 고른 경우 건물 · 가게 이름만 (예: 스타벅스 홍대동교점), 지도 핀만 옮긴 경우 구 + 동 + 번지 (예: 마포구 동교동 101-23). 도로명 주소는 쓰지 않는다
   - 장소 메모: 글 쓸 때 입력한 만날 곳 이름 (B-03-2, 예: AK플라자 주변, 협의 가능). 비어 있으면 줄을 숨긴다
   - 미리보기 오른쪽 아래 [지도 보기 ↗] 버튼 또는 지도를 누르면 전체 화면 지도(1-03d, 글 위치 핀 + 내 위치, 보기만 가능, 탐색 위치 설정 지도 재사용)

4. "요청 n · 조회 n" 표시 (요청 = 이 글로 열린 채팅방 중 상대가 나가지 않은 방 수, [채팅 n개 보기]의 n과 같다. 0이어도 표시). 조회수를 1 올린다 (인기순 2순위)
5. 스크롤해서 제목 영역을 넘으면 상단 바에 제목 · 지금 교환 · 위치 · 시간이 붙는다

2. 체크박스로 여러 개 선택 (최대 5개). 6개째를 누르면 토스트 "최대 5개까지 고를 수 있어요"
3. 하단 [다음] → 메시지 첨부 화면(1-04b): 고른 교환할 제품(사진 · 이름 · 작성 시각) + "함께 보낼 메세지 (선택)" 입력칸 → [교환 요청하기] → 전송(C-07-1)
   - 메시지는 첫 메시지 아이템 카드 바로 뒤에 일반 채팅 메시지로 보낸다. 원본 글 내용은 바꾸지 않는다 (10/26 PD S 안 ①). 0\~1,000자 (채팅 메시지와 같음, 10/31)
   - [편집] = 뒤로가기 (선택 화면으로)
4. 상단 [새로 작성] → 고른 글 선택이 풀리고 빈 교환폼으로 (방식 바꾸기)
5. [그만두기] → 교환글 상세

**동작 — 새로 작성하기 (교환폼 1-14)**

| 항목 | 필수 | 입력 방식 |
|---|---|---|
| 사진 | 필수 | 1\~5장, 첫 장이 대표 (B-01-2) |
| 제품명 | 필수 | 2\~40자 |
| 상품 상태 | 필수 | 미개봉 / 개봉 중 하나가 항상 선택된 상태 (처음 미개봉). 하자 칩 없음, 하자는 설명에 |
| 자세한 설명 | 선택 | 0\~1,000자 |

- 태그 없음 (요청 아이템은 검색 대상이 아님)
- 하단 [교환 요청하기]: 사진 1장 이상 + 제품명 입력 시 활성 → 전송(C-07-1). 빈 칸이 있는데 누르면 그 칸에 오류 표시 (B-06-1과 같은 방식)
- 제품명은 한 줄 고정. 제품명 40자 · 설명 1,000자에 닿으면 더 늘지 않고, 이어서 치면 마지막 글자가 새 글자로 바뀐다 (PD 시안)
- 금지어 · 외부 거래 경고는 2차 (P-02-04 · C-08-1)

**조건**
- 첨부는 원본 교환글과 연결한다. 데이터를 복사(스냅샷)해 두지 않는다 (10/25 PM 결정). 요청 카드 · 아이템 상세는 원본 글의 현재 정보를 보여준다
- 요청 화면에서 내 글 내용을 고칠 수 없다. 고치려면 원본 글을 수정하고(B-07-1, 약속 확정 전까지), 그러면 채팅방에 수정 안내가 간다. 요청 뒤에는 아이템 상세 ⋮ [수정하기]로 원본 글 수정 화면에 바로 갈 수 있다 (C-07-2)
- 고쳐서 보낼 정도로 다르면 [새로 작성]으로 요청한다. 이때 원본 글과 연결되지 않아 예약중 · 교환 완료가 자동으로 바뀌지 않는다
- 교환 완료 시 약속에서 고른 첨부 글만 교환 완료 (F-01-2). 고르지 않은 첨부 글은 교환 가능으로 남는다
- 새로 작성한 아이템은 교환글이 아니다. 해당 요청에만 붙고 홈 · 검색 · 내 글 목록에 나오지 않는다. 사진 · 제품명 · 상태 · 설명을 요청 데이터로 저장한다
- 같은 내 글을 여러 요청에 동시에 첨부할 수 있다 (P-07-02). 그 글이 다른 곳에서 예약중 · 교환 완료가 되면 다른 채팅방 카드에 "다른 교환이 진행 중인 아이템" · "교환 완료된 아이템"으로 표시

| 예외 상황 | 처리 |
|---|---|
| 교환 가능한 내 글 0개 | 시트를 건너뛰고 빈 교환폼 (C-06-1) |
| 고르는 사이 내 글이 예약중 · 삭제됨 | 전송 시 "선택한 글 중 요청할 수 없는 글이 있어요" 후 목록 새로고침 |
| 사진 0장 · 제품명 비어 있음 | [교환 요청하기] 비활성 |

**결과** 요청 전송 (C-07-1)

### C-07-1 요청 전송 · 채팅방 생성

> 요청을 보내면 바로 1:1 채팅방을 만들고 요청 아이템을 첫 메시지로 보여준다. 같은 글 · 같은 사람은 채팅방 1개

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-07, REQ-C-06 | P-07-03 | 1-03a, 2-02 |

- **예외 · 제약:** 같은 글 · 같은 사람 채팅방 1개 · 예약중 · 교환 완료 글에는 요청 불가
- **비고:** 10/19 PM·PD 회의: 수락 단계 삭제, 채팅방 생성을 이 기능에 합침. v0.4 (10/26): 아이템 카드 한 줄씩 · 첫 카드 [약속 잡기] 삭제 · 첨부 글 수정 알림. v0.5 (10/27): 함께 보낸 메시지 · 수정 · 삭제 자동 메시지 · 상단 카드 다시 계산 · 약속은 + 메뉴

**진입** 메시지 첨부 화면 [교환 요청하기] · 교환폼 [교환 요청하기] (C-06-2)

**동작**
1. 서버에서 글 상태 · 차단 관계 · 같은 글에 내 채팅방이 있는지 확인한다
2. 통과하면 요청 저장과 채팅방 생성을 한 번에 처리한다 (둘 중 하나만 성공하지 않게)
3. 채팅방 첫 메시지로 아이템 카드: 첨부 아이템이 1개면 큰 카드(사진 · 이름 · 짧은 설명 · [자세히 보기]), 여러 개면 카드 하나에 한 줄씩(사진 · 이름 · 짧은 설명, 최대 5줄). 줄을 누르면 아이템 상세(C-07-2). 함께 보낸 메시지가 있으면 카드 바로 뒤에 일반 메시지로
4. 채팅방 상단 고정 카드: 요청한 교환글 제목 + 제안 아이템 이름 (여러 개면 첫 메시지 카드 첫 줄 기준 "우사기 미니 피규어 외 1개". 아이템이 삭제되면 남은 아이템으로 다시 계산, 남은 게 없으면 "삭제된 아이템")
5. 게시자에게 교환 요청 알림 (지금 교환 글이면 반복 알림 D-02-1, 2차)
6. 요청자는 바로 그 채팅방으로 이동, 토스트 "{닉네임}님에게 교환 요청을 보냈어요"

**조건**
- 같은 글에 같은 사람의 채팅방은 1개
- 채팅방은 "방 + 참여자" 구조 (향후 그룹 채팅 대비)
- 게시자는 수락 없이 바로 대화할 수 있다. 원하지 않으면 채팅방 나가기 · 차단 (E-09-1)
- 요청 아이템은 원본 교환글과 연결 (C-06-2). 첨부된 글이 수정되면 수정한 사람 쪽 자동 메시지 "'아이템명'을 수정했어요 [보러가기]" + 상대 채팅 알림 (E-01-3 · B-07-1). 게시자가 요청받은 글을 수정해도 같다
- 첫 메시지 카드에 [약속 잡기] 버튼은 없다. 약속은 입력칸 + 메뉴 → 약속 잡기 (E-03-1)

| 예외 상황 | 처리 |
|---|---|
| 같은 글에 내 채팅방이 이미 있음 | 새로 만들지 않고 기존 방으로 이동 + "이미 대화 중인 글이에요" |
| 그사이 예약중 · 교환 완료 · 삭제 | "지금은 요청할 수 없는 글이에요" 안내 |
| 차단 관계 | 요청 불가 안내 |
| 첨부한 내 글이 삭제됨 | 카드의 그 줄에 "삭제된 아이템" + 지운 사람 쪽 자동 메시지 "'아이템명'을 삭제했어요" + 상단 카드 다시 계산 (B-07-2 · E-01-3). 다시 첨부하는 기능은 없다 (다른 물건은 채팅에서 사진으로) |
| 전송 · 생성 실패 | 입력 유지, 둘 다 되돌리고 공통 오류 (P-07-03) |

**결과** 채팅방 생성, 양쪽 채팅 목록에 추가. 첫 요청이고 알림이 꺼져 있으면 설정에서 켜도록 한 번 안내 (N-03-1)

### C-07-2 요청 아이템 상세

> 채팅방 아이템 카드를 누르면 요청 아이템의 사진 · 제품명 · 상태 · 설명을 보여준다 (내 교환글 첨부 · 새로 작성 모두 이 화면)

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-07 | P-07-02 | 2-05 |

- **예외 · 제약:** 요청자 · 게시자 같은 화면 · 내 교환글 첨부 · 새로 작성 같은 화면 · 수정은 약속 확정 전까지
- **비고:** v0.4 (10/26) 새 기능. v0.5 (10/27): 두 방식 화면 통일(4개 항목, 원본 연결 글만 [원본 글 보기]) · [수정하기] = 원본 글 수정 또는 이 아이템만 · 수정 자동 메시지 (PM · PD 주석 답변)

**진입** 채팅방 첫 메시지 아이템 카드의 줄 · [자세히 보기] (C-07-1)

**동작**
1. 사진(넘겨 보기, "1 / n") · 제목(제품명) · 상품 상태 배지 · 설명 4개만 보여준다. 카테고리 · 태그 · 원하는 아이템 · 희망 장소는 보여주지 않는다
2. 새로 작성한 아이템: 교환폼에 입력한 내용 (이 요청에만 저장)
3. 내 교환글을 첨부한 아이템: 원본 교환글에서 위 4개를 열 때마다 가져와 보여준다 (복사 없음, 원본을 고치면 바로 반영) + 하단 [원본 글 보기] → 교환글 상세(C-05-1). 새로 작성한 아이템에는 이 버튼이 없다
4. 사진을 누르면 이미지 크게 보기(X-02-1)
5. ⋮ 메뉴
   - 내 아이템 [수정하기]
     - 내 교환글 첨부: 원본 글 수정 화면(B-07-1)으로 바로 이동, 저장하면 이 화면으로 돌아오고 이 글이 첨부된 모든 채팅방에 반영
     - 새로 작성: 제품 정보 입력 화면(교환폼 재사용)에서 이 요청의 아이템만 수정
     - 둘 다 저장하면 수정한 사람 쪽 자동 메시지 "'아이템명'을 수정했어요 [보러가기]" + 상대 알림 (E-01-3)
   - 상대 아이템: 신고하기(공통 신고 화면) · 차단하기(확인 팝업 → 채팅 목록) (C-09-1 · C-09-2, 신고에 이 아이템이 첨부됨)

**조건**
- 요청자 · 게시자 같은 화면
- 아이템이 여러 개여도 누른 아이템만 보여준다 (아이템끼리 넘겨 보기 없음)
- 수정은 약속 확정 전까지만. 확정되면 약속에서 고른 첨부 글은 예약중이 되어 수정 불가(B-07-1), 새로 작성 아이템도 잠긴다. 약속에서 고르지 않은 첨부 글은 교환 가능이라 원본 수정 가능
- 내 교환글 첨부 아이템은 복사본이 없어 "이 채팅방에서만" 다르게 고칠 수 없다 (P-07-02)

| 예외 상황 | 처리 |
|---|---|
| 원본 글이 삭제된 아이템 | "삭제된 아이템이에요" 안내 후 채팅방으로 |
| 약속 확정 후 수정 시도 | [수정하기] 비활성 + "약속이 잡힌 뒤에는 수정할 수 없어요" |

**결과** 아이템 상세 표시

1. ⋮ 메뉴 (바텀시트): 홈 카드 · 교환글 상세는 신고하기만 / 게시자 프로필 · 요청 아이템 상세는 신고하기 · 이 사용자 차단하기 (10/26: 목록에서는 차단을 빼고 채팅 · 프로필에서만, PD 의견)
2. 신고 화면(새 화면 하나를 교환글 · 채팅방 · 아이템 상세 · 프로필 신고에 공통으로 사용)에서 사유를 고른다 (판매 · 구매 유도 / 외부 거래 / 부적절한 사진 · 내용 / 사기 의심 / 기타 직접 입력)
3. [신고하기] → 운영자가 관리자 페이지에서 하루 1회 확인 (H-02-1)

**조건**
- 신고자는 상대에게 공개하지 않음
- 신고한 사람에게 처리 결과는 알리지 않는다. 신고당한 사람은 글 삭제 · 경고 · 이용 제한 시 운영 안내 알림 (P-06-02 · P-05-05)
- 신고가 쌓여도 자동으로 숨기지 않는다. 운영자가 신고 수 많은 순으로 확인 (H-02-1, 10/31: 임시 숨김 삭제)
- 교환이 완료된 상대를 신고할 때(채팅방 E-09-1 · 교환 내역 G-04-1)는 "교환한 물품에 문제가 있어요 (하자 · 설명과 다름)" 사유를 추가로 보여준다

| 예외 상황 | 처리 |
|---|---|
| 이미 신고한 글 | "이미 신고했어요" 안내 |
| 기타 선택 · 내용 없음 | [신고하기] 비활성 |

**결과** 토스트 "신고를 접수했어요"

### C-09-2 사용자 차단

> 사용자를 차단하면 서로의 글 · 채팅이 보이지 않는다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-09 | P-07-03 | 2-02a, 2-05, 1-05 |
- **1차에서 빠지는 부분:** 게시자 프로필 ⋮ 차단 (프로필과 함께 P1)


- **예외 · 제약:** 예약중인 상대 차단 시 약속 자동 취소 (매너 지표 영향 없음)
- **비고:** v0.4 (10/26): 진입 경로를 채팅방 · 프로필 · 요청 아이템 상세로 좁힘 (PD 의견: 차단은 채팅에서 효용)

**진입** 채팅방 ⋮(E-09-1) · 게시자 프로필 ⋮(C-05-2) · 요청 아이템 상세 ⋮(C-07-2) → 차단. 홈 카드 · 교환글 상세 ⋮에는 없음 (10/26)

**동작**
1. 확인 팝업 "차단하면 서로의 글 · 채팅이 보이지 않아요"
2. 차단 → 홈 목록 · 검색 · 탐색 위치 설정 숫자에서 상대 글 제외, 내 목록에서 상대와의 채팅방 숨김, 상대는 내 글에 교환 요청 불가
3. 차단당한 쪽은 채팅방이 남고 입력창 대신 "대화할 수 없는 상대예요". 차단 사실은 상대에게 알리지 않는다 (10/29)
4. 예약중인 상대면 약속을 자동 취소하고(매너 지표 영향 없음) 상대에게는 "약속이 취소됐어요"만 알린다. 같은 글의 다른 채팅방은 약속 잡기를 다시 연다 (E-11-1)

**조건**
- 차단으로 인한 약속 취소는 매너 지표에 반영하지 않는다
- 해제는 마이페이지 차단 목록 (G-07-1)

| 예외 상황 | 처리 |
|---|---|
| 예약중인 상대 | 약속 자동 취소, 글은 교환 가능으로 (매너 지표 영향 없음) |
| 처리 실패 | 공통 오류 (P-07-03) |

**결과** 토스트 "차단했어요". 채팅방 · 채팅에서 연 아이템 상세에서 차단하면 채팅 목록으로 (채팅방이 숨겨져 돌아갈 곳이 없음), 프로필에서 차단하면 이전 화면
