### C-01-1 탐색 위치 설정 (지도에서 위치 고르기 · 내 위치 버튼)

> 홈 헤더에서 지도를 열어 위치를 고르면, 그 지점 주변 1km 교환글만 홈에 보여준다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-01 | P-03-01, P-03-02, P-03-04 | 1-01a, 1-15, 1-15a |

- **예외 · 제약:** 반경 1km 고정 · 설정 위치는 기기에만 저장(서버 저장 안 함) · 주소는 헤더 구 + 동, 리스트 위 · 지도 하단은 번지까지 (P-03-04)
- **비고:** v0.4 (10/26): 교환 지도 탭 삭제로 '내 위치 버튼'을 탐색 위치 설정으로 다시 씀 (PD 검색 위치 설정 시안 · 주석 답변 기준). v0.5 (10/27): 숫자 핀 탭 = 그 위치로 지도 이동(글 목록 없음) · 지도 하단 1줄 지번 + 2줄 도로명 · 리스트 위 번지까지 · 지도 칩을 홈에도 적용 (PD 시안 주석 답변)

**진입** 홈 헤더 "모든 지역 ▾"(위치를 정했으면 "마포구 동교동 ▾") → 드롭다운 [탐색 위치 설정하기]

**동작**
1. 헤더 드롭다운: 모든 지역에서 찾기 / 탐색 위치 설정하기 (체크 표시 없음)
2. [탐색 위치 설정하기] → 지도 화면(1-15). 가운데 고정 핀이 고를 위치를 가리키고, 지도를 움직여 위치를 고른다. 처음엔 가이드 문구 "지도를 움직여서 선택해보세요", 지도를 움직이면 사라지고 다시 나오지 않음
3. 지도 위
   - 장소 검색창: 누르면 장소 검색(B-03-1, 역 · 가게 · 주소) 결과 목록(1-15a) → 고르면 지도가 그 위치로 이동
   - 칩: 홈 칩 줄과 같은 칩(C-02-3) — 지도를 열면 홈에서 고른 칩이 그대로 적용, 바꾸면 지도 숫자와 하단 글 수에 반영. [이 위치에서 찾기]를 누르면 지도에서 고른 칩이 홈에도 적용, [✕]로 닫으면 홈 칩은 그대로. 지도에는 카테고리 칩이 없고, 홈에서 고른 카테고리를 지도 숫자 · 글 수에도 그대로 적용 (개발 전 확정)
   - 거점 칩: 홍대 · 용산 · 건대·성수 · 신도림 · 국전 → 누르면 그 거점 중심으로 지도 이동
   - 숫자 핀: 그 주변 교환글 수(대략). 확대해도 핀 모양은 그대로, 숫자로만 표시. 누르면 지도가 그 핀 위치로 이동해 가운데 핀이 그 자리에 놓이고, 하단 주소 · 글 수가 바뀐다. 글 목록은 띄우지 않는다 (목록은 [이 위치에서 찾기] 뒤 홈에서, 10/27)
   - 내 위치 버튼: 내 위치로 지도 이동, 내 위치는 동그라미로 표시
4. 하단: 가운데 핀 위치 주소 두 줄 (1줄 = 구 + 동 + 번지, 장소 검색으로 들어와 아직 지도를 안 움직였으면 검색한 장소 이름 / 2줄 = 도로명 주소) + "1km 주변 {칩} 교환글 n개" + [이 위치에서 찾기]
5. [이 위치에서 찾기] → 홈으로 돌아가 헤더가 "마포구 동교동 ▾", 리스트 위 "마포구 동교동 170-10 주변 1km · n개", 목록은 그 지점 1km 안 글만 (C-02-1)
6. [모든 지역에서 찾기] → 위치 해제, 헤더 "모든 지역 ▾", 전체 글

**조건**
- 반경은 1km 고정 (도보 15분, 서베이 근거). 거리는 가운데 핀 지점 ↔ 글의 희망 장소 좌표
- 주소 표시 (P-03-04): 홈 헤더 = 구 + 동 (마포구 동교동 ▾) / 리스트 위 = 구 + 동 + 번지 (마포구 동교동 170-10 주변 1km) / 지도 하단 = 1줄 지번(또는 검색한 장소 이름) · 2줄 도로명. 탐색 위치는 내 화면에만 보이고 서버에 저장하지 않는다. 동은 법정동 기준 [개발 확인]
- 지도에서 핀으로 건물명을 거꾸로 찾지 않는다 (근처 다른 건물 이름이 잡힐 수 있음). 이름은 장소 검색으로 고른 경우에만
- 설정한 위치는 기기에만 저장해 앱을 다시 켜도 유지. 서버에 저장하지 않음 (REQ-N-04). 재설치 · 기기 변경 시 "모든 지역"으로
- 지도 축소: 구 단위까지는 가까운 핀을 합쳐 숫자로 표시, 구보다 넓게 축소하면 숫자 핀을 숨기고 "지도를 확대하면 교환글 수를 볼 수 있어요" (정확한 줌 단계는 FE 확인)
- 숫자 · 글 수는 홈 목록과 같은 기준으로 센다 (교환 가능 글만, 예약중 · 교환 완료 · 삭제 · 차단한 사용자 글 제외)
- 거점 칩 이동에는 거점별 중심 좌표가 필요 (P-03-01, 다각형과 함께 11/2 전달)

| 예외 상황 | 처리 |
|---|---|
| 위치 권한 없음 · OS 위치 꺼짐에서 내 위치 버튼 | 사전 안내 → OS 팝업 (N-03-2). 거부하면 "지도는 그대로 움직여서 고를 수 있어요" |
| 현재 위치를 못 가져옴 | "현재 위치를 찾을 수 없어요" |
| 1km 안 글 0개 | 하단 "1km 주변 교환글 0개", [이 위치에서 찾기]는 그대로 가능 |
| 번지 · 도로명을 못 가져옴 | 가져온 단위까지만 표시 (구 + 동 또는 구) |
| 장소 검색 결과 0건 | B-03-1과 같음 |

**결과** 홈 목록이 설정 위치 1km 안 글로 바뀌고 헤더에 위치 표시

**참고**
- v0.3까지는 교환 지도 탭의 "내 위치 버튼"이었다 (10/23 교환 지도 탭 삭제)
- "내 주변에서 찾기"(현재 위치 1km 바로 적용)는 넣지 않음 — 지도에서 내 위치 버튼으로 같은 일을 할 수 있어서 (10/26)

### C-02-1 홈 교환글 목록 · 카드

> 홈(첫 번째 탭)에서 교환글을 카드 목록으로 보여주고, 위치를 정했으면 그 주변 1km 글만 보여준다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-02 | P-07-03, P-03-04 | 1-01 |

- **출시 후로 미루는 부분:** 카드 ⋮ 지금 교환 끄기 (B-07-3, P1)
- **예외 · 제약:**
  - 예약중 · 교환 완료 · 삭제된 글과 차단한 사용자의 글은 보이지 않는다.
  - 빈 화면에서는 이유에 따라 다른 안내를 보여준다.
- **비고:** v0.4 (10/26): 교환 지도 탭 삭제로 홈이 첫 번째 탭 · 위치 필터 · 빈 화면 이유별 · 카드 ⋮. v0.5 (10/27): 리스트 위 줄은 번지까지 · 칩과 상관없이 표시 · 목록과 함께 스크롤, 카드 위치는 구 + 동, 지금 교환 배지는 교환 가능일 때만

**진입** 하단 첫 번째 탭인 홈(1-01)으로 들어간다. 하단 탭은 홈 · 채팅 · 마이다.

**동작**
1. 헤더에는 위치("모든 지역 ▾" 또는 "마포구 동교동 ▾", C-01-1), 검색(C-03-1), 알림(X-01-1)이 있다.
   - 위치 ▾는 [논의] 위치
2. 칩 줄에는 [전체] (정렬 메뉴는 출시 후, C-02-2) · 지금 교환 · 일반 교환 · 캐릭터 · 아이돌 · 스포츠 · 기타 칩이 있다. 칩은 하나만 고를 수 있다 (C-02-3, 11/17).
3. 위치를 정했으면 리스트 위에 "마포구 동교동 170-10 주변 1km · n개" (칩과 상관없이 표시, 개수는 고른 칩 기준). 리스트 위 줄은 목록과 함께 스크롤되어 위로 사라진다
4. 교환 가능 글만 최신순으로 20개씩 불러온다.
   - 위치를 정했으면 그 지점 1km 안 글만.
   - 글이 예약중이 되면 목록에서 빠진다. 예약중 글은 교환 요청을 받을 수 없어서다 (11/17).
   - 약속이 취소돼 교환 가능으로 돌아오면 다시 보인다. 순서는 작성 시각 그대로다.
5. 카드에는 대표 사진 · 제품명 · 위치(구 + 동, 예: 마포구 동교동) · 작성 시각 · 배지 줄 · 원하는 아이템 · ⋮가 보인다.
   - 배지 줄은 [곧 만료](빨강), [지금 교환](보라) 순서로 놓인다.
   - "곧 만료"는 지금 교환이 끝나기 10분 전부터 보인다. 남은 분은 표시하지 않는다.
   - 예약중 글은 목록에 없으므로 예약중 배지도 없다 (11/17, PD 하이파이).
   - 제품명은 최대 2줄이고, 넘으면 말줄임표로 줄인다.
   - 작성 시각은 "n초 전 · n분 전 · n시간 전 · n일 전 · n주 전" 형식으로 보인다 (11/17, PD 하이파이).
   - 원하는 아이템은 최대 2줄이고, 넘으면 말줄임표로 줄인다.
   - 글 쓸 때 [아무거나 상관없어요]를 골랐으면 원하는 아이템이 회색 "아무거나"로 보인다 (11/17, PD 하이파이).
6. 카드 ⋮를 누르면 바텀시트가 열린다.
   - 남의 글이면 신고하기가 있다 (C-09-1).
   - 내 글이면 수정하기(B-07-1) · 삭제하기(B-07-2) · 교환 완료로 바꾸기(G-02-3)가 있다.
   - 지금 교환 끄기(B-07-3, 지금 교환 글일 때만)는 P1이다.
7. 목록은 스크롤에 따라 아래처럼 움직인다.
   - 아래로 당기면 새로고침한다.
   - 끝까지 내리면 다음 20개를 불러온다.
   - 위로 스크롤하면 헤더 · 칩 줄이 숨고, 아래로 스크롤하면 다시 보인다.
   - [+ 글쓰기]와 하단 탭은 항상 보인다.
8. 카드를 누르면 교환글 상세(1-03)로 간다. 오른쪽 아래 [+ 글쓰기]를 누르면 1-06으로 간다.

**조건**
- 예약중 · 교환 완료 · 삭제된 글과 차단한 사용자의 글은 목록에서 빠진다.
- 처음 들어오면 모든 지역과 첫 칩(전체 · 최신순)이 선택되어 있다.
- 카드 ⋮에는 사용자 차단을 넣지 않는다. 차단은 채팅방 ⋮ · 게시자 프로필 ⋮에서 한다 (C-09-2, 10/26).

| 예외 상황 (빈 화면) | 문구 · 버튼 |
|---|---|
| 전체 0개 (모든 지역 · 모든 교환글) | "아직 등록된 교환글이 없어요." / "교환글을 작성해 교환할 사람을 찾아보세요." + [첫 교환글 올리기] (글쓰기와 같음) |
| 지금 교환만 보는데 0개 | "지금 교환 중인 글이 없어요." / "먼저 올려볼까요?" + [글쓰기] |
| 일반 교환만 보는데 0개 | "일반 교환 중인 글이 없어요." / "먼저 올려볼까요?" + [글쓰기] (11/17, PD 하이파이) |
| 카테고리로 걸러 0개 | "조건에 맞는 교환글이 없어요" / "다른 조건의 교환글을 찾아보세요." + [전체 보기] (첫 칩으로) |
| 설정 위치 1km 안 0개 | "주변 1km에 교환글이 없어요" + [다른 위치 보기] (C-01-1) |
| 불러오기 실패 | 공통 오류 (P-07-03): "교환글을 불러오지 못했어요" / "잠시 후 다시 시도해 주세요" + [다시 시도]. 네트워크 없음은 "인터넷에 연결할 수 없어요." / "Wi-Fi 또는 모바일 데이터 연결 상태를 확인한 후 다시 시도해 주세요." + [다시 시도] |

- 여러 경우가 겹치면 위치 → 칩 순서로 안내한다. [+ 글쓰기]는 빈 화면에서도 보인다.

**결과** 카드 목록을 보여준다

**참고**
- 예약중 글은 목록에서 뺀다 (11/17 변경, 이전엔 목록에 두고 "예약중" 배지). 예약중 표시는 상세 · 내 교환글 · 채팅 상단에 남는다
- v0.3까지 홈은 두 번째 탭이었다 (첫 번째 탭 교환 지도 삭제, 10/23)

### C-02-2 목록 정렬

> 홈 목록은 최신순 하나로 보여준다. 이번 출시에는 정렬 메뉴가 없다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-02 | P-03-02 | 1-01c |

- **출시 후로 미루는 부분:** 정렬 메뉴 · 인기순 (11/23 PM: 정렬이 하나뿐이라 메뉴를 숨김). 가까운순은 [논의] 위치
- **예외 · 제약:**
  - (출시 후) 정렬은 첫 칩(전체)에서만 고를 수 있다.
  - 가까운순 기준점 = 내 위치 (탐색 위치를 정했으면 설정 위치)
- **비고:** 1차는 최신순만, 가까운순 · 인기순은 2차 (10/20 · 10/26 재확인) → 11/17: PD 하이파이대로 정렬을 첫 칩 [최신 ▾] 메뉴로 옮기고 세 정렬 모두 1차 (PM). v0.4: 정렬을 칩 줄에서 빼 리스트 위 드롭다운으로 했던 것은 이번에 되돌림

**진입** 홈에 처음 들어오거나, 홈 칩 줄 맨 앞 [전체] 칩을 누르면 들어온다.

**동작**
1. 첫 칩은 "전체"(모든 교환글) 칩이다. ▾ 메뉴는 없다 (이번 출시).
2. 홈 목록은 항상 최신순이다.
3. (출시 후) 정렬 메뉴를 다시 열면: 첫 칩 [최신 ▾] → 최신순 (기본) / 인기순 / 가까운순, 고르면 다른 칩 선택이 풀리고 그 순서로 다시 불러온다

**조건**

### C-05-1 교환글 상세 · 하단 버튼 상태

- **출시 후로 미루는 부분:** ⋮ 지금 교환 끄기 (B-07-3, P1)
- **예외 · 제약:** 삭제되었거나 차단한 사용자의 글은 볼 수 없다.

**진입** 홈 목록 · 검색 · 알림 · 게시자 프로필에서 교환글을 누르면 들어온다

**동작**

2. 교환 장소에는 장소 이름 한 줄, 희망 장소 지도 미리보기, 지도 아래 장소 메모가 보인다.
   - 글 쓸 때 장소 검색으로 골랐으면 장소 이름은 건물 · 가게 이름만 보인다 (예: 스타벅스 홍대동교점).
   - 글 쓸 때 지도 핀만 옮겼으면 장소 이름은 구 + 동 + 번지로 보인다 (예: 마포구 동교동 101-23).
   - 도로명 주소는 쓰지 않는다.
   - 장소 메모는 글 쓸 때 입력한 상세 주소다 (B-03-2, 예: AK플라자 주변, 협의 가능). 비어 있으면 줄을 숨긴다.
   - 미리보기 오른쪽 아래 [지도 보기 ↗] 버튼 또는 지도를 누르면 전체 화면 지도(1-03d, 글 위치 핀 + 내 위치, 보기만 가능, 탐색 위치 설정 지도 재사용)
3. 게시자 요약(닉네임 · 완료 횟수 · 매너 지표 F-06-1)을 누르면 프로필(C-05-2)로 간다.
4. "요청 n · 조회 n"이 보인다.
   - 요청 수는 이 글로 열린 채팅방 중 상대가 나가지 않은 방 수다. [채팅 n개 보기]의 n과 같다.
   - 요청 수가 0이어도 보인다.
   - 조회수는 계정 + 날짜당 1회 센다 (아래 조건).
5. 스크롤해서 제품명 영역을 넘으면 상단 바에 제품명 · 지금 교환 · 위치 · 시간이 붙는다.
6. 하단 버튼은 아래 표대로 바뀐다.

|---|---|
| 요청 안 함 · 교환 가능 | [교환 요청하기]. 누르면 방식 선택 시트(C-06-1)가 열린다 |
| 이미 이 글로 채팅 중 | [채팅으로 가기]. 누르면 목록을 거치지 않고 그 채팅방(2-02)으로 바로 간다. 글이 예약중 · 교환 완료여도 이 버튼이 먼저다 |

  - 약속이 취소돼 교환 가능으로 돌아왔을 때 시간이 남아 있으면 다시 보인다 (B-04-1).

  - 시간 · 분까지만 표시하고 초는 보이지 않는다 (초가 계속 줄면 정신없음).
  - 끝나기 10분 전부터 빨간색으로 보인다 (목록 "곧 만료" 배지와 같은 기준).
  - 시간이 끝나면 이 줄과 배지가 사라지고 일반 교환 글로 남는다 (B-04-1).

   - 아이템이 여러 개면 첫 아이템 카드의 이름 뒤에 "외 n개"를 붙인다 (예: "우사기 미니 피규어 외 1개").
   - 아이템이 삭제되면 남은 아이템으로 다시 표시한다.
   - 남은 아이템이 없으면 "삭제된 아이템"으로 보인다.
5. 게시자에게 교환 요청 알림을 보낸다. 지금 교환 글도 1번만 보낸다 (반복 알림 D-02-1은 P1).
6. 요청자는 바로 그 채팅방으로 이동하고, 토스트 "{닉네임}님에게 교환 요청을 보냈어요"가 뜬다.

**조건**
- 같은 글에 같은 사람의 채팅방은 1개만 만든다.
- 채팅방은 "방 + 참여자" 구조로 만든다 (나중의 그룹 채팅에 대비).
- 게시자는 수락 없이 바로 대화할 수 있다. 원하지 않으면 채팅방을 나가거나 차단할 수 있다 (E-09-1).
- 요청 아이템은 원본 교환글과 연결된다 (C-06-2).
  - 첨부된 글이 수정되면 수정한 사람 쪽 자동 메시지 "'아이템명'을 수정했어요 [보러가기]"가 올라가고, 상대에게 정보 변동 알림이 간다 (E-01-3 · B-07-1 · X-01-1).
  - 게시자가 요청받은 글을 수정해도 같다.
- 첫 메시지 카드에 [약속 잡기] 버튼은 없다. 약속은 입력칸의 + 메뉴에서 약속 잡기를 눌러 잡는다 (E-03-1).
- 교환 요청 푸시는 1개만 보낸다. 첫 아이템 카드는 새 메시지 알림을 따로 보내지 않는다 (11/16).

| 예외 상황 | 처리 |
|---|---|
| 같은 글에 내 채팅방이 이미 있음 | 새로 만들지 않고 기존 방으로 이동하고, "이미 대화 중인 글이에요"를 보여준다 |
| 그사이 예약중 · 교환 완료 · 삭제 | "지금은 요청할 수 없는 글이에요"라고 안내한다 |
| 차단 관계 | 요청할 수 없다고 안내한다 |
| 첨부한 내 글이 삭제됨 | 그 아이템 카드에 "삭제된 아이템"을 표시한다. 지운 사람 쪽 자동 메시지 "'아이템명'을 삭제했어요"가 올라가고, 상단 카드를 다시 계산한다 (B-07-2 · E-01-3). 다시 첨부하는 기능은 없다 (다른 물건은 채팅에서 사진으로) |
| 전송 · 생성 실패 | 입력한 내용은 그대로 둔다. 둘 다 되돌리고 공통 오류를 보여준다 (P-07-03) |

**결과** 채팅방이 만들어지고 양쪽 채팅 목록에 추가된다. 첫 요청이고 알림이 꺼져 있으면 설정에서 켜도록 한 번 안내한다 (N-03-1)

### C-07-2 요청 아이템 상세

> 채팅방 아이템 카드를 누르면 요청 아이템의 사진 · 제품명 · 상태 · 설명을 보여준다 (내 교환글 첨부 · 새로 작성 모두 이 화면)

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-07 | P-07-02 | 2-05 |

- **예외 · 제약:**
  - 요청자와 게시자는 같은 화면을 본다.
  - 내 교환글 첨부 아이템과 새로 작성한 아이템은 같은 화면을 쓴다.
  - 수정은 약속 확정 전까지만 할 수 있다.
- **비고:** v0.4 (10/26) 새 기능. v0.5 (10/27): 두 방식 화면 통일(4개 항목, 원본 연결 글만 [원본 글 보기] → 11/20 삭제) · [수정하기] = 원본 글 수정 또는 이 아이템만 · 수정 자동 메시지 (PM · PD 주석 답변)

**진입** 채팅방 첫 메시지의 아이템 카드를 누른다 (C-07-1)

**동작**
1. 사진(넘겨 보기, "1 / n") · 제품명 · 상품 상태 배지 · 설명 4개만 보여준다. 카테고리 · 태그 · 원하는 아이템 · 희망 장소는 보여주지 않는다.
2. 새로 작성한 아이템은 교환폼에 입력한 내용을 보여준다 (이 요청에만 저장된다).
3. 내 교환글을 첨부한 아이템은 화면을 열 때마다 원본 교환글에서 위 4개를 가져와 보여준다.
   - 복사본이 없으므로 원본을 고치면 바로 반영된다.
   - [원본 글 보기]는 없다 (11/20 삭제). 교환 판단에 필요한 4개는 이미 보이고, 원본 상세로 가면 상대 글에 거꾸로 요청이 생길 수 있어서다.
   - 상대가 궁금하면 채팅방 상단 닉네임을 눌러 프로필(C-05-2)로 간다.
4. 사진을 누르면 이미지 크게 보기(X-02-1)가 열린다.
5. ⋮ 메뉴는 누구의 아이템인지에 따라 다르다.
   - 내 아이템의 ⋮ 메뉴에는 [수정하기]가 있다.
     - 내 교환글을 첨부한 아이템이면 원본 글 수정 화면(B-07-1)으로 바로 간다. 저장하면 이 화면으로 돌아오고, 이 글이 첨부된 모든 채팅방에 반영된다.
     - 새로 작성한 아이템이면 제품 정보 입력 화면(교환폼 재사용)에서 이 요청의 아이템만 수정한다.
     - 둘 다 저장하면 수정한 사람 쪽 자동 메시지 "'아이템명'을 수정했어요 [보러가기]"가 올라가고, 상대에게 알림이 간다 (E-01-3).
   - 상대 아이템의 ⋮ 메뉴에는 [신고하기]와 [차단하기]가 있다.
     - [신고하기]를 누르면 공통 신고 화면으로 간다. 신고에는 이 아이템이 자동으로 붙는다 (C-09-1).
     - [차단하기]를 누르면 확인 팝업이 뜨고, 차단하면 채팅 목록으로 돌아간다 (C-09-2).

**조건**
- 요청자와 게시자는 같은 화면을 본다.
- 아이템이 여러 개여도 누른 아이템만 보여준다 (아이템끼리 넘겨 보기 없음).
- 수정은 약속 확정 전까지만 할 수 있다.
  - 확정되면 약속에서 고른 첨부 글은 예약중이 되어 수정할 수 없다(B-07-1).
  - 확정되면 새로 작성한 아이템도 잠긴다.
  - 약속에서 고르지 않은 첨부 글은 교환 가능 상태라 원본을 수정할 수 있다.
- 내 교환글 첨부 아이템은 복사본이 없어 "이 채팅방에서만" 다르게 고칠 수 없다 (P-07-02).

| 예외 상황 | 처리 |
|---|---|
| 원본 글이 삭제된 아이템 | "삭제된 아이템이에요"를 안내한 뒤 채팅방으로 돌아간다 |
| 약속 확정 후 수정 시도 | [수정하기]를 누를 수 없다(흐리게 보인다). "약속이 잡힌 뒤에는 수정할 수 없어요"를 보여준다 |

**결과** 아이템 상세를 보여준다

### C-08-1 외부 거래 표현 경고 (요청 · 채팅)

> 채팅에서 외부 거래 표현을 감지하면 전송은 하되 경고와 신고하기를 보여준다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P1 | REQ-C-08 | P-02-03, P-02-06, P-06-01 | 2-02 |


- **예외 · 제약:**
  - 전송은 막지 않는다.
  - 키워드로 감지한다.
- **비고:** 10/20: 2차 배포 (금지어와 같은 단어 목록). v0.5.2 (10/31): 보낸 사람에게도 경고 (본인도 모를 수 있음), 상단 고정 경고 없음 (PM 결정). 11/20: 함께 보낼 메시지 삭제로 검사 대상은 채팅만

**진입** 채팅에서 텍스트를 보내면 이 검사가 동작한다.

**동작**
1. 전송할 때 외부 거래 표현(오픈채팅 · 카톡 ID · 전화번호 · 계좌 · 송금 등)을 검사한다.
2. 표현이 감지되어도 메시지는 그대로 보낸다.
3. 보낸 사람 · 받은 사람 화면 모두 그 메시지 아래에 경고를 보여준다. 받은 사람에게는 [신고하기]도 보여준다.
4. [신고하기]를 누르면 사유가 "외부 거래"이고 해당 메시지가 첨부된 신고로 이어진다 (C-09-1).

**조건**
- 전송을 막지 않는 이유는 "어디서 샀어요" 같은 정상 문맥도 걸릴 수 있기 때문이다.
- 감지 키워드 · 패턴은 정책서 P-02-06 (외부 거래 분류)을 따른다.

| 예외 상황 | 처리 |
|---|---|
| 같은 상대가 여러 번 감지 | 메시지마다 경고를 보여준다. 상단 고정 경고는 없다 (쌓이면 신고로 처리한다) |

**결과** 메시지가 전송되고 그 아래에 경고가 보인다

### C-09-1 교환글 신고 (더보기 메뉴)

> 교환글 ⋮ 메뉴에서 사유를 골라 신고한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-09 | P-06-01, P-06-02, P-05-04 | 9-04, 1-01 · 1-03 ⋮ 메뉴 |


- **예외 · 제약:**
  - 같은 글은 두 번 신고할 수 없다.
  - 신고한 사람이 누구인지 공개하지 않는다.
- **비고:** v0.4 (10/26): 홈 카드 · 상세 ⋮는 신고하기만 (차단 제외). '이 글 숨기기'는 2차 이후 후보(C-10-1)

**진입** 홈 카드 · 교환글 상세 · 게시자 프로필 · 요청 아이템 상세의 ⋮ (9-04)에서 신고를 누른다

**동작**
1. ⋮를 누르면 바텀시트 메뉴가 열린다.
   - 홈 카드 · 교환글 상세에서는 신고하기만 있다.
   - 게시자 프로필 · 요청 아이템 상세에서는 신고하기 · 이 사용자 차단하기가 있다.
   - 목록에서는 차단을 빼고 채팅 · 프로필에서만 차단한다 (10/26, PD 의견).
2. 신고는 두 단계다. 먼저 사유 목록 화면 "신고하는 이유를 선택해주세요."에서 사유를 고른다.
   - 신고 화면은 교환글 · 채팅방 · 아이템 상세 · 프로필 신고에 공통으로 쓴다.
   - 사유는 판매 · 구매 유도 / 외부 거래 / 부적절한 사진 · 내용 / 사기 의심 / 기타 중에서 고른다.
3. 사유를 누르면 사유별 설명 화면으로 간다. 사유 이름 · 설명 · [신고하기]가 보인다.
   - 예: 판매 · 구매 유도는 "굿즈를 현금을 통해 구매하거나 판매하도록 유도하는 경우 신고해주세요."가 보인다.
   - 기타는 "신고 내용을 자유롭게 적어주세요."와 "상세 설명 (필수)" 칸("신고 내용을 입력해주세요.")이 보인다.
4. [신고하기]를 누르면 신고가 들어가고, 운영자가 관리자 페이지에서 하루 1회 확인한다 (H-02-1).

**조건**
- 신고한 사람이 누구인지 상대에게 공개하지 않는다.
- 신고한 사람에게 처리 결과는 알리지 않는다. 신고당한 사람에게는 글 삭제 · 경고 · 이용 제한이 있을 때 운영 안내 알림을 보낸다 (P-06-02 · P-05-05).
- 신고가 쌓여도 자동으로 숨기지 않는다. 운영자가 신고 수가 많은 순으로 확인한다 (H-02-1, 10/31: 임시 숨김 삭제).
- 교환이 완료된 상대를 신고할 때(채팅방 E-09-1 · 교환 내역 G-04-1)는 "교환한 물품에 문제가 있어요 (하자 · 설명과 다름)" 사유를 추가로 보여준다.

| 예외 상황 | 처리 |
|---|---|
| 이미 신고한 글 | 토스트 "이미 신고했어요."가 뜬다 |
| 기타를 골랐는데 내용을 입력하지 않음 | [신고하기]를 누를 수 없다(흐리게 보인다) |

**결과** 신고한 화면으로 돌아가고, 토스트 "신고를 완료했어요."가 뜬다

### C-09-2 사용자 차단

> 사용자를 차단하면 서로의 글 · 채팅이 보이지 않는다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-09 | P-07-03 | 2-02a, 2-05, 1-05 |


- **예외 · 제약:** 예약중인 상대를 차단하면 약속이 자동으로 취소된다 (매너 지표에는 영향이 없다).
- **비고:** v0.4 (10/26): 진입 경로를 채팅방 · 프로필 · 요청 아이템 상세로 좁힘 (PD 의견: 차단은 채팅에서 효용)

**진입** 채팅방 ⋮(E-09-1) · 게시자 프로필 ⋮(C-05-2) · 요청 아이템 상세 ⋮(C-07-2)에서 차단을 누른다. 홈 카드 · 교환글 상세 ⋮에는 없다 (10/26)

**동작**
1. 확인 팝업 "차단하면 서로의 글 · 채팅이 보이지 않아요"를 띄운다.
2. 차단하면 아래처럼 바뀐다.
   - 홈 목록 · 검색 · 탐색 위치 설정 숫자에서 상대 글 제외
   - 내 목록에서 상대와의 채팅방이 보이지 않는다.
   - 상대는 내 글에 교환 요청을 할 수 없다.
3. 차단당한 쪽은 채팅방이 남고, 입력창 대신 "대화할 수 없는 상대예요"가 보인다. 차단 사실은 상대에게 알리지 않는다 (10/29).
4. 예약중인 상대를 차단하면 약속을 자동으로 취소한다.
   - 매너 지표에는 영향이 없다.
   - 상대에게는 "약속이 취소됐어요"만 알린다.
   - 같은 글의 다른 채팅방에서는 약속 잡기를 다시 연다 (E-11-1).

**조건**
- 차단으로 인한 약속 취소는 매너 지표에 반영하지 않는다.
- 차단 해제는 마이페이지 설정의 "차단 사용자"에서 한다 (G-07-1).

| 예외 상황 | 처리 |
|---|---|
| 예약중인 상대 | 약속을 자동으로 취소하고, 글은 교환 가능으로 돌아간다 (매너 지표에는 영향이 없다) |
| 처리 실패 | 공통 오류를 보여준다 (P-07-03) |

**결과** 토스트 "차단했어요"가 뜬다. 채팅방이나 채팅에서 연 아이템 상세에서 차단하면 채팅 목록으로 간다 (채팅방이 숨겨져 돌아갈 곳이 없다). 프로필에서 차단하면 이전 화면으로 돌아간다
