### C-01-1 교환 지도 · 지도 보기 (거점 묶음 · 개별 핀 · 카테고리 필터)

> 현장 모드 글을 지도에 보여준다. 축소하면 거점별 "현장 N"으로 묶고, 확대할수록 개별 핀으로 나누며, 카테고리로 거른다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-01 | P-03-01, P-07-03 | 3-01 |

- **예외 · 제약:** 현장 모드가 끝난 글 · 예약중 글은 사라짐 · 위치는 희망 장소 기준
- **비고:** 10/16 이전안 확정 (FE 구현 가능) · 글이 많을 때 성능 [개발 확인]

**진입** 첫 번째 탭 교환 지도 → 상단 [지도 \| 리스트] 중 지도 (기본)

**동작**
1. 거점 5곳이 다 보이는 축척으로 시작한다
2. 현장 모드 시간이 남은 글만 불러온다
3. 축소하면 거점 반경 안의 글을 거점 마커 "{거점명} · 현장 N"으로 묶고, 확대할수록 개별 핀으로 나눈다. 반경 밖 글은 자기 핀 위치에 표시
4. 카테고리 ▾를 고르면 마커 숫자 · 핀을 다시 그린다
5. 거점 마커 → 그 거점으로 확대 [제안] / 핀 → 교환글 상세(1-03) / 같은 자리에 글이 여러 개(거점만 고른 글) → 숫자 묶음, 누르면 목록
6. ◎ 내 위치 버튼 → C-02-1

**조건**
- 위치 기준은 글의 희망 장소 (사용자 실제 위치 아님)
- 거점 반경 1km (P-03-01)
- 거점만 고르고 핀을 옮기지 않은 글은 거점 대표 좌표에 핀 (거점별 대표 출구 [개발 확인])
- 예약중이 된 글은 지도 · 리스트 보기에서 뺀다
- 지도 이동 · 확대가 멈추면 보이는 범위만 다시 불러오고 묶어서 표시 (글이 많으면 느려질 수 있음 [개발 확인])
- 필터는 지도 · 리스트 보기에서 공유, 교환글 리스트 탭 필터와는 따로

| 예외 상황 | 처리 |
|---|---|
| 거점 현장 글 0개 | 마커를 흐리게 "거점 · 현장 0" |
| 모든 거점 0개 | 지도 위 빈 상태 안내 + [글쓰기] → 1-06 |
| 카테고리 결과 0건 | "조건에 맞는 현장 글이 없어요" + [필터 초기화] |
| 누른 글이 그사이 현장 모드 종료 · 예약중 · 삭제 | "지금은 볼 수 없는 현장 글이에요" 안내 후 핀 제거 |
| 지도 로딩 실패 | [다시 시도] (P-07-03) |

**결과** 거점 마커 · 핀 표시

### C-01-2 교환 지도 · 리스트 보기

> [리스트]로 바꾸면 지도와 같은 현장 글을 목록으로 보여준다 (가까운순 [제안])

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-01 | P-03-01, P-07-03 | 3-02 |

- **예외 · 제약:** 예약중 글 제외 · 위치 권한이 없으면 최신순 [제안]
- **비고:** 10/16: 바텀시트 삭제 → 리스트 보기로 대체 (글이 많으면 시트 탐색 불편) · 화면 구성은 PD 하이파이

**진입** 교환 지도 상단 [리스트]

**동작**
1. 지도와 같은 현장 글(현장 모드 시간이 남은 글)을 목록으로 보여준다
2. 정렬은 가까운순 [제안]
3. 카드 → 교환글 상세(1-03)

**조건**
- 예약중 글은 보여주지 않는다
- [제안] 카드 구성: 사진 · 제목 · 남은 시간 · 원하는 아이템 · 거리 · ⋮ (옛 거점 시트 · 내 주변 카드 기준)
- [제안] 20개씩 불러오기
- [제안] 카테고리 필터는 지도 보기와 공유
- 화면 구성은 PD 하이파이에서 확정

| 예외 상황 | 처리 |
|---|---|
| 위치 권한 없음 | [제안] 최신순으로 보여주고 위치 켜기 안내 (N-03-2) |
| 0건 | "지금 현장 글이 없어요" + [글쓰기] |
| 불러오기 실패 | 공통 오류 (P-07-03) |

**결과** 현장 글 목록

### C-02-1 내 위치 버튼 · 위치 꺼짐 안내

> 내 위치 버튼을 누르면 내 위치 주변 1km가 보이게 지도를 옮기고, 이후 줌은 자유롭게 조절한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-02 | P-03-02 | 3-01 |

- **예외 · 제약:** 처음 1km · 줌 상한 없음 · 위치 거부 시 권한 안내 화면
- **비고:** 10/16: 탭 → 버튼, 줌 상한 없음 (FE)

**진입** 교환 지도 ◎ 내 위치 버튼

**동작**
1. 위치 권한이 없으면 사전 안내 → OS 팝업 (N-03-2)
2. 허용되면 내 위치를 가운데 두고 주변 1km가 보이게 지도를 옮긴다
3. 이후 사용자가 줌인 · 줌아웃하면 화면에 보이는 범위의 현장 글을 다시 불러온다 (C-01-1과 같은 방식)

**조건**
- 처음 보여주는 범위는 1km (도보 15분). 상한이 아니라 시작 범위이고, 줌 상한은 없다
- 예약중이 된 글은 보여주지 않는다
- 사용자 위치는 조회에만 쓰고 저장하지 않음 (REQ-N-04)

| 예외 상황 | 처리 |
|---|---|
| 위치 거부 · OS 위치 꺼짐 | "지도는 그대로 볼 수 있어요" 안내 + [위치 켜기] |
| 현재 위치를 못 가져옴 | "현재 위치를 찾을 수 없어요" |
| 내 주변에 현장 글 0건 | "근처에 지금 현장 글이 없어요 · 먼저 올려볼까요?" + [글쓰기] |

**결과** 지도가 내 위치로 이동. 설정에서 위치를 켜고 돌아오면 바로 내 위치로 이동

### C-03-1 교환글 목록 · 카드

> 교환글 리스트(두 번째 탭)에서 교환글을 카드 목록으로 보여준다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-03 | P-07-03 | 1-01 |

- **예외 · 제약:** 교환 완료 · 삭제 · 차단한 사용자 글은 보이지 않음

**진입** 하단 두 번째 탭 교환글 리스트(1-01)

**동작**
1. 교환 가능 · 예약중 글을 기본 최신순으로 20개씩 불러온다
2. 카드: 대표 사진 · 제목 · 원하는 아이템 · 희망 장소 · 작성 시각 · 상태 배지 · 현장 모드 배지(남은 시간)
3. 아래로 당기면 새로고침, 끝까지 내리면 다음 20개
4. 카드 → 교환글 상세(1-03), 오른쪽 아래 글쓰기 버튼 → 1-06

**조건**
- 교환 완료 · 삭제 글, 차단한 사용자의 글은 제외

| 예외 상황 | 처리 |
|---|---|
| 글 0건 | 빈 상태 안내 + [글쓰기] |
| 불러오기 실패 | 공통 오류 (P-07-03) |

**결과** 카드 목록 표시

**참고**
- 예약중 글도 목록에 그대로 두고 "예약중" 배지를 붙인다 (와이어프레임 1-01)

### C-03-3 카테고리 · 거점 필터

> 교환글 리스트 상단 카테고리 칩과 거점 ▾로 목록을 거른다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-03 | P-03-01 | 1-01, 1-02a |

- **예외 · 제약:** 카테고리 · 거점 각각 하나만 선택

**진입** 교환글 리스트 상단 카테고리 칩 · 거점 ▾ / 검색 결과의 카테고리 ▾ → 필터 바텀시트(1-02a)

**동작**
1. 교환글 리스트 상단 카테고리 칩: 전체 / 애니메이션 / 아이돌(케이팝) / 스포츠 / 기타 중 하나를 누르면 바로 적용
2. 거점 ▾: 거점 전체 / 홍대 / 용산 / 건대·성수 / 신도림 / 국전 중 하나
3. 검색 결과에서는 카테고리 ▾ · 거점 ▾를 누르면 바텀시트가 열리고, 고른 뒤 [적용] / [초기화]
4. 목록을 다시 불러온다

**조건**
- 카테고리 · 거점은 각각 하나만 선택 (전체 포함)
- 카테고리와 거점을 같이 고르면 둘 다 맞는 글만
- 거점 필터는 희망 장소가 그 거점으로 분류된 글만

| 예외 상황 | 처리 |
|---|---|
| 결과 0건 | "조건에 맞는 교환글이 없어요" + [필터 초기화] |

**결과** 필터가 적용된 목록

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |

**동작**

2. 제목과 태그를 정규화(띄어쓰기 · 대소문자 무시)해 검색어가 들어간 글을 찾는다
3. 기본 정확도순: ① 태그 정확히 일치 ② 제목 포함 ③ 태그 일부 포함, 같은 순위는 최신순. 정렬 변경: 정확도순 · 최신순 · 가까운순 · 인기순, 필터는 검색 후 필터 시트(1-02a)
4. 검색어를 최근 검색어에 저장 (C-05-1)

**조건**
- 검색어 2\~30자
- 교환 완료 · 삭제 · 차단한 사용자 글 제외

| 예외 상황 | 처리 |
|---|---|
| 1자 이하 | 검색 버튼 비활성 |
| 결과 0건 | "검색 결과가 없어요" + [위시리스트에 키워드 등록] (위시리스트 MVP 포함 시) |
| 검색 실패 | 공통 오류 (P-07-03) |

**결과** 검색 결과 목록

### C-06-1 교환글 상세 · 하단 버튼 상태

> 사진 · 템플릿 정보 · 태그를 보여주고, 내 관계에 따라 하단 버튼을 바꾼다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|

- **예외 · 제약:** 삭제되었거나 차단한 사용자의 글은 볼 수 없음

**진입** 목록 · 지도 · 검색 · 알림의 교환글

**동작**
1. 사진(넘겨 보기) · 제목 · 카테고리 · 상품 상태 · 원하는 아이템 · 교환 개수 · 희망 장소 · 설명 · 태그 · 작성 시각 · 상태 배지를 보여준다

3. 조회수를 1 올린다 (인기순 2순위)
4. 하단 버튼은 아래 표대로

| 상황 | 하단 버튼 |
|---|---|
| 요청 안 함 · 교환 가능 | [교환 요청하기] → 1-03a |
| 대기 중 요청 있음 | "요청 대기 중" (취소는 D-08-1) |
| 수락됨 | [채팅하기] → 2-02 |
| 거절됨 · 재요청 가능 | [다시 요청하기] (C-09-1) |
| 거절됨 · 재요청 불가 | "더 이상 요청할 수 없어요" (비활성) |
| 예약중 · 교환 완료 | 상태 표시 (비활성) |
| 내 글 | [받은 요청 n건 보기] → 5-05, ⋮ 수정 · 삭제 |

| 예외 상황 | 처리 |
|---|---|
| 삭제된 글 · 차단 관계 | "삭제되었거나 볼 수 없는 글이에요" 안내 후 이전 화면 |

**결과** 상세 표시

### C-07-1 교환 요청 작성

> 내 아이템을 첨부하고 조율 가능 여부 · 가능한 시간 · 메시지를 적어 교환을 요청한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-07 | P-02-03, P-02-04 | 1-03a |

- **예외 · 제약:** 첨부 아이템 없이 요청 불가 · 메시지 최대 100자

**진입** 교환글 상세 [교환 요청하기]

**동작**
1. 요청 화면 위에 받고 싶은 아이템(교환글 제목 · 교환 개수 · 거점)을 보여준다
2. 입력 항목

   | 항목 | 필수 | 입력 방식 |
   |---|---|---|
   | 내 아이템 첨부 | 필수 | 새 사진 첨부 / 내 교환글에서 선택, 여러 개 가능 (C-07-2) |
   | 조율 가능 | 선택 | 체크 "다른 조합도 괜찮아요" |
   | 가능한 시간 | 선택 | 칩: 지금 바로 / 오늘 / 날짜 협의 |
   | 메시지 | 선택 | 0\~100자 |

3. 첨부 아래 "이 글 1개 ↔ 내 아이템 N개" 요약. 게시자가 1:1만 원하는데 2개 이상 첨부하면 "게시자가 1:1 교환을 원해요. 채팅에서 조율할 수 있어요" 안내
4. [요청 보내기] → 전송(C-08-1)

**조건**
- 메시지는 외부 거래 표현 검사 대상 (C-10-1)

| 예외 상황 | 처리 |
|---|---|
| 첨부 0개 | [요청 보내기] 비활성 |
| 작성 중 닫기 | "작성한 내용이 사라져요" 확인 |

**결과** 요청 전송 (C-08-1)

### C-07-2 내 아이템 첨부 (내 교환글 · 새 사진)

> 이미 올린 내 교환글을 고르거나 새 사진을 찍어 요청에 첨부한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-07 | P-07-02, P-02-04 | 1-03a, 1-04 |

- **예외 · 제약:** 교환 가능 상태인 내 글만 선택 · 합계 최대 5개

**진입** 요청 작성 [내 교환글에서 고르기] · [새 사진 첨부]

**동작**
1. 내 교환글: 내 글 목록(1-04)에서 여러 개 체크 → [n개 첨부하기]. 사진 · 제목 · 상품 상태를 그대로 가져온다
2. 새 사진: 사진 선택(B-01-2) → 아이템 이름 입력 (필수, 금지어 검사 P-02-04). 비어 있으면 "아이템 이름을 입력해 주세요"와 함께 [요청 보내기] 비활성
3. 첨부 목록에 카드로 쌓인다

**조건**
- 교환 가능 상태인 내 글만 선택. 예약중 · 교환 완료 글은 보이되 선택 불가
- 첨부 합계 최대 5개 [제안]
- 교환이 완료되면 첨부한 내 글도 함께 교환 완료 (B-08-1)
- 같은 내 글을 여러 요청에 동시에 첨부할 수 있다. 그 글이 한 곳에서 예약중 · 교환 완료가 되면 다른 대기 요청의 첨부에서 자동으로 빠지고, 첨부가 0개 남은 요청은 자동 취소 (P-07-02)

| 예외 상황 | 처리 |
|---|---|
| 내 교환글 0개 | "올린 교환글이 없어요" + [새 사진으로 첨부하기] |
| 6개째 | 선택 불가 안내 |
| 고른 글이 그사이 예약중 · 삭제 | 전송 시 서버가 걸러 안내, 해당 항목 빼고 다시 확인 |

**결과** 요청 작성 화면 첨부 목록에 추가

### C-08-1 요청 전송 · 중복 요청 방지

> 요청을 보내고, 같은 글에 대기 중인 요청이 있으면 다시 보낼 수 없게 막는다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-08 | P-07-03 | 1-03a |

- **예외 · 제약:** 한 글에 대기 중 요청 1개 · 예약중 · 교환 완료 글에는 요청 불가

**진입** 요청 작성 [요청 보내기]

**동작**
1. 서버에서 글 상태 · 중복 · 차단 관계를 확인한다
2. 통과하면 요청을 "대기 중"으로 저장하고 게시자에게 알림 (현장 모드 글이면 반복 알림 D-05-1)
3. 상세 하단 버튼이 "요청 대기 중"으로 바뀐다

**조건**
- 같은 글에 대기 중 요청은 1개
- 대기 중 요청은 현장 모드 종료 또는 3일 무응답 시 만료 (D-07-1)

| 예외 상황 | 처리 |
|---|---|
| 이미 대기 중 요청 있음 | "이미 요청을 보냈어요" 안내 |
| 그사이 예약중 · 교환 완료 · 삭제 | "지금은 요청할 수 없는 글이에요" 안내 |
| 차단 관계 | 요청 불가 안내 |
| 전송 실패 | 입력 유지, 공통 오류 (P-07-03) |

**결과** 토스트 "교환을 요청했어요", 상세로 돌아감. 첫 요청이고 알림이 꺼져 있으면 알림 재요청 (N-03-1)

### C-09-1 재요청

> 거절된 요청을 같은 글에 1회 다시 보낸다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-09 | - | 1-03, 1-03a |

- **예외 · 제약:** "이미 교환했어요" 거절은 재요청 불가 · 재요청이 다시 거절되면 더 이상 불가

**진입** 교환글 상세 [다시 요청하기] · 거절 알림 · 보낸 요청(5-06)

**동작**

2. 보내면 게시자 요청 카드에 "재요청" 표시

**조건**
- 글당 재요청 1회
- 거절 사유가 "이미 교환했어요"면 재요청 불가

| 예외 상황 | 처리 |

**결과** 요청 전송 (C-08-1)

### C-11-1 교환글 신고 (더보기 메뉴)
