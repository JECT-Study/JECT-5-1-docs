### H-01-1 운영자 로그인

> 개발이 만들어 준 운영자 계정으로 로그인한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-01 | P-06-02 | H-01 |

- **예외 · 제약:** 회원가입 없음 · 앱 사용자 계정으로는 로그인 불가

**진입** 관리자 페이지 주소

**동작**
1. 아이디 · 비밀번호 입력 → [로그인] → 신고 처리(H-02)
2. 상단 오른쪽 계정 이름 · [로그아웃] → 이 화면

**조건**
- 운영자 계정은 개발이 만들어 준다. 운영자 1명당 계정 1개 (PM 2명 → 2개). 처리 기록에 계정 이름이 남는다
- 메뉴: 신고 처리 · 사용자 · 금지어

| 예외 상황 | 처리 |
|---|---|
| 아이디 또는 비밀번호가 틀림 | 입력칸 아래 "아이디 또는 비밀번호가 맞지 않아요" |
| 로그인하지 않고 다른 화면 주소로 들어옴 | 이 화면으로 |

**결과** 신고 처리 화면

### H-02-1 신고 처리

> 글 · 채팅 · 아이템 · 프로필 신고를 확인하고 글 삭제 · 경고 기록 · 신고 기각으로 처리한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-02 | P-05-04, P-06-01, P-06-02 | H-02 |

- **예외 · 제약:** 신고한 사람에게는 결과를 알리지 않음 · 지운 글은 되돌리지 않음 · 채팅 메시지는 지우지 않음 (신고 증거)

**진입** 메뉴 신고 처리 → 탭 [신고]

**동작**
1. 칩: 처리 전 / 처리 완료. 같은 대상의 신고는 한 줄로 묶고 신고 수가 많은 순
2. 줄: 대상(글 · 채팅 · 아이템 · 프로필) · 내용 · 신고당한 사람 · 사유 · 신고 수 · 접수 시각
3. 줄을 누르면 오른쪽에 상세: 대상 미리보기(글 · 아이템은 사진 · 제목 · 상태, 채팅은 신고된 대화) · 신고 사유와 내용 · 이 사람의 위반 기록. 신고당한 사람 이름 → 사용자(H-03-1)
4. 글 신고: [글 삭제] → 확인 팝업 → 삭제 + 위반 경고 1회 + 게시자에게 "운영 정책 위반으로 글이 삭제됐어요" / [신고 기각]
5. 채팅 · 아이템 · 프로필 신고: [경고 기록] → 위반 경고 1회 + 본인에게 "운영 정책 위반으로 경고를 받았어요. 3회가 되면 이용이 정지돼요" / [신고 기각]
6. 처리하면 같은 대상의 신고가 모두 처리 완료로 옮겨진다. 처리한 계정 · 시각 · 결과가 기록된다
7. 처리 완료 칩: 대상 · 내용 · 신고당한 사람 · 결과 · 처리한 계정 · 처리 시각

**조건**
- 운영자가 하루 1회 확인 (REQ-N-06)
- 경고 기준: 2회 7일 이용 제한 · 3회 영구 정지 (P-05-04). 제한은 자동으로 걸리지 않는다. 기준에 닿으면 삭제 확인 팝업 · 상세에 알려주고, 운영자가 사용자 화면(H-03-2)에서 적용
- 대화는 신고된 채팅방 것만 볼 수 있다 (개인정보 처리방침에 명시)
- 글 삭제 시 예약중이던 약속은 취소되고 상대에게 "약속이 취소됐어요". 이 글로 열린 채팅방에는 "교환글이 삭제됐어요" (B-07-2와 같음)

| 예외 상황 | 처리 |
|---|---|
| 처리할 신고 없음 | "처리할 신고가 없어요" |
| 다른 운영자가 먼저 처리함 | "이미 처리된 신고예요" + 목록 새로고침 |
| 그사이 글이 이미 삭제됨 | [글 삭제] 대신 "이미 삭제된 글이에요" |
| 처리 실패 | 공통 오류 (P-07-03) |

**결과** 신고 처리 완료, 필요하면 본인에게 운영 안내 알림 (X-01-1)

### H-02-2 노쇼 신고 처리

> 노쇼 신고를 약속 정보 · 두 사람의 답 · 채팅 기록으로 확인하고 인정 · 기각 · 허위 신고로 처리한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-02, REQ-F-04 | P-01-03, P-05-02, P-05-03 | H-02 |

- **예외 · 제약:** 신고한 사람에게는 결과를 알리지 않음 · 노쇼 판단을 위해 그 약속의 채팅방 대화만 볼 수 있음

**진입** 메뉴 신고 처리 → 탭 [노쇼 신고]

**동작**
1. 줄: 약속 일시 · 장소 · 신고한 사람 · 신고당한 사람 · 상대 답 · 접수 시각
2. 상세: 약속 정보 · 두 사람의 답(F-04-1) · 90일 안 인정된 노쇼 횟수 · 채팅 기록
3. [노쇼 인정] → 노쇼한 사람 매너 지표 −10 + 본인에게만 알림 "노쇼로 기록됐어요. 이의가 있으면 문의하기로 알려주세요"
4. [기각] → 처리 완료
5. [허위 신고] → 신고자 매너 지표 −10

**조건**
- 노쇼 누적 기준: 90일 안 인정 2회 7일 · 3회 30일 제한 (P-05-02). 기준에 닿으면 상세에 표시하고 운영자가 H-03-2에서 적용
- 허위 신고가 반복되면 노쇼 누적과 같은 제한 (P-05-03)
- 처리한 계정 · 시각 · 결과 기록

| 예외 상황 | 처리 |
|---|---|
| 상대가 이미 "교환했어요"로 답한 약속 | 교환 완료가 우선, [기각] |
| 다른 운영자가 먼저 처리함 | "이미 처리된 신고예요" + 목록 새로고침 |

**결과** 노쇼 신고 처리 완료

### H-03-1 사용자 조회 · 기록 정리

> 닉네임으로 사용자를 찾아 위반 기록을 보고, 문의로 받은 일(이의 제기 · 구제 신청 · 잘못된 자동 완료)을 처리한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-03 | P-01-04, P-05-01, P-06-03 | H-03 |

- **예외 · 제약:** 문의는 여기서 받지 않음 (외부 폼 · 이메일). 답은 이메일로 · 지운 글은 되돌리지 않음

**진입** 메뉴 사용자 · 신고 처리 상세의 사람 이름

**동작**
1. 닉네임 검색 → 사용자 상세
2. 요약: 닉네임 · 이용 상태(정상 / 제한 중 해제일 / 영구 정지) · 가입일 · 교환 완료 횟수 · 매너 지표 · 위반 기록(90일 안 인정 노쇼 · 경고 · 허위 신고 횟수). 기준에 닿았으면 "노쇼 누적 7일 제한 기준에 해당해요"처럼 표시
3. [이용 제한] → 이용 제한 팝업(H-03-2). 제한 중이면 [제한 해제] → 바로 해제
4. 탭: 교환 내역 / 임박 취소 기록 / 노쇼 기록 / 받은 신고
5. 교환 내역의 자동 완료 건 [되돌리기] → H-03-4
6. 임박 취소 기록 [기록 삭제] → H-03-3
7. 노쇼 기록의 인정 건 [인정 취소], 받은 신고의 경고 [경고 취소] → 기록과 매너 지표를 원래대로 (이의를 받아들였을 때, P-01-04)

**조건**
- 취소 · 해제하면 본인에게 알림: "노쇼 기록이 취소됐어요" · "경고가 취소됐어요" · "이용 제한이 해제됐어요"
- 되돌릴 수 있는 것: 경고 · 노쇼 인정 · 이용 제한 · 자동 완료. 지운 글은 되돌리지 않는다 (사용자가 다시 올리면 됨)
- 모든 처리는 처리한 계정 · 시각과 함께 기록

| 예외 상황 | 처리 |
|---|---|
| 검색 결과 없음 | "찾는 사용자가 없어요" |
| 탈퇴한 사용자 | 기록만 보이고 처리 버튼 없음 |

**결과** 사용자 기록 갱신

### H-03-2 이용 제한 적용

> 기간과 사유를 골라 이용 제한을 건다. 기준을 보고 운영자가 적용하며 자동 적용은 없다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-03, REQ-F-07 | P-05-01, P-05-02, P-05-03, P-05-04, P-05-05 | H-03 |

- **예외 · 제약:** 자동 적용 없음 · 기간을 더하지 않음

**진입** 사용자 상세 [이용 제한]

**동작**
1. 팝업: 기간(7일 · 30일 · 영구 정지) · 사유(노쇼 누적 · 외부 거래 · 판매 · 금지어 반복 · 허위 신고 · 기타) · 메모(운영자만 봄) · 기준표
2. [적용] → 제한 시작, 본인에게 사유 · 해제일 알림. 상세 상태가 "7일 제한 중 (해제일)"로

**조건**
- 기준: 노쇼 90일 안 인정 2회 7일 · 3회 30일 / 외부 거래 · 판매 · 금지어 1회 경고 · 2회 7일 · 3회 영구 정지 / 허위 신고 반복은 노쇼와 같음
- 제한 중에는 보기만 가능: 교환글 작성 · 교환 요청 · 메시지 · 약속 모두 막힘 (P-05-01)
- 잡혀 있던 약속은 자동 취소, 상대에게 "약속이 취소됐어요" (상대 매너 지표 영향 없음)
- 상대 채팅방 입력창은 "지금은 대화할 수 없는 상대예요" (제재 사실은 알리지 않음, E-01-2)
- 제한 중 글쓰기 · 요청 · 메시지 · 약속을 누르면 사유 · 해제 일시 · 문의 경로 안내 (P-05-05)
- 영구 정지면 로그인할 때 정지 안내, 상대 채팅방은 탈퇴와 같게 입력 종료

| 예외 상황 | 처리 |
|---|---|
| 사유 없이 [적용] | 비활성 |
| 이미 제한 중인데 또 적용 | 새 제한이 더 길면 새 기간으로 바꾸고, 더 짧으면 지금 제한 유지 |

**결과** 이용 제한 적용

### H-03-3 임박 취소 기록 삭제

> 문의하기로 받은 임박 취소 구제 신청을 확인하고 기록을 지운다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P2 | REQ-H-03, REQ-E-08 | P-01-01 | H-03 |

**진입** 사용자 상세 탭 [임박 취소 기록] → [기록 삭제]

**동작**
1. 확인 팝업 "임박 취소 기록을 지울까요? 문의하기로 받은 구제 신청을 확인했을 때만 지워요. 지우면 매너 지표에서 이 기록이 빠져요" [취소] [삭제]
2. [삭제] → 기록 삭제, 매너 지표 원래대로

**조건**
- 상대와 합의한 임박 취소였다는 구제 신청(E-08-1 · G-08-1)을 확인했을 때만
- 결과는 문의 답변 이메일로

**결과** 임박 취소 기록 삭제

### H-03-4 자동 완료 되돌리기

> 교환하지 않았는데 자동 완료됐다는 문의를 받으면 교환 전으로 되돌린다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-H-03, REQ-F-03 | P-01-01 | H-03 |

- **예외 · 제약:** 자동 완료 건만 (직접 답한 교환 완료는 되돌리지 않음)

**진입** 사용자 상세 탭 [교환 내역] 자동 완료 건 [되돌리기]

**동작**
1. 확인 팝업 "교환 완료를 되돌릴까요? 글과 첨부 글이 교환 가능으로 돌아가고, 두 사람의 완료 횟수가 1씩 줄어요. 두 채팅방에 '교환 전으로 되돌렸어요'가 남아요" [취소] [되돌리기]
2. [되돌리기] → 글 · 약속에서 고른 첨부 글 교환 가능, 두 사람 완료 횟수 −1, 약속은 취소된 것으로, 같은 글 다른 채팅방 약속 잡기 다시 열림 (E-11-1)
3. 두 채팅방에 "교환 전으로 되돌렸어요" + 두 사람에게 운영 안내 알림 (X-01-1)

| 예외 상황 | 처리 |
|---|---|
| 그사이 글이 삭제됨 | "삭제된 글이라 되돌릴 수 없어요" |

**결과** 교환 전 상태로

| 확정 | 포함 | 2차 | P2 | REQ-H-04 | P-02-06 | H-04 |

**진입** 메뉴 금지어 → 탭 [금지어 목록]

**동작**

2. 목록: 단어 · 분류 · 추가한 날 · [삭제] (확인 팝업 없이 바로)

**조건**

| 1자 이하 | [추가] 비활성 |

**결과** 금지어 목록 갱신

### H-04-2 금지어에 걸린 글

> 게시할 때 서버가 금지어를 찾은 글을 모아 확인한다 (게시는 막지 않음)

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P2 | REQ-H-04 | P-02-02, P-05-04 | H-04 |

**진입** 메뉴 금지어 → 탭 [걸린 글]

**동작**
1. 줄: 글 제목 · 걸린 단어 · 게시자 · 게시 시각 · [글 보기] · [문제없음] · [글 삭제]
2. [글 보기] → 글 미리보기 / [문제없음] → 목록에서 빠짐 / [글 삭제] → H-02-1의 글 삭제와 같음 (경고 1회)

**조건**
- 걸리지 않은 우회 표현을 찾으면 H-04-1에서 금지어 목록에 추가
