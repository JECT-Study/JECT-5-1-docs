### X-01-1 알림 발송 · 알림 목록

> 교환 요청 · 새 메시지 · 정보 변동 · 약속 취소 · 교환 확인 등을 상황별 문장으로 푸시하고, 알림 목록에서 누르면 해당 화면으로 간다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-X-01 | P-07-04, P-07-03 | 4-01 |

- **출시 후로 미루는 부분:**
  - 지금 교환 반복 알림 (D-02-1, P1)과 키워드 알림 (G-05-2, P2)은 출시 후로 미룬다.
  - 지금 교환 글의 교환 요청 첫 알림은 이번 출시에 넣는다.
  - 약속 변경 제안 · 제안 만료 · 후기 요청 알림도 각 기능과 함께 출시 후로 미룬다.
- **예외 · 제약:** 푸시가 꺼져 있어도 앱 안 알림 목록에는 알림이 쌓인다 (채팅 메시지 제외).
- **비고:** 알림 진입은 상단 아이콘 (확정). v0.5.2 (10/30~10/31): 자동 완료 마지막 알림 · 운영 안내 알림 추가. 11/16: 1차 푸시를 4종으로 줄임 — 1차 일정 안에 문구 · 화면을 다 맞추기 어렵고, 약속 · 글 수정 · 삭제는 채팅방에 카드 · 안내로 올라와 "새 메시지"로 알려도 들어오면 확인할 수 있음. 약속 취소 · 교환 확인은 놓치면 헛걸음하거나 완료 처리가 안 돼 따로 둠 (PM 결정 · PD 의견으로 닉네임 포함). 11/20: 글 수정 · 삭제를 "새 메시지"에서 "정보 변동"으로 따로 나눠 5종 — 새 메시지로 받으면 채팅방에 들어가서야 상황을 알게 돼 헷갈림 (PD 제안 · PM 결정 · 개발 가능 확인)

**진입** 상단 알림 아이콘을 누르거나 푸시를 누른다

**동작**
1. 이벤트가 생기면 대상자에게 푸시를 보낸다. 앱 안 알림 목록에는 채팅 메시지를 뺀 알림을 저장한다 (종류 · 받는 사람 · 표시 항목 · 이동 화면은 정책서 P-07-04 표).
2. 푸시는 두 줄로 보낸다.
   - 제목은 상대방 닉네임이다. 탈퇴했으면 "탈퇴한 사용자"로 보인다.
   - 내용은 알림 종류별 문장에 교환글 제품명을 붙인다.
   - 메시지 내용은 넣지 않는다.
   - 문장은 PD가 작성한다.
3. 알림 목록은 아래처럼 보인다.
   - 최신순으로 20개씩 보여준다.
   - 안 읽은 알림은 강조한다.
   - 아이콘에 안 읽은 수 배지가 붙는다.
4. 알림을 누르면 읽음 처리한 뒤 해당 화면으로 이동한다.
5. [모두 읽음]을 누르면 전체를 읽음 처리한다.

**푸시 5종** 교환 요청 · 새 메시지 · 정보 변동 · 약속 취소 · 교환 확인
- 새 메시지 = 채팅 메시지 · 약속 제안 · 확정 · 거절 · 약속 제안 자동 취소 · 약속 다시 잡기 가능 (6가지 상황이 같은 문장)
- 정보 변동 = 채팅한 글의 글 · 아이템 수정 · 교환글 삭제 · 첨부 아이템 삭제 (3가지 상황이 같은 문장). 삭제로 약속 제안이 함께 취소되면 정보 변동 1개만 보낸다
- 약속 취소 = + 메뉴 취소 · 확정 약속이 있는 방 나가기 · [못 만났어요] · 차단 · 탈퇴 · 이용 제한
**상황별 문장 · 알림 목록** 새 메시지 중 채팅 메시지를 뺀 5가지와 정보 변동 3가지를 상황별 문장으로 나누고 알림 목록에도 저장한다. 채팅 메시지는 푸시로만 보내고, 채팅 목록의 안 읽은 수로 확인한다
**추가 알림** 약속 전 알림 · 리마인드 · 자동 완료 하루 전 · 자동 완료 · 운영 안내. 출시 후: 약속 변경 제안 (P1) · 약속 제안 만료 (P1) · 지금 교환 반복 (P1) · 후기 요청 (P2) · 키워드 (P2)

**운영 안내 알림** 운영자가 관리자 페이지(H)에서 나에 대해 무언가를 처리하면 오는 알림이다. 알림별로 누르면 가는 곳은 아래와 같다.

| 알림 | 이동 |
|---|---|
| 글이 삭제됐어요 | 내 교환글 (5-04) |
| 경고를 받았어요 · 이용이 제한됐어요 · 노쇼로 기록됐어요 | 내 프로필 (5-02, 이용 상태 · 노쇼 기록) |
| 경고가 취소됐어요 · 노쇼 기록이 취소됐어요 · 이용 제한이 해제됐어요 | 내 프로필 (5-02) |
| 교환 전으로 되돌렸어요 (자동 완료를 운영자가 되돌림) | 그 채팅방 (2-02) |

**조건**
- 알림은 30일 동안 보관한다.
- 푸시 5종 알림은 모두 채팅방으로 이동한다. 교환글이 삭제돼도 채팅방은 남아 있어 그대로 들어간다.
- 채팅방을 나가면 그 방의 알림도 알림 목록에서 지운다 (나간 방은 다시 들어올 수 없어서, E-09-1). 그래서 누를 수 없는 알림은 남지 않는다.
- 알림 종류별 설정은 G-06-1에서 한다. 운영 안내 알림은 끌 수 없다 (꼭 알아야 하는 안내).
- 수락 · 거절 · 재요청 알림은 없다 (10/19 요청 단계 삭제).
- 그 채팅방을 열어 보고 있는 동안에는 그 방의 푸시를 띄우지 않는다.
- 메시지가 연달아 오면 메시지마다 바로 보낸다 (합치지 않는다).
- 차단 관계에는 알림을 보내지 않는다. 예외: 차단으로 확정 약속이 취소될 때는 약속 취소 푸시를 보낸다 (다른 취소와 같은 문장이라 차단 사실은 알 수 없다).
- 알림을 끈 채팅방은 그 방의 푸시를 모두 보내지 않는다 (E-09-1).

| 예외 상황 | 처리 |
|---|---|
| 0건 | "아직 받은 알림이 없어요"를 보여준다 |
| 불러오기 실패 | 공통 오류를 보여준다 (P-07-03) |

### X-02-1 이미지 크게 보기

> 사진을 누르면 검은 배경 전체 화면으로 크게 보고, 좌우로 넘겨 다른 사진을 본다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-C-05 | - | 9-06 |

- **예외 · 제약:**
  - 교환글 상세 · 요청 아이템 상세 · 채팅 사진에 똑같이 쓴다.
  - 핀치 줌은 없다.
- **비고:** v0.4 (10/26) 새 기능

**진입** 교환글 상세 · 요청 아이템 상세 · 채팅의 사진을 누른다

**동작**
1. 검은 배경 전체 화면으로 연다. 위 왼쪽에 [X], 아래에 "1 / n"이 보인다.
2. 이미지는 화면 가운데에 놓는다.
   - 좌우를 꽉 채우고, 위아래 남는 곳은 검은 배경으로 둔다.
   - 세로 · 정사각형 · 가로 사진 모두 잘리지 않는다 (PD 시안 3종).
3. 좌우로 넘겨 같은 글 · 아이템의 다른 사진을 본다.
4. [X]를 누르면 원래 화면으로 돌아간다.

**조건**
- 사진이 1장이면 "1 / n"을 표시하지 않는다.
- 핀치 줌은 넣지 않는다 (PD 안, 10/26).
- 굿즈 사진(3:4 · 9:16)은 잘리지 않는다. 화면보다 세로로 긴 이미지(긴 캡처)도 자르지 않고 화면 높이에 맞춰 전체가 보이게 줄인다. 양옆은 검은 여백으로 둔다 (10/31).

| 예외 상황 | 처리 |
|---|---|
| 이미지 불러오기 실패 | 회색 자리와 "사진을 불러올 수 없어요"를 보여준다 |

**결과** 사진이 크게 보인다
