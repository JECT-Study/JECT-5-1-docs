### X-01-1 알림 발송 · 알림 목록

> 교환 요청(새 채팅) · 채팅 · 약속 · 취소 · 교환 확인 · 약속 다시 잡기 가능 · 약속 제안 자동 취소 · 운영 안내 알림을 보내고(후기 · 키워드는 2차), 알림 목록에서 누르면 해당 화면으로 간다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-X-01 | P-07-04, P-07-03 | 4-01 |

- **예외 · 제약:** 푸시가 꺼져 있어도 앱 안 알림 목록에는 쌓임
- **비고:** 알림 진입은 상단 아이콘 (확정). v0.5.2 (10/30~10/31): 자동 완료 마지막 알림 · 운영 안내 알림 추가

**진입** 상단 알림 아이콘 · 푸시

**동작**
1. 이벤트가 생기면 대상자에게 푸시 + 앱 안 알림 저장 (종류 · 받는 사람 · 이동 화면은 정책서 P-07-04 표)
2. 알림 목록: 최신순 20개씩, 안 읽은 알림 강조, 아이콘에 안 읽은 수 배지
3. 알림을 누르면 읽음 처리 후 해당 화면으로 이동
4. [모두 읽음]으로 전체 읽음 처리

**1차 알림 종류** 교환 요청(새 채팅) · 채팅 · 약속(제안 · 확정 · 변경 제안 · 취소 · 약속 전) · 약속 다시 잡기 가능 · 약속 제안 자동 취소 · 교환 확인 · 리마인드 · 자동 완료 하루 전 · 자동 완료 · 운영 안내
**2차 추가** 후기 · 키워드 · 지금 교환 반복

**운영 안내 알림** 운영자가 관리자 페이지(H)에서 나에 대해 무언가를 처리하면 오는 알림. 알림별로 누르면 가는 곳:

| 알림 | 이동 |
|---|---|
| 글이 삭제됐어요 | 내 교환글 (5-04) |
| 경고를 받았어요 · 이용이 제한됐어요 · 노쇼로 기록됐어요 | 내 프로필 (5-02, 이용 상태 · 노쇼 기록) |
| 경고가 취소됐어요 · 노쇼 기록이 취소됐어요 · 이용 제한이 해제됐어요 | 내 프로필 (5-02) |
| 교환 전으로 되돌렸어요 (자동 완료를 운영자가 되돌림) | 그 채팅방 (2-02) |

**조건**
- 보관 기간 30일
- 알림 종류별 설정은 G-06-1 (2차). 운영 안내 알림은 끌 수 없다 (꼭 알아야 하는 안내)
- 수락 · 거절 · 재요청 알림 없음 (10/19 요청 단계 삭제)

| 예외 상황 | 처리 |
|---|---|
| 0건 | "아직 받은 알림이 없어요" |
| 대상 글 · 채팅방이 삭제됨 | "삭제되었거나 볼 수 없는 글이에요", 알림은 읽음 처리 |
| 불러오기 실패 | 공통 오류 (P-07-03) |

### X-02-1 이미지 크게 보기

> 사진을 누르면 검은 배경 전체 화면으로 크게 보고, 좌우로 넘겨 다른 사진을 본다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-C-05 | - | 9-06 |

- **예외 · 제약:** 교환글 상세 · 요청 아이템 상세 · 채팅 사진 공통 · 핀치 줌 없음
- **비고:** v0.4 (10/26) 새 기능

**진입** 교환글 상세 · 요청 아이템 상세 · 채팅의 사진을 누름

**동작**
1. 검은 배경 전체 화면, 위 왼쪽 [X], 아래 "1 / n"
2. 이미지는 화면 가운데, 좌우를 꽉 채우고 위아래 남는 곳은 검은 배경 (세로 · 정사각형 · 가로 사진 모두 잘리지 않음, PD 시안 3종)
3. 좌우로 넘겨 같은 글 · 아이템의 다른 사진을 본다
4. [X] → 원래 화면

**조건**
- 사진이 1장이면 "1 / n" 표시 없음
- 핀치 줌은 넣지 않음 (PD 안, 10/26)
- 굿즈 사진(3:4 · 9:16)은 잘리지 않는다. 화면보다 세로로 긴 이미지(긴 캡처) 처리는 [논의]

| 예외 상황 | 처리 |
|---|---|
| 이미지 불러오기 실패 | 회색 자리 + "사진을 불러올 수 없어요" |

**결과** 사진을 크게 표시
