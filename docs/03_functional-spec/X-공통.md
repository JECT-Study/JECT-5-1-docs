| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-X-01 | P-07-04, P-07-03 | 4-01 |

- **예외 · 제약:** 푸시가 꺼져 있어도 앱 안 알림 목록에는 쌓임
- **비고:** 알림 진입은 상단 아이콘 (확정)

**진입** 상단 알림 아이콘 · 푸시

**동작**
1. 이벤트가 생기면 대상자에게 푸시 + 앱 안 알림 저장 (종류 · 받는 사람 · 이동 화면은 정책서 P-07-04 표)
2. 알림 목록: 최신순 20개씩, 안 읽은 알림 강조, 아이콘에 안 읽은 수 배지
3. 알림을 누르면 읽음 처리 후 해당 화면으로 이동
4. 거절 알림은 사유를 펼쳐 보여주고, 재요청이 가능하면 [다시 요청하기]
5. [모두 읽음]으로 전체 읽음 처리

**조건**
- 보관 기간 30일
- 알림 종류별 설정은 G-06-1
