- **비고:** 10/20: 받은 · 보낸 요청 수 · 메뉴 삭제 (요청 단계 삭제)

### G-02-1 상태별 내 교환글

> 내 교환글을 교환 가능 / 예약중 / 교환 완료 탭으로 나눠 보고, 글마다 진행 중 채팅 수를 표시한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-G-02 | P-07-03 | 5-04 |

- **비고:** v0.5.2 (10/29~10/31): 카드 위치 구 + 동 · ⋮에 교환 완료로 바꾸기(G-02-3)

**진입** 마이페이지 개수 · 메뉴

**동작**
1. 탭별 개수 표시
2. 카드: 대표 사진 · 제목 · 위치(구 + 동) · 작성 시각 · 진행 중 채팅 수 · 지금 교환 남은 시간
3. 카드 → 내 교환글 상세, ⋮ → 수정하기 · 지금 교환 끄기(지금 교환 글일 때만) · 삭제하기 (B-07) · 교환 완료로 바꾸기(교환 가능 글일 때만, G-02-3)

| 예외 상황 | 처리 |
|---|---|
| 탭 0건 | 탭별 빈 화면 안내 (교환 가능 탭은 [글쓰기]) |
| 불러오기 실패 | 공통 오류 (P-07-03) |

**조건**
- 예약중 글은 수정할 수 없고, 약속을 취소해야 삭제할 수 있다 (B-07)
- 예약중 상태는 직접 바꿀 수 없다 (약속과 묶여 있음)

### G-02-3 교환 완료로 바꾸기

> 약속 잡기를 거치지 않고 만나 교환했을 때, 게시자가 교환한 상대를 골라 직접 교환 완료로 바꾼다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-G-02, REQ-F-01 | P-07-02 | 5-04 |

- **예외 · 제약:** 교환 가능 글에서만 · 되돌릴 수 없음 · 상대가 첨부한 글은 바꾸지 않음
- **비고:** v0.5.2 (10/29): 새 기능. 약속 확정이 있어야만 완료할 수 있으면 약속 없이 만난 사람(지금 교환에서 많음)은 완료할 길이 없음 (PM 결정, 당근 방식)

**진입** 내 교환글 ⋮ · 내 교환글 상세 ⋮ (C-05-1) → 교환 완료로 바꾸기

**동작**
1. 시트 "누구와 교환했나요?": 이 글로 열린 채팅방 중 상대가 나가지 않은 방의 상대 목록 + "앱 밖에서 교환했어요"
2. 상대를 고르면 그 채팅방에서 [교환했어요]를 누른 것과 같은 처리 (F-01-2): 글 교환 완료, 양쪽 완료 횟수 +1, 상대 채팅방 카드 "교환이 완료됐어요", 같은 글의 다른 방은 대화 유지 · 약속 잡기만 막힘 (F-02-1)
3. "앱 밖에서 교환했어요" → 글 상태만 교환 완료. 완료 횟수 · 매너 지표 반영 없음

**조건**
- 예약중 글은 이 메뉴가 없고 채팅방 교환 확인(F-01-1)으로 완료
- 요청자는 상대 글을 바꾸지 못하고, 자기가 첨부한 글은 자기 글 ⋮에서 직접 바꾼다

| 예외 상황 | 처리 |
|---|---|
| 채팅 상대 0명 | 목록 없이 "앱 밖에서 교환했어요"만 |
| 처리 실패 | 공통 오류 (P-07-03) |

**결과** 글 교환 완료, 내 교환글 교환 완료 탭으로

- **비고:** v0.4 (10/26): 프로필 사진 없음 (1차). 넣으려면 수집 항목 · 처리방침 · 업로드 · 사진 신고 처리가 필요해 2차 이후. v0.5.2 (10/31): 이용 상태 추가 (경고 · 제한을 알림으로만 알면 놓치기 쉬움)

### G-03-2 닉네임 수정

> 닉네임을 30일에 한 번 바꿀 수 있다. 생년월일 · 성별은 바꿀 수 없다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-G-03 | P-02-04 | 5-03 |

- **예외 · 제약:** 30일에 1회 · 중복 불가
- **비고:** 닉네임 금지어 경고는 2차

**진입** 내 프로필 [수정]

**동작**
1. 닉네임 입력 (A-05-2와 같은 규칙)
2. 생년월일 · 성별은 읽기 전용 "가입할 때만 입력할 수 있어요"
3. [저장] → 반영

**조건**
- 변경은 30일에 1회 (이름을 바꿔 이력을 숨기는 것 방지)

| 예외 상황 | 처리 |
|---|---|
| 30일 안에 다시 변경 | 입력칸 아래 "닉네임은 30일에 한 번 바꿀 수 있어요 ({날짜}부터 가능)", [저장] 비활성 |
| 중복 · 형식 오류 | 입력칸 아래 오류 (A-05-2) |
| 바뀐 내용 없음 | [저장] 비활성 |
| 수정 중 뒤로 가기 | "변경한 내용이 저장되지 않아요" 확인 |

**결과** 내 프로필로, 토스트 "프로필을 수정했어요"

### G-06-1 알림 설정

> 마케팅 정보 수신을 켜고 끄고, 알림을 종류별로 켜고 끈다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 (마케팅 정보 수신) · 2차 (나머지 토글) | P0 | REQ-G-06 | P-04-04, P-07-04 | 5-09, 5-10 |

- **예외 · 제약:** 꺼도 앱 안 알림 목록에는 쌓임 · OS 알림이 꺼져 있으면 토글 비활성 · 운영 안내 알림(X-01-1)은 끌 수 없음
- **비고:** v0.5.1 (10/28): 토글에서 수락 · 거절 삭제 (10/19 요청 단계 삭제 반영). v0.5.2 (10/31): 가입 때 마케팅 수신 동의를 받으니 1차부터 철회할 곳이 필요 → 설정에 "알림 설정" 줄 + 마케팅 정보 수신 토글은 1차. 마케팅 알림 야간 발송 안 함 (별도 야간 동의 화면을 만들지 않으려고)

**진입** 설정 → 알림 설정

**동작**
1. 토글 6종: 교환 요청 / 채팅 메시지 / 약속 · 교환 확인 / 위시리스트 키워드 / 지금 교환 반복 알림 / 마케팅 정보 수신
2. 누르면 바로 저장 (저장 버튼 없음)
3. "약속 · 교환 확인"을 끌 때 "약속 알림을 끄면 약속을 놓쳐 노쇼가 될 수 있어요" 확인 팝업 1회

**조건**
- 마케팅 정보 수신은 가입 때 동의한 값(A-04-1)으로 시작하고, 바꾸면 변경 일시를 저장한다
- 마케팅 알림은 21\~08시에 보내지 않는다 (야간 별도 동의는 받지 않음)
- 거래 알림(요청 · 채팅 · 약속)은 야간 제한 없음

### G-09-2 회원 탈퇴

> 확인을 거쳐 탈퇴한다. 진행 중인 교환이 있으면 약속은 자동 취소되고 모든 채팅방에서 나간다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-G-09, REQ-N-11 | P-04-05, P-04-06, P-04-07, P-07-03 | 5-12 |

- **예외 · 제약:** 진행 중인 교환(예약중 · 약속)이 있어도 탈퇴할 수 있음 · 약속 자동 취소는 기록 · 매너 지표 영향 없음
- **비고:** 재가입 7일 · 기록 이어서 적용 · 보관 1년 (P-04-06 · 07). v0.5.2 (10/31): "진행 중 교환이 있으면 탈퇴 불가" → 탈퇴 가능. 탈퇴하려는 사람에게 글을 정리하고 오라고 하면 흐름이 복잡해짐 (PM 결정)

**진입** 설정 → 탈퇴하기

**동작**
1. 주의 사항 안내: 교환 가능 글은 자동으로 삭제돼요 / 모든 채팅방에서 나가지고, 상대에게는 "탈퇴한 사용자"로 보여요 / 노쇼 · 제재 기록은 1년 동안 보관돼요 / 같은 계정으로는 7일 뒤부터 다시 가입할 수 있어요
2. 진행 중인 교환이 있으면 맨 위에 안내 "진행 중인 교환이 n건 있어요 · 탈퇴하면 잡혀 있는 약속은 자동으로 취소되고, 상대에게 '약속이 취소됐어요' 알림이 가요"
3. 떠나는 이유 (선택): 원하는 굿즈가 없어요 / 교환 상대를 찾기 어려워요 / 사용하기 불편해요 / 기타
4. "위 내용을 확인했어요" 체크해야 [탈퇴하기] 활성
5. 최종 확인 "정말 탈퇴할까요? 되돌릴 수 없어요"
6. 처리: 진행 중 약속 자동 취소 → 교환 가능 글 자동 삭제 (취소로 교환 가능이 된 글 포함) → 모든 채팅방에서 나감. 상대 화면은 닉네임 "탈퇴한 사용자", 입력창 "탈퇴한 사용자와는 대화할 수 없어요"
7. 약속이 취소된 상대: 글은 교환 가능으로, 같은 글의 다른 채팅방 약속 잡기 다시 열림 (E-11-1)

**조건**
- 닉네임 · 생년월일 · 성별은 즉시 파기, 소셜 식별값 · 노쇼 · 제재 기록은 1년 보관 후 파기 (P-04-06)
- 같은 소셜 계정 재가입은 7일 뒤부터, 노쇼 · 제재 기록은 이어서 적용 (P-04-07)
- 교환 완료된 글은 상대의 교환 내역을 위해 남긴다 (게시자는 "탈퇴한 사용자")

| 예외 상황 | 처리 |
|---|---|
| 처리 실패 | 공통 오류 (P-07-03) |

**결과** 로그인(0-03), 토스트 "탈퇴했어요. 그동안 이용해 주셔서 감사해요"
