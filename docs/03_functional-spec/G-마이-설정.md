### G-02-1 상태별 내 게시글

> 내 게시글을 교환 가능 / 예약중 / 교환 완료 탭으로 나눠 보고, 게시글마다 진행 중 채팅 수를 표시한다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-G-02 | P-07-03 | 5-04 |

- **출시 후:** ⋮ 지금 교환 끄기 (B-07-3, P1)

- **비고:** v0.5.2 (10/29~10/31): 카드 위치 구 + 동 · ⋮에 교환 완료로 바꾸기(G-02-3)

**진입** 마이페이지 메뉴 "내가 올린 게시글"을 누른다

**동작**
1. 화면 제목은 "내 게시글"이다. 탭마다 개수를 함께 표시한다 (예: 교환가능 3).
2. 카드에는 대표 사진 · 제품명 · 위치(구 + 동) · 작성 시각 · 진행 중 채팅 수 · 지금 교환 남은 시간이 보인다.
3. 카드를 누르면 내 게시글 상세로 간다. ⋮를 누르면 수정하기 · 지금 교환 끄기(지금 교환 게시글일 때만, P1) · 삭제하기 (B-07) · 교환 완료로 바꾸기(교환 가능 게시글일 때만, G-02-3)가 나온다.

| 예외 상황 | 처리 |
|---|---|
| 탭 0건 | 탭별 빈 화면 안내를 보여준다. 교환 가능 탭에는 "작성한 게시글이 없어요" / "바꾸에서 제품을 교환해보세요!"와 [글쓰기]가 보인다 |
| 불러오기 실패 | 공통 오류를 보여준다 (P-07-03) |

**조건**
- 예약중 게시글은 수정할 수 없고, 약속을 취소해야 삭제할 수 있다 (B-07).
- 예약중 상태는 직접 바꿀 수 없다 (약속과 묶여 있음).

### G-02-3 교환 완료로 바꾸기

> 약속 잡기를 거치지 않고 만나 교환했을 때, 게시자가 교환한 상대를 골라 직접 교환 완료로 바꾼다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-G-02, REQ-F-01 | P-07-02 | 5-04 |

- **예외 · 제약:**
  - 교환 가능 게시글에서만 쓸 수 있다.
  - 되돌릴 수 없다.
  - 상대가 첨부한 게시글은 바꾸지 않는다.
- **비고:** v0.5.2 (10/29): 새 기능. 약속 확정이 있어야만 완료할 수 있으면 약속 없이 만난 사람(지금 교환에서 많음)은 완료할 길이 없음 (PM 결정, 당근 방식). 11/23: 상대를 고르면 교환 확정 시트를 거침 · 진행 중 약속 제안 자동 취소 · "앱 밖에서 교환했어요"도 확인을 거치고 모든 채팅방에 안내 (PM). 11/27: "앱 밖에서 교환했어요"를 뺌. 앱 밖에서 교환한 글은 삭제(B-07-2)로 처리하고, 고를 상대가 없는 글에는 메뉴를 보여주지 않는다 (PD 제안 · PM)

**진입** 내 게시글 ⋮ 또는 내 게시글 상세 ⋮(C-05-1)에서 교환 완료로 바꾸기를 누른다

**동작**
1. 화면 "어떤 제품과 교환했나요?"가 열린다 (11/26, PD 하이파이. 전에는 "누구와 교환했나요?" 시트였다).
   - 제목 아래에 "[게시글 이름]에 교환 요청한 제품이에요."가 보인다.
   - 이 게시글로 열린 채팅방 중 상대가 나가지 않은 방이 한 줄씩 보인다. 줄에는 상대가 요청하며 낸 제품(여러 개면 "제품명 외 n개")과 상대 닉네임이 보인다.
   - 하나를 고르기 전에는 아래 [교환 완료로 바꾸기]를 누를 수 없다.
2. 하나를 고르고 [교환 완료로 바꾸기]를 누르면 확인 창을 한 번 보여준다 (되돌릴 수 없어서, 11/23 PM).
   - 제목은 "교환을 확정할까요?", 본문은 "한쪽만 확정해도 교환 완료 처리돼요. 확정은 취소할 수 없어요."이고 버튼은 [취소]와 [교환 확정하기]다 (11/26, PD 하이파이).
   - [교환 확정하기]를 눌러야 처리한다.
   - [취소]를 누르면 처리하지 않는다.
3. [교환 확정하기]를 누르면 그 채팅방에서 [교환했어요]를 눌러 확정한 것과 같게 처리한다 (F-01-2).
   - 게시글이 교환 완료로 바뀐다.
   - 양쪽 완료 횟수가 +1 된다. 매너 지표에는 반영하지 않는다 (혼자 눌러서 올릴 수 있어서, 11/23 PM).
   - 상대 채팅방에 "교환에 성공했어요!" 카드가 올라간다.
   - 같은 게시글의 다른 방은 대화를 유지하고 약속 잡기만 막힌다 (F-02-1).
4. 그 게시글에 걸려 있던 진행 중 약속 제안은 모두 자동 취소한다 (11/23 PM).
   - 카드 버튼만 "취소됨"으로 바꾼다.
   - E-04-1의 안내 문구와 알림은 보내지 않는다.
   - 다른 방에는 "다른 분과 교환이 완료됐어요" 안내가 간다 (F-02-1).

**조건**
- 매너 지표에는 반영하지 않는다.
- 고를 상대가 없으면(교환 요청을 받은 적이 없거나 상대가 모두 채팅방을 나감) ⋮ 메뉴에 [교환 완료로 바꾸기]를 보여주지 않는다. 앱 밖에서 교환한 글은 삭제한다 (B-07-2, 11/27).
- 예약중 게시글에는 이 메뉴가 없고, 채팅방 교환 확인(F-01-1)으로 완료한다.
- 요청자는 상대 게시글을 바꾸지 못하고, 자기가 첨부한 게시글은 자기 게시글 ⋮에서 직접 바꾼다.

| 예외 상황 | 처리 |
|---|---|
| 고를 상대 0명 | 메뉴를 보여주지 않는다 (위 조건) |
| 처리 실패 | 공통 오류를 보여준다 (P-07-03) |

**결과** 게시글 교환 완료, 내 게시글 교환 완료 탭으로

### G-03-1 내 프로필

> 닉네임 · 완료 횟수 · 매너 지표 · 노쇼 기록을 확인한다. 받은 후기는 출시 후

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-G-03 | P-01-04, P-04-03 | 5-02 |

- **예외 · 제약:** 받은 후기는 본인만 볼 수 있다 (출시 후).
- **비고:** v0.4 (10/26): 프로필 사진 없음 (1차). 넣으려면 수집 항목 · 처리방침 · 업로드 · 사진 신고 처리가 필요해 2차 이후. v0.5.2 (10/31): 이용 상태 추가 (경고 · 제한을 알림으로만 알면 놓치기 쉬움). 11/23: 사진을 올리는 기능은 없지만 기본 아바타 이미지를 보여줌 (11/23 회의)

**진입** 마이페이지의 프로필 요약을 누른다

**동작**
1. 기본 아바타 · 닉네임 · 교환 완료 횟수를 보여준다.
   - 프로필 사진을 올리는 기능은 없다. 기본 아바타 이미지를 보여준다 (모두 같은 기본 이미지, 11/23).
2. [수정]을 누르면 닉네임 수정(G-03-2)으로 간다.
3. 매너 지표를 이름과 숫자로 함께 보여준다 (예: 굿즈헌터 · 62). 숫자가 보이는 곳은 이 화면뿐이다 (F-06-1, 11/24).
4. (출시 후) 받은 후기를 단계별 개수로 보여준다 (예: 최고예요 5 · 좋아요 3 · 별로예요 0). "나만 볼 수 있어요"를 함께 보여준다.
5. 노쇼 기록을 보여준다 (본인만).
   - 인정 N회 · 확인 중 N건을 보여준다.
   - 건마다 약속 일시 · 장소 · 상대 닉네임 · 처리 상태(확인 중 / 인정 / 기각)를 보여준다.
   - [이의 제기]를 누르면 문의하기(G-08-1)의 "노쇼 신고 이의 제기"로 간다.
6. 이용 상태를 보여준다 (본인만). "정상 · 경고 n회" 또는 "경고 n회 · 7일 이용 제한 중 ({해제일}까지)"로 보인다 (P-05).

**조건**
- 상대가 남긴 못 만난 이유는 보여주지 않는다.

| 예외 상황 | 처리 |
|---|---|
| 교환 0회 | 완료 횟수 대신 "첫 교환을 기다리고 있어요"를 보여준다 |

### G-03-2 닉네임 수정

> 닉네임을 30일에 한 번 바꿀 수 있다. 생년월일 · 성별은 바꿀 수 없다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-G-03 | P-02-04 | 5-03 |

- **예외 · 제약:**
  - 30일에 1회만 바꿀 수 있다.
  - 다른 사람과 같은 닉네임은 쓸 수 없다.
- **비고:** 닉네임 금지어 경고는 출시 후 (B-05-1, P1)

**진입** 내 프로필에서 [수정]을 누른다

**동작**
1. 닉네임을 입력한다 (A-05-2와 같은 규칙).
2. 생년월일 · 성별은 읽기 전용이고, "가입할 때만 입력할 수 있어요"가 보인다.
3. [저장]을 누르면 반영한다.

**조건**
- 변경은 30일에 1회만 할 수 있다 (이름을 바꿔 이력을 숨기는 것 방지).

| 예외 상황 | 처리 |
|---|---|
| 30일 안에 다시 변경 | 입력칸 아래에 "닉네임은 30일에 한 번 바꿀 수 있어요 ({날짜}부터 가능)"를 보여준다. [저장]은 누를 수 없다(흐리게 보인다) |
| 중복 · 형식 오류 | 입력칸 아래에 오류를 보여준다 (A-05-2) |
| 바뀐 내용 없음 | [저장]을 누를 수 없다(흐리게 보인다) |
| 수정 중 뒤로 가기 | "변경한 내용이 저장되지 않아요" 확인을 띄운다 |

**결과** 내 프로필로 돌아가고, 토스트 "프로필을 수정했어요"가 뜬다

### G-04-1 교환 내역 · 필터

> 완료한 교환과 못 한 · 취소된 교환을 기록으로 보고, 칩으로 거른다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P0 | REQ-G-04 | P-06-01 | 5-07 |

- **예외 · 제약:** 자동 완료 건도 포함한다.

**진입** 마이페이지에서 교환 내역을 누른다

**동작**
1. 칩에는 전체 / 교환 완료 / 못 함 · 취소([교환하지 못했어요] 건)가 있다.
2. 항목에는 "{내 제품} ↔ {받은 제품}" · 상대 닉네임 · 날짜 · 결과 · 후기 상태(출시 후, P2)가 보인다.
3. 항목을 누르면 그 채팅방으로 간다.
   - 후기를 안 보낸 건에는 [후기 보내기]가 있고, 누르면 2-03으로 간다 (출시 후, P2).
   - 자동 완료 건은 "자동"으로 표시한다.
4. 교환 완료 건의 ⋮에 [신고하기]가 있다.
   - 사유에 "교환한 제품에 문제가 있어요 (하자 · 설명과 다름)"가 들어 있다 (C-09-1).
   - 채팅방을 나갔거나 상대가 나갔어도 신고할 수 있다.
   - 같은 상대는 1번만 신고할 수 있다.

**조건**
- 내가 올린 게시글과 내가 요청한 교환을 모두 포함한다. 최신순으로 20개씩 보여준다.

| 예외 상황 | 처리 |

| 상대 탈퇴 | 닉네임 자리에 "탈퇴한 사용자"가 보인다 |

### G-05-1 위시리스트 키워드 관리

> 찾는 제품 키워드를 추가 · 삭제하고 알림을 켜고 끈다

| 상태 | MVP | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|
| 확정 | 포함 | P2 | REQ-G-05 | P-02-04 | 5-08 |

- **예외 · 제약:**
  - 최대 10개까지 등록할 수 있다.
  - 알림을 꺼도 목록은 남는다.
  - 금지어 검사를 한다.

**진입** 설정에서 알림 설정을 누른다

**동작**

   - 채팅 메시지
   - 약속 · 교환 확인

   - 지금 교환 반복 알림 (출시 후)
   - 마케팅 정보 수신
2. 누르면 바로 저장한다 (저장 버튼 없음).
3. 토글을 끄면 아래 푸시가 가지 않는다 (11/23 PM).

| 토글 | 끄면 안 가는 푸시 |
|---|---|
| 교환 요청 | 교환 요청이 왔을 때 |
| 채팅 메시지 | 채팅 메시지, 게시글 · 제품 정보가 바뀌었을 때(정보 변동) |
| 약속 · 교환 확인 | 약속 제안 · 확정 · 거절 · 자동 취소 · 약속 다시 잡기 가능 · 약속 취소, 약속 전 알림, 교환 확인 질문, 리마인드, 자동 완료 하루 전 · 자동 완료 |

4. "약속 · 교환 확인"을 끌 때마다 확인 팝업 "약속 알림을 끄면 약속을 놓쳐 노쇼가 될 수 있어요"를 띄운다 (11/25, 처음 한 번만이 아니라 끌 때마다).

   - 팝업에서 교환 확인 알림도 꺼진다는 것을 함께 알려야 한다. 문구는 PD가 정한다 [논의].

**조건**

- 거래 알림(요청 · 채팅 · 약속)은 야간 제한이 없다.

| 요청에 첨부한 내 게시글 (교환 가능) | 자동 삭제 | 상대 채팅방 제품 카드 "삭제된 제품", 상단 카드 다시 계산 | B-07-2 · E-01-3 |
| 채팅방 | 탈퇴한 사람은 모든 방에서 나감. 상대 쪽 방은 남고 지난 대화를 볼 수 있음 | 시스템 메시지 "상대가 탈퇴했어요" (**푸시 없음**), 닉네임 자리 "탈퇴한 사용자", 입력창 대신 "탈퇴한 사용자와는 대화할 수 없어요" | E-01-2 · E-01-3 |
| 확정 약속 | 자동 취소. 양쪽 모두 기록 · 매너 지표 영향 없음 | 시스템 메시지 "상대가 탈퇴해서 약속이 취소됐어요" + 약속 취소 푸시(제목 "탈퇴한 사용자", X-01-1). 상대 게시글은 교환 가능으로 돌아가고, 같은 게시글의 다른 방에 "다시 약속을 잡을 수 있어요" + 약속 잡기 다시 열림 | E-07-1 · E-11-1 · P-01 |
| 확정 전 약속 제안 | 자동 취소 | 카드 버튼 "취소됨" (시스템 메시지는 "상대가 탈퇴했어요" 하나만) | E-03-1 · E-04-1 |
| 요청 수 · 게시글별 채팅 목록 | 상대 게시글의 "요청 n"과 [받은 교환 요청 n개 보기]에서 빠짐 (상대가 나가지 않은 방만 셈) | - | C-05-1 · E-01-1 |
| 게시자 프로필 | 열 수 없음 | "탈퇴한 사용자예요" 안내 후 이전 화면 | C-05-2 |
| 채팅 · 후기 기록 | 상대의 기록으로 남음 | 작성자 "탈퇴한 사용자" | P-04-06 |
| 개인정보 | 닉네임 · 생년월일 · 성별 즉시 파기, 소셜 식별값 · 노쇼 · 제재 기록 1년 보관 후 파기 | - | P-04-06 |
| 다시 로그인 · 재가입 | 7일 안에는 재가입 불가 안내, 이후 신규 가입 + 노쇼 · 제재 기록 이어서 적용 | - | A-03-1 · P-04-07 |
| 관리자 페이지 | 기록만 보이고 처리 버튼 없음 | - | H-03-1 |

**진입** 설정에서 탈퇴하기를 누른다

**동작**
1. "탈퇴하기 전에 확인해주세요" 아래에 주의 사항을 안내한다.
   - 교환 가능 게시글은 자동으로 삭제돼요
   - 대화중인 모든 채팅방은 나가기 처리되며, 상대에게는 '탈퇴한 사용자'로 보여요
   - 노쇼, 제재 기록은 1년 동안 보관해요
   - 같은 계정으로는 7일 뒤부터 다시 가입할 수 있어요
2. 진행 중인 교환이 있으면 맨 위에 안내 "진행 중인 교환이 n건 있어요 · 탈퇴하면 잡혀 있는 약속은 자동으로 취소되고, 상대에게 '약속이 취소됐어요' 알림이 가요"를 보여준다.
3. "탈퇴사유를 알려주세요" 아래에서 떠나는 이유를 고른다 (선택).
   - 원하는 제품이 없어요
   - 교환 상대를 찾기 어려워요
   - 사용이 불편해요
   - 기타
4. "위 내용을 확인했습니다"를 체크해야 [탈퇴하기]를 누를 수 있다.
5. 최종 확인 팝업 "정말 탈퇴할까요?" / "탈퇴시 계정을 다시 복구할 수 없어요" / "재가입은 7일 후 가능해요"와 [탈퇴하기] [취소]를 띄운다.
6. 아래 순서로 처리한다. 상대 화면은 위 "탈퇴하면 바뀌는 것" 표대로 바뀐다.
   - 진행 중인 약속을 자동으로 취소한다.
   - 교환 가능 게시글을 자동으로 삭제한다 (취소로 교환 가능이 된 게시글 포함).
   - 모든 채팅방에서 나간다.
7. 약속이 취소된 상대는 게시글이 교환 가능으로 돌아가고, 같은 게시글의 다른 채팅방에서 약속 잡기가 다시 열린다 (E-11-1).

**조건**
- 닉네임 · 생년월일 · 성별은 즉시 파기한다. 소셜 식별값 · 노쇼 · 제재 기록은 1년 보관 후 파기한다 (P-04-06).
- 같은 소셜 계정으로는 7일 뒤부터 재가입할 수 있다. 노쇼 · 제재 기록은 이어서 적용한다 (P-04-07).
- 교환 완료된 게시글은 상대의 교환 내역을 위해 남긴다 (게시자는 "탈퇴한 사용자").

| 예외 상황 | 처리 |
|---|---|
| 처리 실패 | 공통 오류를 보여준다 (P-07-03) |

**결과** 로그인(0-03)으로 가고, 토스트 "탈퇴했어요. 그동안 이용해 주셔서 감사해요"가 뜬다
