### N-03-1 알림 꺼짐 안내

> 알림이 꺼져 있으면 첫 교환글 게시 · 첫 교환 요청 직후 휴대폰 설정에서 켜도록 한 번 안내한다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-N-03 | - | 9-01 |

- **예외 · 제약:** 시점별 1회 (첫 게시 · 첫 요청) · OS 팝업을 다시 띄우지 않음
- **비고:** v0.5.3 (10/31): 가입 때 OS 팝업만 띄우고, 거부했으면 설정으로 안내하는 방식으로 확정 (PM 결정)

**진입** 첫 게시(B-06-2) · 첫 요청(C-07-1) 직후, OS 알림 권한이 꺼져 있을 때

**동작**
1. 팝업 "알림이 꺼져 있어요 · 교환 요청과 약속 알림을 받으려면 휴대폰 설정에서 알림을 켜 주세요" [나중에] [설정 열기]
2. [설정 열기] → 휴대폰의 바꾸 알림 설정

**조건**
- 시점별 1회, 총 최대 2회
- 알림 설정 화면(G-06-1)의 OS 알림 꺼짐 안내는 별도

**결과** 팝업을 닫고 원래 흐름 계속

### N-03-2 위치 권한 요청 · 상태 안내

> 위치가 필요한 순간에 이유를 먼저 안내하고 권한을 요청하며, 설정에서 현재 상태를 보여준다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-N-03, REQ-N-04 | P-03-02 | 9-02, 5-10 |

- **예외 · 제약:** 앱 실행 · 온보딩에서는 묻지 않음 · 거부해도 다른 기능 사용 가능
- **비고:** v0.4 (10/26): 위치가 필요한 곳 = 탐색 위치 설정 내 위치 버튼(C-01-1) · 글쓰기 현재 위치(B-03-2) · 상세 전체 화면 지도(C-05-1) · (2차) 가까운순(C-02-2). 교환 지도 탭은 삭제

**진입** 탐색 위치 설정 내 위치 버튼(C-01-1) · 현재 위치로 설정 · 가까운순 중 처음 쓰는 곳

**동작**
1. 사전 안내 바텀시트. 요청한 곳에 맞는 문구 (예: 내 위치 버튼 "내 위치 주변 교환글을 찾을 수 있어요")
2. [위치 허용하기] → OS 팝업 / [나중에] → 팝업을 띄우지 않음
3. 허용 → 호출한 기능 바로 실행. 한 번 허용하면 세 곳 공통
4. 설정(5-10)에 "위치 접근: 허용됨 / 허용 안 됨" + [변경] → 기기 설정

**조건**
- 위치는 조회에만 쓰고 저장하지 않음 (REQ-N-04)

| 예외 상황 | 처리 |
|---|---|
| 거부 | 희망 장소는 거점 · 검색 · 지도 핀으로 설정, 내 위치 버튼은 안내 후 지도 유지, 정렬은 최신순 유지 |
| 이미 거부 (OS가 다시 안 띄움) | 기기 설정 이동 안내 |

**미결정**
- [개발 확인] 대략적 위치만 허용했을 때 반경 처리

### N-03-3 사진 · 카메라 권한 요청 · 꺼짐 안내

> 사진은 OS 기본 사진 선택 창을 써서 권한을 요청하지 않고, 촬영을 처음 누를 때 카메라 권한을 요청하며, 거부한 뒤에는 안내를 보여준다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-N-03 | - | 9-05 |

- **예외 · 제약:** 권한은 앱 전체에 하나 (글쓰기 · 요청 · 채팅 공통)
- **비고:** v0.4 (10/26): 앨범 거부 안내 · 제한된 접근 보충 (PD 주석 답변). 11/11: OS 기본 사진 선택 창 사용으로 앨범(사진) 권한 요청 · 앨범 거부 안내(1-07a) · 제한된 접근 처리 · 사진 권한 팝업(9-03) 삭제 (FE 답변 · PM 결정)

**진입** 사진 추가 시트(B-01-2)에서 [카메라로 촬영]을 처음 누를 때

**동작**
1. 사진: OS 기본 사진 선택 창을 쓰므로 앨범(사진) 권한 팝업을 띄우지 않는다
2. 카메라: [카메라로 촬영]을 처음 누를 때 OS 카메라 권한 팝업 → 허용하면 카메라 실행
3. 카메라를 거부해도 [앨범에서 선택]으로 사진을 올릴 수 있다

| 예외 상황 | 처리 |
|---|---|
| 카메라 거부 | [카메라로 촬영]을 누르면 "휴대폰 설정에서 카메라를 켜 주세요" + [설정 열기] |
