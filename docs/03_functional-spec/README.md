## 규칙

- **기능 ID = 요구사항 ID + 번호** (REQ-B-07 → B-07-1, B-07-2)
- 요구사항 하나에 기능 1\~3개. 여러 요구사항에 걸치면 대표 하나에 붙이고 "요구사항"에 함께 적는다
- **정책 ID** = 정책서 항목 (P-01-01 형식). 공통 오류 P-07-03은 오류 처리가 있는 기능에만 적는다
- **상태:** 확정 / 논의 / 개발 확인 / 제안
- **MVP:** 포함 / 제외 / 논의. 삭제한 기능은 지우고 같은 영역 번호를 앞으로 당긴다 (v0.4, 10/26). "제외"는 MVP 이후 후보라 남긴다
- **배포:** 1차 (11월 말 스토어 배포) / 2차 (12/18 MVP 완성). P0에만 붙임
- **화면:** 기존 화면 번호를 쓰고, 새 화면은 번호 뒤에 "(추가 예정)"
- **본문 양식:** 진입 → 동작 → 조건 → 예외 → 결과 → 미결정(있을 때만). 화면 문구는 와이어프레임 기준
- 본문은 항상 최신 내용만 둔다. 바뀐 이력은 아래 변경 사항과 커밋 기록에
