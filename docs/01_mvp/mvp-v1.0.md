## 요약

- **이번 출시 (P0):** 1차 · 2차 구분 없이 한 번에 만든다. 12/18까지 **애플(App Store)만** 배포하고, 구글 배포는 그 뒤에 한다.
  - 핵심 경험: 가입 → 교환글 작성(지금 교환 포함) → 홈 · 검색 · 상세 → 교환 요청 → 채팅 · 약속 → 교환 완료
  - 신뢰: 게시자 프로필 · 매너 지표(교환 완료 · 노쇼 반영) · 약속 전 알림
  - 심사 필수: 신고 · 차단 · 차단 목록 · 문의하기 · 약관 보기 · 회원 탈퇴 · 신고 처리(관리자 페이지)
- **출시 후 (P1 · P2):** 핵심 경험을 해치지 않는 편의 기능. 지우지 않고 우선순위만 뒤로 둔다.
- **어떻게 골랐나 (11/23)**
  1. FE나 BE 중 한쪽이라도 작업을 시작한 기능은 그대로 둔다
  2. 심사에 필요한 기능은 시작 여부와 상관없이 둔다
  3. 시작 안 한 기능 중 핵심 경험이 없어도 이어지는 편의 기능은 출시 후로 미룬다
- **위치는 거점 선택으로 확정 (11/23):** 기기 위치를 쓰지 않는다. 사용자가 직접 고른 장소만 저장한다. 그래서 위치기반서비스 신고가 필요 없다.
  - 홈 헤더에서 거점(홍대 · 용산 · 건대·성수 · 신도림 · 국제전자센터(국전))을 골라 그 거점 교환글만 본다 (C-01-1)
  - 가까운순 정렬 · 거리 표시 · 위치 권한 요청은 없다 (C-02-2 · B-03-2 · N-03-2)
  - 교환 장소는 장소 검색 · 지도 핀으로 직접 고르고, 서버가 좌표로 거점을 자동 분류한다 (B-03-2)

- **1 · 2차 구분 없앰:** 배포 칸을 지우고 P0(이번 출시) · P1 · P2 · 이후로만 나눈다.
- **P0으로 올림 (옛 2차):**
  - 탐색 · 신뢰: C-01-1 거점 선택 · C-03-1 검색 · C-05-2 게시자 프로필 · F-06-1 매너 지표

  - 마이: G-02-2 · G-02-3 · G-03-1 · G-03-2 · G-04-1
  - 관리자: H-01-1 · H-02-1 · H-02-2 · H-03-1 · H-03-2 · H-03-4

- **배포:** 12/18까지 애플만 (11/22 파트장 회의)
