## 요약

- **1차 (P0, 11/27 스토어 심사 제출):** 두 사람이 앱에서 교환 한 사이클을 끝낼 수 있게 + 심사 필수 + 지금 교환 가벼운 판
  - 한 사이클: 가입 → 교환글 작성 → 홈 · 상세 → 교환 요청 → 채팅 · 약속 → 교환 완료
  - 심사 필수: Apple 로그인(iOS) · 신고 · 차단 · 차단 목록 · 문의하기 · 약관 보기 · 회원 탈퇴
  - 지금 교환: 작성 때 선택 + 유지 시간, 카드 · 상세 배지, 시간이 끝나면 배지가 사라짐, 홈 [모든 교환글 ▾] 칩으로 거르기
- **2차 (12/18 MVP 완성):** 완성형에서 1차를 뺀 나머지. P1 먼저, P2는 여유 있으면
  - P1 대표: 탐색 위치 지도 · 관리자 페이지 · 반복 알림 · 검색 · 매너 지표 · 노쇼 · 금지어 · 외부 거래 경고 · 자동 완료 · 약속 수정
- **왜 이렇게 잘랐나**
  1. 1차가 심사를 통과하면 2차가 밀려도 12/18 공개 조건은 확보된다. 그래서 1차는 "이것만 공개돼도 바꾸"여야 한다
  2. 지금 교환을 빼면 1차가 그냥 교환글 게시판이 된다. 무거운 반복 알림은 2차라 1차 지금 교환은 가볍다
  3. 탐색 위치 지도는 숫자 핀 묶기 · 거점 다각형 · 주소 변환 · 1km 거르기가 몰려 있어 가장 무겁다. 1차 사용자 수에서는 홈 전체 최신순으로 충분하다. 지도 SDK는 1차에도 쓴다 (희망 장소 고르기 · 상세 미리보기)
  4. 관리자 페이지: 심사는 신고를 처리하는 수단만 본다. 1차 신고는 개발이 DB에서 확인해 처리한다
