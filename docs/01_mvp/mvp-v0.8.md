## 요약

- **서비스명:** 바꾸 (Bakku)
- **서비스:** 랜덤 굿즈를 뽑은 직후 원하지 않는 아이템을 바로 올리고, 원하는 아이템을 가진 사람과 직접 만나 교환하는 현장 교환 앱
- **핵심 흐름:** 교환글 작성 → 홈 탐색(탐색 위치 1km) · 교환 요청 → 바로 1:1 채팅 → 약속(교환할 물건 확정) → 현장 교환 → 교환 확인
- **이번 버전의 큰 변화**
  1. 교환 지도 탭 삭제 → 홈(첫 번째 탭) 리스트 + 탐색 위치 설정(지도에서 위치를 고르면 1km 안 글만). 하단 탭 홈 · 채팅 · 마이 (10/23 정기회의 · 10/24 PD)
  2. 교환 요청을 단순화: 내 교환글 여러 개(최대 5) 또는 새 아이템 1개, 조율 · 가능한 시간 · 메시지 칸 삭제. 첨부는 원본 글과 연결(복사 없음)
  3. 약속에서 교환할 물건을 확정하고, 확정 뒤에는 변경 제안 → 상대 수락으로 바꿈
  4. 기획 문서 삭제 항목을 지우고 기능 · 요구사항 번호를 앞으로 당김 ([기능 명세 v0.4 변경 사항](../03_functional-spec/README.md))

## 2. 서비스 정의 · 타겟

v0.7과 같다. 해결할 문제 중 "지금 근처에 있는 상대를 모른다"의 해결 방식만 바뀜

| 문제 | 근거 | MVP의 해결 방식 |
|---|---|---|
| 지금 근처에 있는 상대를 모른다 | 인터뷰: "전날 글은 상대가 이미 떠남" · 서베이: 이동 30분 이내 65% | 지금 교환(현장 모드) 배지 · 칩, 탐색 위치 설정(고른 지점 1km 안 글만) (1차), 가까운순 · 현장 글 반복 알림 (2차) |

## 3. 핵심 방향 (v0.7에서 바뀐 줄만)

| 항목 | 결정 | 근거 |
|---|---|---|
| 중심축 | 현장 교환. 뽑은 직후 글을 올리는 것이 대표 진입 시점. **지금 교환 · 탐색 위치 설정은 1차부터** | 인터뷰 3명 지지 · 서베이 현장 교환 경험 59% |
| 배포 | 1차: 한 사이클(가입 → 글 → 홈 탐색 → 요청 = 채팅 → 약속 → 교환 → 완료) + 스토어 심사 필수 기능 / 2차: 탐색 편의 · 신뢰 · 안전 장치 | JECT 배포 마감 12/18 |
| 노출 | 홈(첫 번째 탭)은 전체 글(교환 가능 · 예약중), 교환 방식 · 카테고리로 거르고 탐색 위치를 정하면 1km 안 글만 | 10/23 정기회의 |
| 교환 장소 | 희망 장소는 현재 위치 · 장소 검색 · 지도 핀. 상세 교환장소는 장소 이름(검색) 또는 번지(핀) + 장소 메모(만날 곳 이름), 정확한 시간 · 장소는 채팅 약속에서 (10/27) | 10/26 PM |
| 요청 아이템 | 원본 교환글과 연결, 복사 없음. 실제 교환 물건은 약속 때 확정 | 10/25 PM · 완료 시 글 상태를 정확히 맞추기 위해 |
| 신뢰 · 운영 | 완료 횟수 공개 (1차), 프로필 사진 없음, 매너 지표 · 후기 (2차) | 개인정보 · 개발 공수 |
