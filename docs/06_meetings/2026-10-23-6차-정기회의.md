## 1. 홈 · 교환 지도 통합

- 제안: 홈 상단에서 내 주변 또는 지역을 고르고, 지도에서 탐색 위치를 정하면 그 주변 글이 홈 리스트에 표시
- 정할 것: 지도 숫자의 의미, 지도와 리스트 개수 일치, 반경 검색 범위, 거점 분류 유지 여부
- BE: 기존안과 개발 공수는 크게 다르지 않으나 구현 기준을 명확히 해야 함
- **결정:** PD 의견을 모아 PM · PD가 정리 → PM이 예외 케이스 작성 → 개발 시작 전 최종 공지

## 2. 교환 요청 절차 간소화

- 개편안: 요청 폼 작성 → 요청함 · 수락 단계 없이 바로 1:1 채팅
- **결정:** 기존 글을 요청에 붙이면 선택 당시 사진 · 내용을 복사. 원본을 고쳐도, 거래가 끝나도 원본 글에는 영향 없음 (BE 구현 문제없음)
- **결정:** 상품 상태는 개봉 · 미개봉만, 하자는 설명에 작성하는 방향
- 요청 입력 흐름(버튼 분리 등)은 PD가 추가 검토

## 3. 관리자 기능 · 데이터 직접 수정
