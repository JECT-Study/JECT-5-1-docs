## 4. 작업 방식 인식 차이 · 절충안

- 11/11 전체 채널에 작업 방식을 공유했으나 파트별 이해가 달랐음
  - FE: 1차는 와이어프레임으로 만들고, 2차에 테스트하면서 하이파이 디자인을 입힌다고 이해
  - PD: 1차에서 하이파이로 작업하고, 개발 완료 표시가 달리면 와이어프레임으로 만든 부분에 하이파이를 입힌다고 이해
- **결정 (PD · FE):** 앞으로 '디자인시스템' 피그마 파일을 기준으로 함. 하이파이 상태를 이모지와 코멘트로 구분 (하이파이 검토 중 / 개발 가능 · 개발 중 · 개발 완료)
- **결정 (PD · FE):** FE PR은 시간이 많이 들지 않으면 웹 배포로 미리 볼 수 있게 하고, 어려우면 기존처럼 캡처로 공유
- **결정 (PD · PM):** 참석하지 못한 팀원이 생기면 PD · PM 회의 내용 공유를 요청
- **요청 (전 파트 → PM):** 기획 문서 변경이 텍스트로만 공유돼 따라가기 어려움 → 중요한 기획 변경은 구두로도 전달
