- **정책 ID** = 분류 번호 + 순번 (예: P-01-02)
- **분류:** P-01 매너 지표 · 노쇼 / P-02 게시물 · 금지어 · 외부 거래 / P-03 거점 · 위치 / P-04 회원 · 개인정보 / P-05 이용 제한 · 제재 / P-06 신고 · 문의 운영 / P-07 교환 진행 기준

- **배포:** 1차 (11월 말 스토어 배포) / 2차 (12/18 MVP 완성)
- **약관 반영:** 이용약관 · 개인정보 처리방침 · 위치기반서비스 약관 중 옮길 곳
- 화면 동작은 기능 명세서에 두고, 정책서에는 기준값 · 규칙만 둔다

## P-01 매너 지표 · 노쇼

### P-01-01 매너 지표 반영 항목
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** F-06-1 · F-04-1 · REQ-F-06 · **약관:** 이용약관
- **내용:** 교환 완료 · 후기 · 노쇼 · 임박 취소로 지표 1개를 계산한다. 이름은 "매너 지표", 숫자로 표시
- **기준값:** 올림: 교환 완료 · 좋은 후기 / 내림: 노쇼 (운영자 인정) · 임박 취소 · 나쁜 후기 · 허위 노쇼 신고 · "못 만났어요" 사유 중 물품 다름 · 금품 요구 (운영자 확인 후 반영) / 원래대로: 노쇼 이의 인정 · 임박 취소 구제 · 경고 취소
- **예외:** 영향 없음: 임박 전 약속 취소 · 서로 취소 · 제안 만료 · 자동 완료 · 마감 · 차단 · 탈퇴 · 이용 제한으로 인한 자동 취소 · 다른 약속 확정으로 인한 제안 자동 취소 · 약속 수정
- **노쇼 판단:** "못 만났어요"에 두 사람이 각자 답한 이유를 맞춰 누가 안 나왔는지 정한다 (예: A "상대가 연락 없이 안 나왔어요" + B "제가 못 갔어요" → B 노쇼). 엇갈리거나 한쪽만 답하면 운영자가 채팅 기록으로 확인. 답이 없다는 것만으로 노쇼로 정하지 않는다 (F-04-1)
- **임박 취소 구제:** 상대와 합의한 임박 취소였다면 문의하기(구제 신청)로 사유를 받아 운영자가 확인 후 기록 삭제 (E-08-1 · H-03-3)
- **비고:** 10/20: "못 만났어요" 사유 추가 (F-04-1). 사유별 깎는 폭은 2차 개발 전에 계산식(P-01-02)에서 정한다. 1차는 기록만. v0.5.2 (10/29~10/31): 합의 · 일방 취소 → 약속 취소 · 임박 취소, 두 사람 답 대조, 구제 절차, 이름 · 숫자 표시 확정

### P-01-02 매너 지표 계산식
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** F-06-1
- **내용:** 시작값과 항목별 증감 (F-06-1이 정책서로 넘김)
- **기준값:** 시작 50 · 범위 0\~100 / 교환 완료 +2 / 최고예요 +2 · 좋아요 +1 · 별로예요 −1 / 임박 취소 −5 / 노쇼 −10 / 허위 노쇼 신고 −10
- **예외:** 계산식은 사용자에게 공개하지 않음
- **비고:** "못 만났어요" 사유(물품 다름 · 금품 요구)별 깎는 폭은 2차 개발 전에 정한다 (10/20). v0.5.2 (10/31): 계산식 확정 (와이어프레임 · 관리자 페이지가 이 숫자 기준)

### P-01-03 노쇼 확인 · 반영
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** F-04-2 · REQ-F-04 · **약관:** 이용약관
- **내용:** 운영자가 관리자 페이지(H-02-2)에서 확인해 인정하면 노쇼한 사람의 매너 지표에 반영한다
- **기준값:** 운영자 하루 1회 확인 · 인정되면 노쇼한 사람에게만 알림 "노쇼로 기록됐어요. 이의가 있으면 문의하기로 알려주세요" · 신고자에게는 결과를 알리지 않음
- **예외:** 확인 전에는 지표 미반영. 글은 신고 접수 즉시 교환 가능 · 상대가 이미 "교환했어요"로 답한 약속은 교환 완료가 우선 (기각)

### P-01-04 이의 인정 시 원복
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** G-03-1 · G-08-1 · **약관:** 이용약관
- **내용:** 노쇼 이의가 받아들여지면 기록을 "기각"으로 바꾸고 매너 지표를 되돌린다
- **기준값:** 노쇼 기록 "기각" 처리 + 깎였던 매너 지표 복구 (계산식 기준 +10) · 본인에게 "노쇼 기록이 취소됐어요" 알림. 경고 취소 · 이용 제한 해제도 같은 방식 (관리자 페이지 H-03-1)
- **예외:** –

## P-02 게시물 · 금지어 · 외부 거래

### P-02-01 게시 기준
- **상태:** 확정 · **배포:** 1차 · **관련 기능:** B-01-1 · B-01-2 · **약관:** 이용약관
- **내용:** 1게시물 1아이템, 직접 찍은 실물 사진만 올린다
- **기준값:** 아이템 1개 · 사진 1\~5장
- **예외:** 공식 이미지 · 다른 사람 사진은 신고 대상
- **비고:** MVP 핵심 방향 (IP 회피)

### P-02-02 판매 · 구매 표현 금지
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** B-05-1 · REQ-B-05 · **약관:** 이용약관
- **내용:** 판매 · 구매 · 가격 등 구매를 유도하는 표현이 포함되면 경고를 보여준다. 게시는 막지 않는다
- **기준값:** 띄어쓰기를 지우고 단어 목록과 비교 · 입력 단계 경고 + 게시 시 서버에서 한 번 더 확인해 운영자 확인 목록에 남김 · 문맥 판단 없음
- **예외:** 목록에 없는 우회 표현은 신고로 모아 목록에 추가 (P-02-06)
- **비고:** 10/20 개발 확인 안건 4번: 문맥 판단은 LLM이 필요해 제외 → 막지 않고 경고만. 2차 배포

### P-02-03 외부 거래 유도 감지
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** C-08-1 · REQ-C-08 · **약관:** 이용약관
- **내용:** 채팅에서 오픈채팅 · 메신저 ID · 전화번호 · 계좌 · 송금 등을 감지하면 경고한다 (요청 메시지 칸은 v0.4에서 없어짐)
- **기준값:** 전송은 허용 · 보낸 사람 · 받은 사람 화면 모두 메시지 아래 경고, 받은 사람에게 신고하기
- **예외:** 상단 고정 경고는 없음 (쌓이면 신고로 처리)
- **비고:** v0.5.2 (10/31): 보낸 사람에게도 경고 (본인도 외부 거래 표현인 줄 모를 수 있음, PM 결정)

### P-02-04 검사 대상
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** B-05-1 · A-05-2 · B-03-2 · C-06-2 · C-08-1
- **내용:** 금지어 · 외부 거래 표현을 검사하는 입력 칸
- **기준값:** 
  - 금지어 (경고, 게시 · 저장은 가능): 교환글 제목 · 원하는 아이템 · 설명 · 태그 / 닉네임 / 만날 곳 이름 / 교환폼(새로 작성) 제품명 · 설명 / 위시리스트 키워드
  - 외부 거래 (전송 허용 + 경고): 채팅
- **예외:** –
- **비고:** 10/20: 금지어도 막지 않고 경고만 (개발 확인 안건 4번). 2차 배포. v0.4 (10/26): 요청 메시지 칸 삭제 · 새 사진 아이템 이름 → 교환폼 제품명 · 설명

- **기준값:** –

### P-02-06 금지어 목록 · 운영
- **상태:** 확정 · **배포:** 2차 · **관련 기능:** B-05-1 · C-08-1 · H-04-1 · H-04-2
- **내용:** 기본 목록으로 시작하고, 신고 · 걸린 글에서 찾은 우회 표현은 운영자가 관리자 페이지(H-04-1)에서 추가한다
- **기준값:** 처음 목록 (분류: 판매 · 구매 / 외부 거래 / 기타)
  - 판매 · 구매: 팔아요 · 팝니다 · 삽니다 · 구해요 · 판매해요 · 판매합니다 · 구매해요 · 구매합니다 · 가격 · 숫자+원 · 만원 · 택배 · 반값
  - 외부 거래: 오픈채팅 · 오픈챗 · 카톡 · 카카오톡 · 텔레그램 · 인스타 DM · 계좌 · 송금 · 입금 · 010- 패턴
- **예외:** 한 글자(원)는 숫자와 붙을 때만. 오탐은 개발과 패턴 조율
- **비고:** 근거: 판매 중개 시 사업자 등록 필요 · 앱 밖 거래 사기 피해 구제 불가라 판매 · 외부 거래 표현에 경고를 보여준다 (MVP 핵심 방향, REQ-N-07)
  - 2차 개발 전에 PM이 목록을 다시 정리해 개발 파트에 전달한다
  - 판매 · 구매는 단어 대신 문장 형태만: "판매처 아시는 분" · "구매 인증" 같은 정상 글에 경고가 뜨는 것 방지
  - 토스 제외: 띄어쓰기 제거 비교 시 "토스트"까지 걸림. 송금 · 입금 · 계좌로 대체
  - 가격 유지: 가격 언급 자체가 무료 교환 성격과 맞지 않음
  - 원은 숫자와 붙을 때만 (예: 5000원)

- **예외:** 번지 · 도로명을 못 가져오면 가져온 단위까지 · 핀 위치로 건물명을 거꾸로 찾지 않음 (근처 다른 건물 이름이 잡힐 수 있음) · 1km는 고른 지점 기준
- **비고:** v0.4 (10/26) 새 정책: PD 검색 위치 설정 주석 답변. v0.5 (10/27): 화면별 표기로 나눔 — 탐색 위치는 내 기기에만 저장 · 내 화면에만 보여 번지까지, 교환장소는 사람들이 알아보기 쉬운 장소 이름 우선 (PM, PD 시안 코멘트)

  - 이미 제한 중인데 또 적용하면 더 긴 쪽으로 (기간을 더하지 않음)
- **예외:** 위반 경고 · 노쇼 인정 · 이용 제한은 운영자가 취소할 수 있고, 취소하면 본인에게 알림 (P-01-04)

### P-07-02 요청 첨부 · 같은 내 글 여러 요청 첨부
- **상태:** 확정 · **배포:** 1차 · **관련 기능:** C-06-2 · C-07-1 · E-03-1 · E-04-1 · F-01-2 · B-07-1 · B-07-2
- **내용:** 요청에 첨부한 내 교환글은 원본 글과 연결하고 복사(스냅샷)하지 않는다. 같은 내 교환글을 여러 요청에 동시에 첨부할 수 있다 (C-06-2가 정책서로 넘김)
- **기준값:** 
  - 요청 1건 = 내 글 최대 5개 또는 새로 작성한 아이템 1개 (섞지 않음)
  - 약속에서 교환할 물건으로 고른 첨부 글은 약속 확정 때 예약중, 교환 완료 때 교환 완료. 고르지 않은 첨부 글은 교환 가능 유지
  - 그 글이 다른 곳에서 교환 완료되면 다른 채팅방 아이템 카드에 "교환 완료된 아이템"
  - 첨부 글을 고치면 그 글이 첨부된 채팅방에 고친 사람 쪽 자동 메시지 "'아이템명'을 수정했어요 [보러가기]" · 지우면 "'아이템명'을 삭제했어요" + 카드 줄 "삭제된 아이템" (다시 첨부 없음)
  - 복사본이 없어 첨부 글을 "이 채팅방에서만" 다르게 고칠 수 없다. 요청 아이템 상세의 [수정하기]는 원본 글 수정 화면으로 간다
- **예외:** 그 글이 다른 곳에서 예약중이면 아이템 카드에 "다른 교환이 진행 중인 아이템" 표시하고 약속 물건 목록에서 뺀다
- **비고:** 10/20: 대기 요청이 없어져 "첨부에서 빠짐 · 자동 취소" 삭제. v0.4 (10/25 · 26 PM): 원본 연결 · 여러 개 선택 · 약속 때 물건 확정 · 고른 글 예약중
